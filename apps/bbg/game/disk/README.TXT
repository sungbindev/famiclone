GAME.CMD：在步步高学生电脑（BBGDOS）下运行 NES 游戏。

使用方法：
1. 把 GAME.CMD 和游戏文件放在同一张带 BBGDOS 的系统盘上，游戏文件名须是 8.3 名字（如 MARIO.NES）。
2. 进入 DOS，在提示符下输入 GAME 显示游戏菜单（上下键选择，Start 运行）；或输入 GAME MARIO（或 GAME MARIO.NES）直接运行。
3. 进入游戏后按手柄的 Start 开始。

注意：
- 只支持 mapper 0 的游戏：PRG 16K 或 32K，CHR 8K。
- 游戏里不能回到 DOS，只能复位。
- 出错时在命令行显示英文提示并回到 DOS，如 Mapper not supported、No .NES file on the disk。
