# bbk-bios：计划与进度

## 目标

在小霸王 SB2000 上运行步步高（BBK）的 BIOS 与 BBGDOS：改写步步高 BIOS 的硬件层，让它在 SB2000 的 6576 模式（SB-DOS 自己用的模式）下工作；SB-DOS 里的 EXE `START.EXE`（[bbk-loader](../../bbk-loader/README.md)）把 BIOS 映像 `bios.bbk` 装进扩展 RAM，换掉小霸王的 BIOS 与 SB-DOS，启动步步高系统，再从软盘启动 BBGDOS。

原厂源码、汇编器、符号还原与 FC 兼容模式的探测结论在 [machines/bbk](../../../../machines/bbk/docs/计划与进度.md)。

## 当前状态

英文版 BBGDOS 已能在模拟器里启动到 `A:\>`：`start` → 步步高开机检测画面（内存 256K、显存 32K、软驱 A）→ 从软驱 A 启动 → `Starting BBGDOS...` → `BBGDOS(R) Version 3.0` → 提示符，键盘输入正常，`dir` 能列出软盘文件。验证方法见 [../README.md](../README.md) 的 `npm run verify`。没有在真机上验证。

## 6576 模式的移植

### 映像文件 `bios.bbk`

| 位置 | 内容 |
| --- | --- |
| 0-3 | 魔数 `BBKB` |
| 4 | 格式版本 1 |
| 5 | 页数 8 |
| 6-7 | 入口地址（`Begin`，小端） |
| 8-15 | 保留，0 |
| 16 起 | 8 个 16K 页：页 0-6 是字库，取自 `bbk_bios10.nes`；页 7 是汇编结果，起始地址 `$C000`，空隙填 `$FF` |

文件长 131088 字节。构建见 `npm run build`（[../tools/build-bios.mjs](../tools/build-bios.mjs)）。

### 装载器 `start`

SB-DOS 下运行 `start`（`apps/sb2000/bbk-loader`）：读入盘上的 `BIOS.BBK`，检查文件头，关 NMI 与中断，用 DMA 把 8 个页复制到扩展 RAM 的 4K 页 `$E0-$FF`，再把跳板放到 ERAM `$6000` 运行：窗口 4-7 指向映像页 7，窗口 0-3 指向映像页 0，屏蔽全部中断，`$2008`、`$4300` 清 0，跳到入口。始终留在 6576 模式，不写 `$4301`；步步高系统起来后不再返回 DOS，只能硬复位。详见 [../../bbk-loader/README.md](../../bbk-loader/README.md)。

### 地址空间

| 步步高 | SB2000 的实现 |
| --- | --- |
| `$0000-$07FF` 内存、`$0800-$1FFF` 覆盖区 | SB2000 的内部 RAM（2K，按 2K 镜像），一致 |
| `$2000-$3FFF` PPU | 6576 PPU，寄存器不同，经 HAL 虚拟（见下） |
| `$4000-$43FF` 内部功能 | SB2000 的 `$4000-$43FF`：声音、手柄、键盘、中断、软驱、语音等 |
| `$4400-$57FF` 扩充空间 | **SB2000 没有**；原厂 BIOS 的低端内存分配会用到它 |
| `$5800-$5FFF` 系统 RAM | SB2000 的 `$5000-$5FFF` 2K 是同一块存储器的镜像，`$5800-$5FFF` 够用 |
| `$6000-$7FFF` 公共 RAM | SB2000 的 ERAM 8K；`$6010-$604F` 放 HAL 变量（`$6000-$60FF` 是手册规定的系统保留区） |
| `$8000-$BFFF` 分页区间（16K） | 窗口 0-3（`$4040-$4043`），每个 4K，指向扩展 RAM 的 4K 页 |
| `$C000-$FFFF` ROM 或 DRAM 最后一页 | 窗口 4-7（`$4044-$4047`）；`$FF01` 位 3 的切换改成改写窗口 |
| `$FF00-$FFFF` 步步高的 I/O | 不再使用；BIOS 里对应的访问都改了 |

扩展 RAM 的 128 个 4K 页（`$80-$FF`）分配：`$80-$BF` 是步步高的 DRAM（16 个 16K 页，256K）；`$E0-$FF` 是映像（页 r 在 `$E0+4r` 起）。

### 分页

- 步步高页号 `v >= $80` 是 DRAM，只取低 4 位，16K 页 `p` 对应 4K 页 `$80+4p` 起的 4 个；真机对页号高位不译码，BIOS 的内存检测靠这个别名算出大小，16 页时得到 256K。
- `v < $80` 是映像页，取低 3 位，4K 页 `$E0+4(v&7)` 起；字库页 0-6、代码页 7。
- `$C000-$FFFF`：ROM 时是映像页 7（`$FC-$FF`），RAM 时是 DRAM 第 15 页（`$BC-$BF`，即步步高页 `$FF`）。
- 内存检测不写 ROM 页 0（映像在可写的扩展 RAM 里，写会破坏字库）。

### 显示

步步高 BIOS 按 NES PPU 的方式用 `$2006/$2007` 写 VRAM，6576 PPU 的布局不同。硬件适配层（HAL）维护一套虚拟 PPU，把每次写转成 6576 的写入：

| 虚拟地址 | 6576 的实现 |
| --- | --- |
| `$0000-$1FFF` 图案表 | 扩展显存 `$8000` 起；步步高的 2K 图案槽（`$FF03+8n`）指向的 2K 页 p 放在 `$8000+p*$800` |
| `$2000-$3EFF` 名称表 | CRAM 的 `j*$800`，每个图块 2 字节：低字节 = 图案地址右移 4 位的低 8 位，高字节 = 调色板组左移 4 位 or 图案地址右移 12 位；按镜像方式（`$FF01` 位 1-0）把同一个写入做到所有相同的名称表 |
| 属性字节 | 改它覆盖的 4×4 个图块条目的调色板组；名称表条目是图块与调色板组的唯一记录，不另存影子 |
| `$3F00-$3FFF` 调色板 | `$2040` 起，每组 0 号色是公共背景色 |
| `$2000` | 记下虚拟值，真 `$2000` 的地址增量位固定为 0，增量由 HAL 处理；原厂用 `sta $2008`（`$2000` 的镜像）暂时关 NMI，改成只写真 `$2000` |
| `$2001`、`$2005` | 直接用 6576 的同名寄存器 |

BIOS 的显存检测改为固定 32K。步步高的显示全用背景图块，没有用精灵。

### 键盘与软驱

- 软驱：控制器与步步高同一种，端口按模拟器源码重映射：`$FF80/$FF88`→`$4200/$4201`（DMA 数据，带终止计数）、`$FF90` 读→`$4202`、`$FF90` 写→`$4101`、`$FF98`→`$4203`、`$FFA0`→`$4204`、`$FFA8`→`$4205`、`$FFB8` 读→`$4207`、`$FFB8` 写→`$4100`。
- 键盘：SB2000 的键盘经 `$4020` 送 XT 扩展码，与步步高 `KeyCodeTable` 的码一致，`$E0` 前缀对应步步高的扩展键标志。原厂用手柄口 `$4016/$4017` 扫描矩阵，已换成：键盘中断 `HalKbdIrq`（在 `BRKINTEntry` 里先调用）把码放进 16 字节队列，BBGDOS 常开着中断屏蔽运行，所以取键时 `HalKbdGet` 也主动查一次 `$4033` 位 5。`$4032` 只留键盘中断不屏蔽（`$DF`），其余中断源（定时器、鼠标、软驱）都屏蔽。原厂的矩阵扫描代码与码表还在源码里，已无人调用。

### 其他改动

- 去掉调试监控器的 7 个代码块（见“已查明的结论”），冷启动入口走复位向量，腾出的空间放 HAL；代码页 15915 字节，剩余 469 字节。
- 并口打印机、微机通讯卡的端口指向一个空变量，`ConnectPCCard` 直接返回“没连上”；语音口同样指向空变量；分屏的队列口写空变量。

### 验证（模拟器）

`npm run verify`：SB-DOS 里运行 `start`，画面依次出现：

1. 蓝底“系统检测 内存:256K 显存:32K 软驱卡 软驱:A 微机通讯卡 没连通微机 系统启动 从软驱A启动...”；
2. `Starting BBGDOS...`、日期与时间提示，回车跳过；
3. `BBG(R) BBGDOS(R) Version 3.0`、`A:\>`；
4. `dir` 列出 `BBGDOS.SYS`、`COMMAND.CMD`、`START.EXE`、`BIOS.BBK`。

## 未完成事项

- 中文显示：`Smdos.sys`（盘上的二进制）和 `Smcdos.asm` 直接读写 PPU，在 SB2000 上不能用，需要改成经虚拟 PPU 或 6576 的写法；中文版启动盘 `000.IMG` 还没试。
- 低端内存分配：原厂 `LowRAMAlloc` 在 `$4400-$57FF` 分配，SB2000 没有这段 RAM；溢出时它会回绕到 `$4400`，没有处理。
- 步步高页 `$FE` 与 `$4000-$7FFF`：原厂硬件里公共 RAM 就是页 `$FE` 的内容，SB2000 上它们是两块存储器，别名没有处理，也没有验证 BBGDOS 是否依赖它。
- 图案槽改变后不回刷已写入的名称表（原厂硬件是实时生效），中文显示与分屏需要。
- 卷轴：6576 的名称表高 32 行，步步高只有 30 行，垂直卷轴经过第 30 行时画面会出现两行空白。
- 扫描线分屏、鼠标、语音、并口打印机（改接 SB2000 的 `$4017`、`$4025`、`$4026`）、微机通讯卡（缺电缆针脚定义，待用户决定）。
- 虚拟名称表的读（`lda $2007`）返回 0。
- 内存按 256K 报告，不是原厂常见的 512K；映像占了一半扩展 RAM。
