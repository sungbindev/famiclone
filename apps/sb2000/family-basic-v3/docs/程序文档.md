# Family BASIC v3（SB2000 版）程序文档

Family BASIC v3.0（NS-HUBASIC V3.0）是运行在小霸王学习机 SB2000 上的 SB-DOS 程序。程序文件为 `FBASIC.EXE`，语句、表达式与数据与 FC 原版一致；键盘使用 SB2000 自带的键盘，保存与读取使用软盘。

## 运行环境

- 小霸王学习机 SB2000，SB-DOS 6576 模式。
- 软盘上有 `FBASIC.EXE`。构建后的磁盘镜像为 `build/sb2000/FBASIC.img`。

## 启动与退出

1. 在 SB-DOS 的 `A:\>` 提示符下输入 `FBASIC`，按回车。
2. 启动后显示 `NS-HUBASIC V3.0`、可用内存（实测 `4086 BYTES FREE`）和 `OK`。
3. 按 F12，或输入 `SYSTEM` 后回车，返回 `A:\>`。

退出后程序文本不保留。需要保留的程序请先用 `SAVE` 存到软盘。

## 键盘

| 按键 | 作用 |
| --- | --- |
| 字母、数字、标点、Shift 符号 | 与 PC 美式键盘相同 |
| 回车 | 执行语句，或结束输入 |
| 方向键 | 移动光标 |
| CapsLock | 切换假名输入模式 |
| Alt | 图形字符（对应原版的 GRPH 键） |
| Esc | ESC |
| Backspace、Delete | DEL |
| Insert | INS |
| Home | CLR/HOME |
| Shift + Home | 清屏 |
| F1 至 F8 | 功能键 F1 至 F8 |
| F9 或 Ctrl + C | STOP，中断程序 |
| F12 | 退出到 SB-DOS |

## 保存与读取

程序文件存为 `名字.BS`，名字取第一个 `.` 或空格之前的部分，扩展名固定为 `.BS`。`SAVE "ABC"` 与 `SAVE "ABC.BS"` 都保存为 `ABC.BS`。

| 语句 | 作用 |
| --- | --- |
| `SAVE "名字"` | 把当前程序保存到软盘 |
| `LOAD "名字"` | 从软盘读入程序，读入后用 `RUN` 运行 |
| `LOAD ? "名字"` | 比较软盘上的程序与内存中的程序，一致显示 `OK`，不一致显示 `TP ERROR` |
| `SAVE S "名字"` | 保存当前背景画面为 `名字.BS` |
| `LOAD S "名字"` | 读入背景画面 |

- 找不到文件、软盘写保护、盘满或文件内容不正确时显示 `TP ERROR`。
- 文件内容是 FC 原版的程序记录格式，不是文本，不能用文本编辑器修改。
- 读写软盘期间键入的按键会丢失，等 `OK` 出现后再输入。

## 内置程序

`GAME 0`、`GAME 1`、`GAME 3` 可以直接运行。`GAME 3` 为 Star Killer。`GAME 2` 没有单独核对。

## 声音与手柄

- `PLAY`、`BEEP` 可以发声。音符时长与原版相同，但声音本身没有实际听过核对。
- `STICK`、`STRIG` 读取 SB2000 手柄。`STICK(0)`、`STRIG(0)`、`STICK(1)` 在相同按键下与原版取值一致。

## 限制

- 只支持软盘保存，不支持磁带。
- 程序文本退出后不保留，需要用 `SAVE` 保存。
- `BACKUP` 语句保留原版流程。学习机没有备份开关，这个语句的结果没有在实机上核对。
- 画面刷新为 50Hz，原版为 60Hz。`GAME` 等依赖帧数的程序，进度与原版不同。
- 键盘的 F1 至 F4、F6、全部假名与图形字符没有逐个核对。
- 以下在 Ember 模拟器中验证，真机没有核实：进入与退出时的画面、声音、软盘读写。

## 常见问题

**输入没有反应**：等待 `OK` 出现。软盘读写期间的按键会丢失。

**显示 `TP ERROR`**：检查文件名是否正确、软盘是否写保护或已满。`LOAD ?` 显示 `TP ERROR` 时，表示软盘上的程序与内存中的程序不一致。

**找不到 `FBASIC`**：确认软盘的根目录有 `FBASIC.EXE`，并且当前驱动器是 `A:`。

**退出后程序丢失**：程序文本不随退出保留，退出前先用 `SAVE` 保存。
