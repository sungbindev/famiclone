# memtest

在小霸王学习机 SB2000（SB-DOS）下运行的内存测试程序：在真机上实测扩展 RAM、ROM 页、扩展显存、内部 RAM 与 DMA 的可用写法，结果分两屏显示。用 fcdev 开发，C 语言。

## 使用

```bash
npm run build    # 生成 build/sb2000/MEMTEST.EXE
npm run start    # 在模拟器里运行
```

把 `build/sb2000/MEMTEST.EXE` 复制到 SB-DOS 的软盘，在 `A:\>` 下输入 `memtest`。屏幕先显示等待提示，约几秒后给出第一屏，按任意键看第二屏，再按任意键返回 DOS。

## 结果的含义

### 第一屏

| 行 | 含义 | 真机实测（2026-11-12） |
| --- | --- | --- |
| `Ext RAM: N/128 banks` | 扩展 RAM 页 `$80-$FF` 里互相独立的 4K 页数，乘 4 是容量；`alias` 是与本程序自己的页内容相同的页数，`odd` 是读回了意外值的页数 | 128 页，512K，无别名 |
| `ROM: N/128 distinct` | ROM 页 `$00-$7F`（只读）里内容不同的页数；`blank` 是内容全相同（如全 `$FF`）的页数；`repeats every` 是内容每隔多少页重复一次 | 128 页不同，1 页空白，不重复 |
| `Ext VRAM: N/32 banks` | 显存 bank `$00-$1F`（`$4300`）里独立的 32K 页数，乘 32 是容量 | 16 页，512K |
| `RAM $0000 x4` | `$07F8`、`$0FF8`、`$17F8`、`$1FF8` 四个地址里互相独立的个数，1 表示内部 RAM 2K 镜像 | 1 |
| `ERAM $6000 x8` | `$63F8` 起每隔 1K 的 8 个地址里互相独立的个数 | 8 |

### 第二屏

DMA 各种写法的结果，每行格式 `阶段 模式 E:ab W:cd`：

| 字段 | 含义 |
| --- | --- |
| 阶段 `N` / `F` | `N` 是 NMI 与显示开着（DOS 正常状态），`F` 是已关 NMI 与中断 |
| 模式 | DMA 模式字节 `$4048`，`A0` 或 `E0` |
| `E:` / `W:` | 目标是 ERAM `$7C00` 还是窗口 2 `$A000`；阶段 `N` 只试 ERAM，`W` 显示 `--` |
| `ab` / `cd` | 依次是 `$404B` 位 7 为 0、为 1 时的结果，`Y` 表示复制出的内容与样板一致，`N` 表示失败（原厂 BIOS 每次都把 `$404B` 的位 7 置 1） |

模拟器已按真机实测修改（2026-11-13），结果与真机相同：`RAM $0000 x4` 为 1，DMA 只有“目标 ERAM、位 7 为 1”是 `Y`，其余都是 `N`。修改前模拟器里全是 `Y`。真机第一次（`$404B` 位 7 清 0、只试 `$A0`/`$E0` 与两种目标）全部失败；第二次的结果是所有“目标 ERAM、位 7 为 1”都是 `Y`，其余都是 `N`。

## 真机实测记录

| 项目 | 结果 |
| --- | --- |
| 扩展 RAM | 页 `$80-$FF` 共 128 个 4K 页，互相独立，无别名，512K |
| ROM 页 `$00-$7F` | 128 页内容互不相同，其中 1 页空白 |
| 扩展显存 | 16 个 32K bank，512K，更大的 bank 号回绕 |
| 内部 RAM | 2K，`$0800-$1FFF` 是它的镜像 |
| ERAM `$6000-$7FFF` | 8K，各 1K 互相独立 |
| `$4400-$5FFF` | 28 个 256 字节块在偏移 `$F8` 处读到的都是 `$68`，写 `$55`、`$AA` 后读回仍是 `$68`：既不是 RAM，也不是会应答的寄存器 |
| DMA | 只有目标是 ERAM 且 `$404B` 位 7 为 1 时成功，模式 `$A0`、`$E0` 都行，与 NMI 开关无关；目标是窗口 2 `$A000` 一律失败 |

## 做法与安全

- 测试写入的单元都先保存、测完按相反顺序还原；关 NMI、关中断之后不调用 DOS 服务，直接写窗口 2 的页寄存器 `$4042`，结束时窗口 2 还原成本程序的第 3 页。ERAM `$7C00` 起的 16 字节在 DMA 测试前保存、测完还原。
- DMA 的模式 `$A0` 与 `$E0` 的目的位（位 5）都是 1，目标都是工作 RAM；`$E0` 只多置了位 6（1.78MB/s 的传输速率），不会写显存。`$404B` 位 7 为 0 的写法按芯片手册相当于源地址 A15 为 0，真机上失败，不会写出内容。
- 扩展 RAM 的写测试先只读比较各页与本程序自己的页的内容：内容相同的页是别名，不写；本程序占的 4 页也不写，按“4 页互不相同”计入。
- 本程序的文件必须大于 `$1100` 字节，且带 BSS 不超过 `$A000`，否则提示 `Bad program size` 后退出；改动代码后要留意这一点。
- 屏幕只有约 12 行、32 列，每屏的行数与每行的字符数不要再增加。
- 模拟器的扩展 RAM、ROM、扩展显存容量是写死的，这几项在模拟器里的结果只能证明程序逻辑；内部 RAM、DMA 与 `$4400-$5FFF` 已按真机实测修改，模拟器里的结果与真机一致。
