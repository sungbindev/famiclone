RUN.EXE：在裕兴学习机的 DOS 下运行 NES 游戏。

使用方法：
1. 把 RUN.EXE 和一个游戏文件（扩展名 .NES，文件名须是 8.3 名字）放在同一张软盘上。
2. 进入 DOS，在提示符下输入：RUN.EXE（必须写扩展名）。
3. 程序运行软盘根目录里的第一个 .NES 文件。进入游戏后按手柄的 Start 开始。

注意：
- 支持 mapper 0（PRG 16K 或 32K，CHR 8K）；V9.0-98 学习卡还支持 mapper 4（MMC3）。
- 游戏里不能回到 DOS，只能复位。
- 出错时画面第 10 行显示英文提示并停住，需要复位。
