## 4. 目标

| 事项 | 说明 |
| --- | --- |
| 步步高、裕兴的目标 | 缺少资料，动手前先用资料与模拟器确认程序格式、内存布局、系统调用与固件要求 |
| NES 的其他映射器 | 现在只支持 `nes.cfg` 的 NROM |
| SB2000 的退出码 | `main` 的返回值没有实现为退出码：`$6308` 是运行库显示消息用的 `LIB_GROUP`，DOS 外壳不读取程序返回时的它，系统里没有退出码这个约定；要不要提供自己的约定（如写到某个 ERAM 单元）以后再定 |
| SB2000 没封装的系统调用 | 见 [api-reference.md](../vscode/targets/sb2000/api-reference.md) 末尾的覆盖表与 `api-unwrapped.json`：文件系统内部步骤、`$41`-`$44`、`$31`、`$34`、`$66`、`$65` 与 `$6D` 的部分子功能、`$74`/`$75` 的 NMI 发送与播放列表等；有需要时再封装并补测试 |

## 5. 反汇编

| 事项 | 说明 |
| --- | --- |
| 其他映射器 | 反汇编已支持 NROM、MMC1、UxROM、CNROM、MMC3、AxROM（按默认模式）与平铺二进制；其他映射器需要在模拟器里查出地址映射再给出布局 |
| 跳转表识别 | 已识别 `LDA 表,X` 加间接 `JMP`、`PHA`/`RTS` 的表和 `JMP (地址)` 指向的表；例程内联的跳转表（`JSR` 之后紧跟地址表）、立即数拼出的分发指针还追不到，这部分按数据输出；补全覆盖靠运行记录：模拟器 `trace ... unique` 在步步高机型上可用，CDL 只对 SB2K 映射器有效，对步步高 RAM 里的程序没用。立即数拼出的指针可以让扩展列出“可能的入口”供人工确认，还没做 |
| 地址表与字符串识别 | 命令“反汇编映像文件”里没追到的字节都按 `.byte` 输出；核心里的候选识别（`shared/disassembly/analysis/detect.ts`）已经给 Copilot 的 `disasm_detect` 用，还没接进命令 |
| 整份学习机 BIOS 的回读 | 512K 的 BIOS 能新建工程并追踪（3649 条指令），整份的生成与回读没有跑 |
| SB2000 固件页的 CDL 验证 | 没有做；模拟器自带 CDL 只对 SB2K 映射器有效 |
