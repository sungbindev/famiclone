| macOS 的 ffmpeg | 磁带解码用的 ffmpeg 目前只有 Windows x64 的程序（`core/third_party/ffmpeg`）；macOS 的程序要在苹果电脑上编译并登记到 `third-party.json`，macOS 的进程启动代码（`platform/process/stream-process-mac`）也要在 macOS 上编译验证 |
| 打印机默认保存位置 | “图片保存位置”留空时存到用户数据目录下的 `printer-output`，这个默认位置待用户确认 |

### 3.1 金字塔学习机（pec9588、pec586）

| 事项 | 说明 |
| --- | --- |
| 5.25 英寸软驱 | 真机可以接一个 5.25 英寸软驱（`pec9588` 主菜单里的「磁盘操作系统」要用），目前没有这种软驱：`floppy-drive` 按镜像大小推断格式，已支持 160、180、320、360、1200 KB 的镜像，缺的是这台机器上的软驱控制器接口（地址译码、寄存器、中断与 DMA 的接法）与驱动器的接线；做之前要先核对接口 |
| 不做的设备 | 真机不支持鼠标与 3.5 英寸软驱（用户 2026-11-21 告知），不为金字塔做这两种设备 |
| `$5300` 与 `$5500` 位 4 的含义 | 磁带的接线已按两个型号的 ROM 定下（见 02 第 6.11 节）：`pec9588` 输出 `$5100` 位 0、输入 `$5500` 位 2，`pec586` 输出 `$5100` 位 2、输入 `$5300` 位 2；`pec9588` 的 ROM 里没有读 `$5300`，`pec586` 的 ROM 里 `$5300` 位 0 是打印机就绪（已接）、读 `$5500` 位 3 的含义也没有查明，现在 `$5500` 固定读出 `$10`；磁带信号的极性用默认的（自己的 SAVE、LOAD 与真实的声像磁带都能工作），没有与真机对照 |
| `pec586` 的启动映像 | 启动映像的拼法（后 256K 每 16K 块末尾的两段 1K）从修改版模拟器 `VirtuaNESex-586-686.exe` 的 mapper 还原，PEC-586 与 PEC-686F 都能开机，真机上这块 32K 映像是什么硬件没有核对；`pec586` 的 ROM 里还有对 `$5400`、`$5700` 的写入没有接 |
| 汉字模式的精灵 | 汉字模式下精灵的取色已后移 2 项；真机上卡带如何区分背景与精灵、精灵取色是否如此没有核对（pec586 启动画面的文字颜色会因此变化） |

## 4. 出现第二个使用者时改成公共的

现在只有一个机型或一处在用、拆成公共模块没有收益的内容。出现第二个使用者时，必须先告诉用户，再改成公共的（放进 `logic/hardware/` 的硬件模块，或 `bootstrap/machines/common/`）。

| 事项 | 说明 |
| --- | --- |
| `Sb2000FcMapper` 的窗口选择与偏移换算（2026-11-16 用户决定） | 在 `bootstrap/machines/sb2000/sb2000-fc-board.hpp`：`$5006` 选 128K 窗口，把 mapper 电路给出的页号换算成扩展 RAM、扩展显存与名称表的偏移；只依赖 `MapperCircuit` 契约，目前只有 `sb2000` 的 FC 兼容模式在用；别的机型或卡带需要同样的窗口换算时，拆成 `logic/hardware/` 下的公共模块（页号线数、窗口大小做成参数） |
| `Sb97FdcInterrupt` 与帧 IRQ 禁止（2026-11-17） | 在 `bootstrap/machines/sb97/`：软驱控制器的 INT 脚接 CPU 的 IRQ 线（控制器请求时与寄存器读写后，IRQ 线跟着控制器的中断标志），以及上电与复位时禁止 APU 帧 IRQ；目前只有 `sb97` 在用（`sb2000` 用中断汇集器，`bbg` 查询状态位）；别的机型需要同样的 INT 线接法时拆成公共的转接设备 |
| `YuxingMachine::InputPort`（2026-11-21） | 在 `bootstrap/machines/yuxing/yuxing.cpp`：在手柄与 APU 帧计数器之上叠加鼠标位与磁带位；各机型的 `$4016-$4017` 输入口读写含义都不同（`fc` 的扩展口、`pec9588`/`pec586` 与 `sb97` 的键盘矩阵、`bbg` 的键盘与鼠标、`yuxing` 的鼠标与磁带），没有第二个使用者，没有拆成公共部件；出现一样的接线时再拆（手柄口与 APU 的公共部分已是 `common/pad-apu-port.hpp`） |
| `BbgBoard` 的分屏与扫描线计数 | 在 `bootstrap/machines/bbg/bbg-board.cpp`：行时钟、扫描线计数器、分屏队列与 MMC3 模式的页号换算只有 `bbg` 在用；别的机型需要同样的扫描线计数或分屏时拆成 `logic/hardware/` 下的公共模块 |
| `YuxingPrinterPort`（2026-11-22） | 在 `bootstrap/machines/yuxing/yuxing-printer-port.*`：把 `$4016` 上逐位送出的字节（位 1 时钟移入、位 2 下降沿锁存）转成并口的一次数据写入，并给出读 `$4016` 位 1 的就绪；只有 `yuxing` 的打印机接在手柄口的扩展线上，其他机型的打印机接线都是并口寄存器（`sb2000`、`bbg`）或主板寄存器（`pec9588`、`pec586`）；别的机型出现同样的逐位送字节接线时拆成公共的转接设备 |
