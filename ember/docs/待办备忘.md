## 2. 界面

| 事项 | 说明 |
| --- | --- |
| macOS 的键盘独占 | **暂不做（2026-11-15 用户决定）**。Windows 上画面区获得焦点时用原始输入独占键盘（01 第 7 节“键盘独占”），macOS 没有实现，现在退回页面内的键盘事件（Esc、Tab、F 键、Ctrl、Alt 组合留给应用，不交给机器）；需要在 macOS 上找出对应的独占做法（如事件拦截或全屏键盘锁定），并在苹果电脑上编译与验证 |

## 3. 学习机（小霸王 2000）

| 事项 | 说明 |
| --- | --- |
| 软盘文件管理 | **暂不做（2026-11-15 用户决定）**。界面（原来设计在右边栏，已取消，形式重新设计）、`media.floppyList`、`media.floppyAddFile`、`media.floppyDeleteFile`、`media.floppyRenameFile`、事件 `media.floppyFilesChanged`、盘片的 FAT12 解析与学习机缓存失效（02 第 6.7 节）；学习机阶段只做了盘片的插拔、保存与写保护 |
| 学习机的磁带接口 | 磁带机目前只挂在经典 FC 上（`tape-deck` 已完成，见 02 第 6.4 节）；学习机机型有自己的音频输入输出接口（一个输入、一个输出），接线和寄存器按机型对照实测核实后往学习机装配里接上同一个 `tape-deck`，设备面板随之显示磁带机一行（现在学习机没有磁带机，面板不显示这一行） |
| macOS 的 ffmpeg | 磁带解码用的 ffmpeg 目前只有 Windows x64 的程序（`core/third_party/ffmpeg`）；macOS 的程序要在苹果电脑上编译并登记到 `third-party.json`，macOS 的进程启动代码（`platform/process/stream-process-mac`）也要在 macOS 上编译验证 |
| 声像教学卡 PLQ（mapper 172，PRG 16K） | `plugins/qls` 只实现了 PRG 32K 的 QLS（`qls.nes` 就是这一种，已用真实磁带验证）；PRG 16K 的“普里奇”版有 PAL 逻辑寄存器和 8K RAM，只有旧模拟器的源代码，没有 ROM 可验证，等有 ROM 再做 |
| 打印机默认保存位置 | “图片保存位置”留空时存到用户数据目录下的 `printer-output`，这个默认位置待用户确认 |
| 与真机仍有差异的读数 | **不改，遇到问题再处理（2026-11-15 用户决定）**。`$4015` 位 4 与 `$4037`（真机读数取决于读取时刻、不固定，无法对齐）、`$4033` 位 6 清除后仍为 1（真机没接鼠标时的状态，这里接着鼠标），见 `packages/fcdev/docs/sb2000/03-硬件说明.md` 的“真机与模拟器仍有差异的行为”；`$4022` 开机值 `$C0`、`$4016` 读 `$44`、`$3FFF` 读 `$68` 已对齐 |
| 其他整机机型 | **暂不做，最后由用户选择再做（2026-11-15 用户决定）**。`sb97`、`bbk10`、`bbk20` 的主机型号与 BIOS 校验（机型清单里现在是“暂未支持”） |
