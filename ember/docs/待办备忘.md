## 4. 出现第二个使用者时改成公共的

现在只有一个机型或一处在用、拆成公共模块没有收益的内容。出现第二个使用者时，必须先告诉用户，再改成公共的（放进 `logic/hardware/` 的硬件模块，或 `bootstrap/machines/common/`）。

| 事项 | 说明 |
| --- | --- |
| `Sb2000FcMapper` 的窗口选择与偏移换算（2026-11-16 用户决定） | 在 `bootstrap/machines/sb2000/sb2000-fc-board.hpp`：`$5006` 选 128K 窗口，把 mapper 电路给出的页号换算成扩展 RAM、扩展显存与名称表的偏移；只依赖 `MapperCircuit` 契约，目前只有 `sb2000` 的 FC 兼容模式在用；别的机型或卡带需要同样的窗口换算时，拆成 `logic/hardware/` 下的公共模块（页号线数、窗口大小做成参数） |
