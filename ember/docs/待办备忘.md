## 4. 出现第二个使用者时改成公共的

现在只有一个机型或一处在用、拆成公共模块没有收益的内容。出现第二个使用者时，必须先告诉用户，再改成公共的（放进 `logic/hardware/` 的硬件模块，或 `bootstrap/machines/common/`）。

| 事项 | 说明 |
| --- | --- |
| `Sb2000FcMapper` 的窗口选择与偏移换算（2026-11-16 用户决定） | 在 `bootstrap/machines/sb2000/sb2000-fc-board.hpp`：`$5006` 选 128K 窗口，把 mapper 电路给出的页号换算成扩展 RAM、扩展显存与名称表的偏移；只依赖 `MapperCircuit` 契约，目前只有 `sb2000` 的 FC 兼容模式在用；别的机型或卡带需要同样的窗口换算时，拆成 `logic/hardware/` 下的公共模块（页号线数、窗口大小做成参数） |
| 软驱控制器的端口译码（2026-11-16） | `sb2000` 在 `bootstrap/machines/sb2000/sb2000-board.hpp` 的 `Sb2000SuperIo` 里把软驱端口（DMA 数据口、数据请求、终止计数、读写寄存器）换成 `fdc-upd765` 的读写调用，`bbk` 在 `bbk-board.cpp` 的整机寄存器里写了一份同样的换算（端口号、行为一致，只是地址不同），现在有三个使用者（`sb97` 在 `sb97-board.cpp` 里也写了一份）；要拆成 `bootstrap/machines/common/` 里的软驱端口转接设备（地址表做成参数）时先经用户确认 |
| `Sb97FdcInterrupt` 与帧 IRQ 禁止（2026-11-17） | 在 `bootstrap/machines/sb97/`：软驱控制器的 INT 脚接 CPU 的 IRQ 线（控制器请求时拉低，寄存器读写后重新定电平），以及上电与复位时禁止 APU 帧 IRQ；目前只有 `sb97` 在用（`sb2000` 用中断汇集器，`bbk` 查询状态位）；别的机型需要同样的 INT 线接法时拆成公共的转接设备 |
| `BbkBoard` 的分屏与扫描线计数 | 在 `bootstrap/machines/bbk/bbk-board.cpp`：行时钟、扫描线计数器、分屏队列与 MMC3 模式的页号换算只有 `bbk` 在用；别的机型需要同样的扫描线计数或分屏时拆成 `logic/hardware/` 下的公共模块 |
