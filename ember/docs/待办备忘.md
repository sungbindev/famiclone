## 2. 学习机（小霸王 2000）

| 事项 | 说明 |
| --- | --- |
| 软盘文件管理 | 右边栏（05 第 4.6 节）、`media.floppyList`、`media.floppyAddFile`、`media.floppyDeleteFile`、`media.floppyRenameFile`、事件 `media.floppyFilesChanged`、盘片的 FAT12 解析与学习机缓存失效（02 第 6.7 节）；学习机阶段只做了盘片的插拔、保存与写保护 |
| 磁带机 | `tape-deck-data`、`tape-deck-av`、`media.tape*` 请求与设备边栏的磁带机卡片（05 第 4.3 节） |
| 软驱指示灯 | 活动栏设备按钮上的软驱读写灯；核心要先上报软驱的读写状态，界面不自己推测 |
| 取出盘片时的确认 | 盘片有未保存的修改时点“取出”，目前直接丢弃修改，应先弹确认框 |
| FC 兼容模式 | 6576 的 `$4301` 写 `$55` 切到 FC 兼容模式（MMC3 仿真，旧版 `runnes`、`bbk-loader` 用） |
| 语音合成 | `$4302` 现在是始终就绪的存根，没有 LPC 解码播放 |
| 打印机默认保存位置 | “图片保存位置”留空时存到用户数据目录下的 `printer-output`，这个默认位置待用户确认 |
| 首选项“输入”分组 | “点击画面捕获鼠标”与指针锁定（相对位移）还没有做 |
| 与真机仍有差异的读数 | `$4022` 开机值（真机 `$C0`，这里 `$80`）、`$4015` 位 4、`$4016` 与 `$4017` 的读数、`$3FFF` 与 `$4037`、`$4033` 位 6，见 `packages/fcdev/docs/sb2000/03-硬件说明.md` 的“真机与模拟器仍有差异的行为” |
| fcdev 接入 Ember | `fcdev run` 与 `fcdev debug` 改用 Ember（sb2000 目标接回 Ember），并恢复 `sb2000-library` 里依赖模拟器的测试 |
| 其他整机机型 | `sb97`、`bbk10`、`bbk20` 的主机型号与 BIOS 校验（机型清单里现在是“暂未支持”） |
