# 更新记录

## 未发布

- 调整 FC 与裕兴、金字塔等学习机的画面颜色：整体比之前更亮，颜色更接近常见的模拟器。
- 学习机运行时在“设置→机型与 ROM”里换了 ROM 后，点硬复位（或断电后再开机）会按新的 ROM 启动，不再继续用开机时的旧 ROM。
- 在资源管理器里双击 `.nes` 文件就能用 Ember 打开并运行；Ember 已在运行时，会在已有的窗口里打开这张卡带。Ember 启动时会把自己登记为 `.nes` 的打开方式，`.nes` 还没有默认程序时它就是默认程序。
- 修复设置实体手柄时，点了键后马上按手柄按钮绑不上、且这个键必须取消后重新点才能再绑的问题；点键时手柄上还按着按钮会提示“请松开”，松开后再按即可绑定。
- “机型与 ROM”对话框新增“从目录添加 ROM”：选一个文件夹，把里面认得出的各机型 ROM 一次添加。
- 学习机开机后，系统栏在机型名右边显示正在使用的 ROM 版本（如“裕兴  V9.0-98”）。
- 添加 ROM 时只接受不带 NES 文件头的 `.bin` 文件。
- 新增裕兴学习机：在“设置→机型与 ROM”里给“裕兴”添加 ROM（V8.0-C、V8.2-D、V8.3-D、V9.0-98 四个学习卡里任选一个，想换另一个就替换），再用“机器→选择机型”开机。
- 裕兴有自带键盘、鼠标、两个手柄口和一个软驱：主菜单可以用方向键或鼠标选择，“磁盘管理”能读写软驱里的软盘，V8.2-D 与 V8.3-D 的学习卡也能从软盘运行 WPS。
- 裕兴支持磁带：游戏 BASIC 里用 `SAVE"A"` 把程序存进磁带机、用 `LOAD"A"` 读回；V8.0-C 主菜单的“声像学习”可以放声像教学磁带，课文跟着磁带出现，磁带里的声音从扬声器播出。
- 修复步步高软驱一号与步步高 98 不能格式化软盘的问题：在 DOS 里输入 `format a:` 现在可以正常完成。
- 设备面板里软驱与磁带机的状态文字（无盘片、无磁带等）左边对齐，磁带机的“取出”按钮移到最右，与软驱的“取出”在同一位置。
- 设备面板里设备名前加了图标并用醒目的样式，名称列变窄，盘片名与磁带名有更多的显示空间。
- 点设备面板里磁带机的位置（如“0:23 / 0:40”）会弹出磁带时间轴：显示磁带上各处声音的大小，连续没有声音的空白段用浅色底标出，用鼠标点击或拖动后松开就能把磁带定位到那里，方便在一盘磁带里找到某个程序的位置（停止和播放时都可以定位）。

## 0.3.4

- 新增金字塔学习机两个机型：“金字塔 PEC-9588”和“金字塔 PEC-586、686”。在“设置→机型与 ROM”里添加 ROM 文件，再用“机器→选择机型”开机；PEC-586 与 PEC-686F 两个 ROM 用同一个机型，添加哪个都可以。
- 金字塔学习机开机后先显示开机画面：PEC-9588 按回车、PEC-586 与 PEC-686F 按空格进入系统主菜单，中西文与函数 BASIC、绘图、LOGO 语言、汇编、声像电视教学等都能进入。PEC-9588 主菜单里的“磁盘操作系统”需要 5.25 英寸软驱，暂时不能用。
- 金字塔学习机自带键盘，运行时画面独占键盘，键盘按电脑键盘的位置对应。
- 金字塔学习机支持磁带：BASIC 里用 `SAVE` 把程序存进磁带机、用 `LOAD` 读回（PEC-586 与 PEC-686F 的命令要写文件名，如 `SAVE "A"`）；主菜单的“声像电视教学”可以放声像教学磁带，课文跟着磁带出现，磁带里的声音从扬声器播出。
- “机型与 BIOS”改名为“机型与 ROM”：有的学习机不是“BIOS 加 ROM”的形式，所以统一叫 ROM；对话框里的按钮与提示、保存位置的名字也随之改叫 ROM，升级后需要重新添加一次 ROM。

## 0.3.3

- 玩经典 FC 游戏时，系统栏不再显示“经典 FC”，只显示卡带名和 mapper 插件。

## 0.3.2

- 带调试端口启动的 Ember（如 `fcdev run --debug`）不会在调试中途自行升级。
- 首选项的“画面”分组新增“画面效果”：可以选择平滑，或让每个像素都清晰分明的像素画面。
- “选择机型”从“文件”菜单移到“机器”菜单的第一项。
- 学习机的 BIOS 不再在首选项里，改在“设置→机型与 BIOS”里添加、替换和移除。
- 拖动窗口和对话框的边缘改变大小时，缩放区在边框线和边框线外面几个像素，贴着边框的滚动条可以正常点击。
- “机器”菜单的“选择机型”选了机型后直接显示这个机型的名字。
- “接入 Family BASIC 键盘”不再出现在首选项里，只在“机器”菜单里设置，也不再保存，每次启动都是未接入。
- 首选项、手柄设置、机型与 BIOS、mapper 插件和关于对话框缩到最小时，设置项右边的控件和工具栏不再换行或挤到名称下面，对话框的最小宽度（首选项、手柄设置还有最小高度）刚好放下里面的内容。

## 0.3.1

- 学习机以及接入 Family BASIC 键盘独占键盘时，`F9` 到 `F12` 也始终留给 Ember，`F9` 开机与断电、`F11` 全屏任何时候都有效。
- 点“文件→选择机型”里已经打对勾且正在运行的机型，什么都不做，不再重新开机。
- “设置”菜单新增“全屏”，快捷键 `F11`。

## 0.3.0

- Ember 改为 Windows 原生程序，支持 Windows 7 SP1 到 Windows 11 的 64 位系统；发布为单个 `Ember.exe`，解压即用，不需要安装。
- 升级只替换 `Ember.exe`，检查更新、下载、重启安装的用法不变。
- 显示画面优先用支持 Direct3D 11 的显卡；没有显卡或驱动的电脑（虚拟机、远程桌面等）会改用系统自带的软件渲染，也能显示画面。
- 不再自带学习机的 BIOS，也不会在电脑里自己查找：需要哪个机型，就在“设置→首选项→机型与 BIOS”里给它添加 BIOS 文件。
- 首选项新增“用户数据目录”：可以在软件所在目录旁的 `ember-data` 与当前用户的应用数据目录之间切换，全部数据一起带过去。
- 帮助文档和更新记录改用系统默认浏览器打开。
- 首选项“画面”里新增“开机与复位后隐藏最初的画面”，默认关闭。
- 经典 FC 游戏不再独占键盘，`F8`、`F9`、`Ctrl+O` 等快捷键和 `Alt` 加字母的菜单键随时可用；学习机以及接入 Family BASIC 键盘时仍独占键盘。
- 画面右下角的提示改为半透明的毛玻璃提示框，新增键盘被独占时的提示。
- “关于 Ember”里的版本、核心版本和编译时间移到右上角，项目地址的焦点框贴着链接文字。
- 对话框的标题栏有了 Ember 图标和最小化按钮，按钮样式与主窗口一致；对话框打开时不再聚焦到某个按钮或链接上；对话框里的滚动条贴着对话框右边。
- 二级菜单放不下时不再盖住一级菜单。
- 对话框打开时不再先闪一下白色。
- 复位后，画面右下角的键盘独占与鼠标捕获提示会再次显示；鼠标捕获提示的文字缩短为“点击捕获鼠标，双击右键释放”。
- 画面右下角的键盘独占提示与鼠标捕获提示各用一个毛玻璃圆角提示框。

## 0.2.2

- 没有开机时，画面上的提示改为“文件→选择机型，选好即开机”。

## 0.2.1

- 首选项新增“应用”分组，里面的“允许同时运行多个实例”打开后，可以同时打开多个 Ember（下次启动时生效）。
- “设置”菜单里“首选项”移到最上面。

## 0.2.0

- 新增小霸王 97（SB97）机型，随安装包带默认 BIOS，使用独立的键盘。
- 新增 200 多个 mapper 插件，覆盖 260 多个 mapper 号：MMC1、MMC2、MMC3 及变体，VRC、Namco、Taito、Sunsoft、Bandai 等常见卡带。
- “设置→mapper 插件”里搜索时忽略空格（`mapper4`、`mmc3` 都能搜到），搜索框右边显示插件与 mapper 的数量，所选插件的详细清单在它那一行下面展开。
- 发现新版本后，标题栏出现蓝色的“更新”按钮，点一下就重启并安装。
- “文件→选择机型”点一下就开机，并记住所选机型。
- 底部面板的高度按内容自动确定。
- 主窗口的默认尺寸调小。
- 没有显卡加速的电脑（虚拟机、远程桌面等）也能显示画面，不再提示“无法初始化画面渲染：浏览器不支持 WebGL”。
- 升级后第一次启动时，自动打开这一页。
- 帮助文档新增“插件开发手册”，讲解怎样给新的卡带 mapper 写插件。
- 帮助文档新增“fcdev 开发手册”：用 fcdev 为 NES 和小霸王学习机开发程序的命令、系统调用、硬件说明、C 接口与汇编符号参考、示例程序源码。
- 帮助文档的滚动条覆盖在页面上，“机型与 BIOS”页增加“打开 BIOS 目录”的链接。

## 0.1.0

首个版本。

- 运行经典 FC（红白机）的 `.nes` 卡带，按卡带的 mapper 自动装配主机；mapper 以插件的方式提供，可以在“设置→mapper 插件”里安装与启用。
- 运行学习机整机：小霸王 SB2000，步步高 BBK10、BBK20；BIOS 随安装包自带，也可以在首选项里添加或替换。
- 软盘、磁带与打印机，键盘、手柄与鼠标，画面与声音。
- 在“帮助→检查更新”里检查并安装新版本，也可以在首选项里设置启动时自动检查。
- 内置调试服务，默认关闭，需要时在首选项里打开。
