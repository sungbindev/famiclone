# Ember 使用说明

Ember 是 FC（红白机）与小霸王、步步高等学习机的模拟器，界面只有一块运行画面，其余操作都在菜单和底部面板里。

## 能运行什么

| 类型 | 做法 |
| --- | --- |
| 经典 FC | 直接打开 `.nes` 文件，主机按卡带的 mapper 自动装配 |
| 学习机整机 | 先添加该机型的 BIOS，再在“文件→选择机型”里选机型并开机，不需要卡带 |

- Ember 不提供任何 BIOS 或游戏文件，需要自备。
- 学习机的 BIOS 文件不能当卡带打开，要走“机型与 BIOS”这条路，见[机型与 BIOS](machines.md)。
- 具体哪些机型已经可用，以“文件→选择机型”里没有置灰的为准。

## 调试功能

Ember 内置一个调试服务，可以用脚本或智能体实时控制模拟器、读取运行数据。普通使用不需要它，默认也是关闭的；需要时见[调试接口手册](../debug/index.md)。
