# Ember 使用说明

Ember 是面向 NES 与小霸王、步步高等学习机应用开发者的模拟器。它不只运行 `.nes`、BIOS 和软盘程序，还提供运行控制、内存与状态检查、断点、单步、跟踪、截图和自动化调试接口，并与 `fcdev` 工具链配套使用。

项目代码、开发工具、学习机程序和文档都在 [GitHub 仓库](https://github.com/sungbindev/famiclone)。完整开发资料见 [fcdev 开发手册](../fcdev/index.md)、[调试接口手册](../debug/index.md) 和 [插件开发手册](../plugin/index.md)。

## 能运行什么

| 类型 | 做法 |
| --- | --- |
| 经典 FC | 直接打开 `.nes` 文件，主机按卡带的 mapper 自动装配 |
| 学习机整机 | 先添加该机型的 BIOS，再在“机器→选择机型”里点该机型就直接开机，不需要卡带 |

- Ember 不提供任何 BIOS 或游戏文件，需要自备。
- 学习机的 BIOS 文件不能当卡带打开，要走“机型与 BIOS”这条路，见[机型与 BIOS](machines.md)。
- 具体哪些机型已经可用，以“机器→选择机型”里没有置灰的为准。

## 调试功能

Ember 内置一个调试服务，可以用脚本、终端客户端、SDK 或 MCP 实时控制模拟器，并读取内存、状态和寄存器，设置断点、监视项与指令跟踪。普通使用不需要它，默认也是关闭的；需要时见[调试接口手册](../debug/index.md)。
