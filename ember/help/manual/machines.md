# 机型与 BIOS

## 选择机型

“机器→选择机型”是一个子菜单，列出几种学习机整机，选中的一项前面有对勾。选过机型后，这一项的名称直接显示已选机型的名字（如“小霸王 2000”），没选过（或最近打开的是卡带）时仍显示“选择机型”。

- 点一个机型就直接用它的 BIOS 开机，并记住这个机型。已经打对勾、而且正在运行（运行或暂停）的机型，再点它什么都不做；点别的机型会立即开机新选的机型。
- 选过的机型会被记住，下次启动沿用；之后点“机器”菜单里的“开机”（或 `F9`、运行面板里的“开机”按钮），直接开这个机型。
- 学习机整机要已添加 BIOS 才可选，没有 BIOS 的置灰，并注明“未添加 BIOS”。
- 还没有支持的机型置灰，注明“暂未支持”。

经典 FC 不在这个菜单里，用“文件→打开卡带”打开游戏即可。打开卡带成功后，已选机型会回到经典 FC（子菜单里没有对勾）。

## 添加、替换与移除 BIOS

“设置→机型与 BIOS”打开的对话框里管理，每个学习机机型一行，显示名称、BIOS 状态（未添加，或文件名与大小）和按钮。Ember 不自带 BIOS，也不会在电脑里自己查找：要用哪个学习机机型，就在这里给它添加 BIOS 文件；想换成别的 BIOS 才用“替换”。

- **添加 BIOS 文件**：点后选择 BIOS 文件（`.bin` 或 `.nes`），文件会复制到 Ember 自己的 BIOS 目录，开机时直接使用，原文件可以删除或移动。BIOS 文件是只含程序的纯文件，大小要等于这个机型的容量（小霸王 97 为 1024 KB，小霸王 2000 为 512 KB，步步高软驱一号为 128 KB，步步高 98 为 2048 KB）；带 NES 文件头的 `.nes` 文件也能用。
- **替换**：选新的文件，复制成功后才删除旧的。
- **移除**：删除 BIOS 目录里的文件，不影响你的原文件，也不会再询问。
- **打开 BIOS 目录**：对话框顶部说明下面的“打开 BIOS 目录”链接，点后用系统的文件管理器打开 Ember 保存 BIOS 的目录，可以直接查看里面的文件。
- 经典 FC 不需要 BIOS，不在这个列表里。
- 还没有支持的机型整行置灰，状态写“暂未支持”。

操作结果和文件不符合机型的错误都以通知显示。BIOS 变化后，“机器→选择机型”会立即更新。

## 开机

开机有三种入口，效果相同：运行面板里的“开机”按钮、“机器”菜单里的“开机”、`F9`。

- **学习机整机**：已添加 BIOS 就能开机，不需要卡带。当前运行的是别的主机时，也会按已选机型重新开机。没有 BIOS 时按钮置灰。
- **小霸王 97**：开机后几秒钟出现小霸王开机画面，画面停着循环变色时按任意键，先显示“正在检测”，几秒后进入主菜单（不按键大约一分钟后也会自己进入）；主菜单用方向键选择软件，回车进入：F-BASIC 进入 BASIC 的 `]` 提示符，DOS 可以读写软驱里的软盘（先在“设备”面板载入镜像）。小霸王 97 没有鼠标，打印机还不支持。
- **经典 FC**：要先用“文件→打开卡带”选一个 `.nes` 文件，选好后直接开机。没有卡带时按钮置灰；断电后按钮可点，直接上电，卡带还在。

学习机整机开机后系统栏会显示主机型号；经典 FC 不显示主机型号，只显示卡带名和 mapper 插件。

## 运行面板

点系统栏左侧的运行按钮展开，只有一行内容：

| 内容 | 说明 |
| --- | --- |
| 开机或断电 | 通电时是“断电”，未通电时是“开机” |
| 暂停或继续 | 没有开机时置灰 |
| 软复位 | 只发复位信号，不改变电源、卡带与盘片 |
| 硬复位 | 相当于断电再上电 |
| 静音与音量 | 静音按钮、音量滑块与数值 |

画面上会显示当前状态：没有开机显示“未开机”，并提示怎么开机；断电显示“已断电”；暂停显示“已暂停”。
