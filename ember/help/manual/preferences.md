# 首选项

点“设置→首选项”（`Ctrl+,`）打开。左侧是分组，右侧是设置项：名称与说明在左，控件在右。

- 改动立即生效并保存，没有“确定”按钮。
- 取值与出厂默认不同时，设置项右侧出现“恢复默认”。
- 文字或数字输入框按回车或失去焦点时提交；取值不合格时输入框标红并说明原因，不会保存。
- 保存失败时用通知给出原因，控件保持原值。

## 分组与设置项

| 分组 | 设置项 | 说明 | 出厂默认 |
| --- | --- | --- | --- |
| 外观 | 主题 | 深色、浅色、跟随系统 | 跟随系统 |
| 画面 | 画面比例 | 4:3、8:7 | 8:7 |
| | 缩放方式 | 适应窗口、整数倍 | 适应窗口 |
| | 显示全部 240 行 | 关闭时上下各裁掉 8 行 | 开 |
| | 开机与复位后隐藏最初的画面 | 开启后开机和复位后最初约 0.1 秒显示为黑色 | 关 |
| 更新 | 启动时检查更新 | 每次启动后自动检查一次新版本，有新版本时自动下载，见[窗口、菜单与快捷键](window.md) | 开 |
| 应用 | 允许同时运行多个实例 | 开启后可以同时打开多个 Ember，下次启动时生效，见[常见问题](faq.md) | 关 |
| | 用户数据目录 | 设置、BIOS、日志等保存的位置，可以切换，见下面的说明 | 软件所在目录旁有 `ember-data` 时用它，否则用应用数据目录 |
| 声音 | 缓冲大小 | 低延迟、标准、稳定 | 标准 |
| | 启动时静音 | 每次启动是否静音 | 关 |
| 输入 | 点击画面捕获鼠标 | 只对带鼠标的机型起作用 | 开 |
| | 接入 Family BASIC 键盘 | 给经典 FC 接上 Family BASIC 键盘 | 关 |
| 调试服务 | 启用 | 是否开启调试服务 | 关 |
| | 端口 | 调试服务的监听端口，1024 到 65535 | 5688 |
| | 令牌 | 连接调试服务用的令牌，可以改写，清空后重新生成 | 自动生成 |
| | 调试输出目录 | 调试服务写出文件（截图、跟踪记录等）的目录，留空表示用用户数据目录下的 `debug-output` | 空 |
| 打印机 | 图片保存位置 | 打印机输出的 PNG 保存到哪里；留空表示保存到用户数据目录下的 `printer-output` | 空 |

- “打印机”分组里的“选择”按钮会弹出选择文件夹窗口，选定后立即保存；也可以直接输入路径。
- “应用”分组里的“用户数据目录”：Ember 把设置、BIOS、日志和安装的插件都放在用户数据目录里。软件所在目录旁有 `ember-data` 文件夹时用它（整个文件夹拷走就带走了全部数据，适合放在 U 盘里），否则用当前用户的应用数据目录（`%APPDATA%\Ember`）。点路径用文件管理器打开；点“改用软件所在目录”或“改用用户数据目录”可以切换，Ember 会先关闭，把数据复制到新位置，核对无误后自动重新启动，并删除原位置的数据。新位置已有数据、软件所在目录不能写入，或这次启动用 `--user-data-dir` 指定了目录时不能切换。
- 声音的音量不在首选项里，在运行面板里调整，见[画面与声音](display-sound.md)。
- 手柄的键位不在首选项里，在“设置→手柄设置”里设置，见[键盘、手柄与鼠标](input.md)。
- 学习机的 BIOS 也不在首选项里，在“设置→机型与 BIOS”里添加、替换、移除，见[机型与 BIOS](machines.md)。

## 调试服务

“调试服务”分组控制模拟器内置的调试服务。默认关闭，开启后只监听本机 `127.0.0.1`。服务开启时，系统栏右侧会显示绿色的“调试模式”，点它可以打开首选项；鼠标停在上面能看到端口和连接数。具体用法见[调试接口手册](../debug/index.md)。
