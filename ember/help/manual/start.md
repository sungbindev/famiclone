# 快速开始

## 玩红白机游戏

1. 点“文件→打开卡带”（`Ctrl+O`），选择 `.nes` 文件；也可以把文件直接拖进窗口。
2. 打开后立即开机并开始运行。
3. 用键盘玩：默认的方向键是 ↑ ↓ ← →，Z 是 B，X 是 A，C、V 是连发 B、连发 A，右 Shift 是选择，回车是开始。键位可以在“设置→手柄设置”里改，见[键盘、手柄与鼠标](input.md)。

最近打开过的卡带在“文件→最近打开”里，最多保留 10 个。

## 使用学习机

1. 小霸王 97、小霸王 2000、步步高软驱一号、步步高 98 的 BIOS 已随 Ember 自带，不用添加；想换别的 BIOS，点“设置→首选项”，在“机型与 BIOS”分组里替换。
2. 点“文件→选择机型”，选中这个机型。
3. 点系统栏左侧的运行按钮展开“运行”面板，按“开机”；也可以用“机器”菜单里的“开机”或 `F9`。
4. 要载入软盘，展开系统栏左侧的设备按钮，在软驱一行点“载入镜像”，也可以把镜像文件拖进窗口。

没有 BIOS 的机型（比如还没有支持的机型）在“选择机型”里是置灰的，旁边写着“未添加 BIOS，请在设置里添加”或“暂未支持”。

## 常用操作

| 要做的事 | 做法 |
| --- | --- |
| 暂停、继续 | `F8` |
| 软复位 | `F7` |
| 硬复位 | `Ctrl+F7` |
| 开机或断电 | `F9` |
| 全屏 | `F11` |
| 静音 | “机器”菜单里的“静音”，或运行面板里的静音按钮 |

在 Windows 上，点击画面后键盘会整个交给模拟的机器，包括 Esc 与 F 键，这时外壳的快捷键不生效。点一下画面以外的地方，快捷键就恢复了。详见[窗口、菜单与快捷键](window.md)。
