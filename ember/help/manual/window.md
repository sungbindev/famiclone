# 窗口、菜单与快捷键

## 窗口的组成

- **标题栏**：应用图标、名称和菜单，右侧是系统的窗口按钮；有新版本可以安装时，窗口按钮左边会出现一个蓝色的“更新”按钮。
- **显示区**：模拟器的运行画面，居中显示，周围是底色。
- **底部面板**：平时收起，点系统栏左侧的按钮才展开，里面有“运行”和“设备”两个面板。
- **系统栏**：窗口最下面一条。左侧是运行按钮、设备按钮、主机型号、已载入的软盘名、卡带名和 mapper 插件；右侧是“调试模式”提示（调试服务开启时才有）和通知按钮。

没有信息的项目不显示。比如没有开机时看不到卡带和 mapper 插件，整机机型开机后只显示主机型号，经典 FC 不显示主机型号。

### 底部面板

- 点系统栏左侧的按钮展开对应的面板，再点同一个按钮收起；点另一个按钮切换面板。面板标题行右上角的“关闭”也能收起。
- 运行与设备两个面板的标题栏有“自动收缩”开关，默认开着，开着时点面板以外的地方会自动收起面板，在面板里操作不会；想让面板一直展开，点一下开关关掉它。两个面板各自记住自己的开关。
- 面板的高度由内容决定，刚好装下面板里的内容，不能拖动；运行面板和设备面板各有各的高度。
- 展开面板时窗口大小不变，运行画面按剩下的空间等比缩放。

### 运行按钮的含义

系统栏里运行按钮的图标会显示当前状态：运行中是填满绿色的三角形，暂停时是暂停图标，没有开机或已断电是普通三角形。把鼠标停在上面能看到文字说明。

### 通知

操作结果和错误提示以通知的形式出现在窗口右下角。点系统栏右侧的通知按钮可以查看。

## 菜单

| 菜单 | 菜单项 |
| --- | --- |
| 文件 | 打开卡带、最近打开、关闭卡带、退出 |
| 机器 | 选择机型、开机或断电、暂停或继续、软复位、硬复位、静音、接入 Family BASIC 键盘 |
| 设置 | 手柄设置、机型与 ROM、mapper 插件、首选项、全屏、窗口始终置顶 |
| 帮助 | 帮助文档、更新记录、打开日志目录、检查更新、关于 Ember |

- “机器”菜单里的“静音”和“接入 Family BASIC 键盘”是勾选项；“设置”菜单里的“全屏”（快捷键 `F11`，全屏时只显示画面，再按 `F11` 回到窗口）和“窗口始终置顶”也是勾选项，“窗口始终置顶”只对当前这次运行有效，下次启动恢复为不置顶。
- “关闭卡带”只对卡带有效；用 ROM 开机的整机机型不涉及卡带。
- 菜单项置灰表示现在不能用，比如没有开机时暂停与复位都是灰的。
- “关于 Ember”里显示应用信息（右上角是版本、核心版本与编译时间）、许可证和项目地址。项目地址直接指向 GitHub 上的 `famiclone/ember` 子目录，点链接会用系统浏览器打开。
- 对话框的标题栏左边是 Ember 的图标，右边和主窗口一样有最小化、最大化和关闭三个按钮；在对话框里点最小化会把 Ember 整个最小化，从任务栏还原后对话框一起回来。对话框打开时不聚焦到某个按钮或链接上，`Esc` 仍然可以关闭它。
- “帮助文档”和“更新记录”用系统默认浏览器打开；Windows 7 上的默认浏览器如果太旧（比如 Internet Explorer 11），请先安装较新的浏览器。

## 检查更新

Ember 可以自己升级（只支持 Windows，只替换 `Ember.exe` 这一个文件）：

- 首选项“更新”分组里的“启动时检查更新”打开时（默认打开），每次启动后 Ember 会自动检查一次新版本；有新版本时在后台下载，下载好后弹出通知，没有新版本或检查失败时不打扰。
- 想马上检查，点“帮助→检查更新”：会通知“正在检查更新…”，之后告诉你已是最新版本、发现新版本，或检查失败的原因。检查和下载期间这一项是灰的。
- 新版本下载好后，这一项变成“重启并安装更新（版本号）”，标题栏右侧（系统窗口按钮左边）同时出现蓝色的“更新”按钮；点其中任何一个，Ember 会先正常退出，再自动重新启动并使用新版本。不点也可以，下次启动就是新版本。
- 放在不能写入的文件夹里（比如 `Program Files`）时不支持升级，点“检查更新”会提示“当前运行方式不支持检查更新。”；把 `Ember.exe` 放到可以写入的文件夹里即可。用启动参数 `--debug-port` 启动的调试实例（如 fcdev 扩展的“调试运行”）也不支持升级。
- 升级后第一次启动新版本时，Ember 会自动打开帮助文档里的[更新记录](changelog.md)，告诉你这个版本有什么变化，每个版本只打开一次；以后想再看，点“帮助→更新记录”。第一次使用时不会打开。

## 默认快捷键

| 操作 | 快捷键 |
| --- | --- |
| 打开卡带 | `Ctrl+O` |
| 开机或断电 | `F9` |
| 暂停或继续 | `F8` |
| 软复位 | `F7` |
| 硬复位 | `Ctrl+F7` |
| 全屏 | `F11` |
| 首选项 | `Ctrl+,` |

- 快捷键暂时不能自己修改。
- 焦点在文本输入框里时，不带 `Ctrl` 的快捷键（`F7`、`F8`、`F9`、`F11`）不触发，带 `Ctrl` 的照常触发。
- 命令置灰时，对应的快捷键也不起作用。

## 键盘跟着画面走

主窗口里点过任何地方后，焦点都会回到画面，不用专门点进画面里，键盘就能继续输入；打开菜单期间不抢焦点，菜单关闭后再还给画面。

玩经典 FC 游戏时，Ember 不独占键盘：`F1` 到 `F24`、`Tab`、`Esc` 和带 `Ctrl`、`Alt`、`Meta` 的组合键不会送给游戏，留给 Ember 的快捷键和菜单（`Alt+F` 等）；其余按键照常送给游戏。

在 Windows 上，运行学习机（包括金字塔学习机与裕兴学习机），或者接入了 Family BASIC 键盘时，画面获得焦点期间 Ember 会独占键盘：所有物理按键，包括 Esc、Tab、其余 F 键以及带 Ctrl、Alt 的组合，都只交给模拟的机器，Ember 收不到，所以这时 `F7`、`F8` 等快捷键和 `Alt` 加字母的菜单键都不生效，要用鼠标操作菜单和面板按钮；只有 `F9`、`F10`、`F11`、`F12` 始终留给 Ember（学习机的键盘没有这几个键），所以 `F9` 开机与断电、`F11` 全屏任何时候都有效。画面右下角的提示框会提醒“键盘已被机器独占，快捷键无效”。独占在这些情况下结束：

- 切换到别的窗口（如 `Alt+Tab`）；
- 关闭窗口。

`Win` 键、`Ctrl+Alt+Del` 与 `Alt+Tab` 仍由系统处理。其他系统上没有独占，F1 到 F24、Tab、Esc 和带 `Ctrl`、`Alt`、`Meta` 的组合键不会送给机器。

## 全屏

按 `F11` 进入或退出全屏，全屏时只显示画面。所有机型的键盘最高只到 `F8`，`F9` 到 `F12` 始终留给 Ember，所以键盘被机器独占时 `F11` 也有效。

全屏时画面默认保持比例，四周留黑边；想让画面铺满整个显示器，在“设置→首选项”的“画面”分组里把“全屏时的画面”改成“拉伸铺满”，见[画面与声音](display-sound.md)。
