# 步步高系统接口说明

BIOS 调用、DOS 调用与文件调用的约定、已核对的行为，以及与使用手册的差异。符号与功能号见 [symbols-reference.md](symbols-reference.md)（由 `src/include` 下的符号文件生成），反汇编工程在 `../../disasm/`。

## 调用约定

| 入口 | 地址 | 参数 | 返回 |
| --- | --- | --- | --- |
| BIOS 调用 | `$5800` | A 为功能号，X、Y 视功能而定 | 视功能而定 |
| 文件调用 | `$5803` | X 为文件通道块地址高字节，Y 为低字节，A 不用设置 | A 为出错码，0 成功；C=1 出错 |
| 外设调用 | `$5809` | X 为子功能 | 视子功能而定 |
| DOS 调用 | `$580C` | A 为功能号，X、Y 视功能而定 | C=0 成功；C=1 出错且 A 为出错码 |

- 四个入口都是 `JSR` 调用。`$5803` 与 `$580C` 指向 BBGDOS.SYS 初始化时装入低端内存的桩代码：桩代码先把 `$8000-$BFFF` 窗口切到 DOS 页，调用 DOS，返回前再切回调用者的页，所以调用者的 A 在文件调用里不起作用。
- 文件通道块与缓冲区的页号由调用者给出：块在 `$8000-$BFFF` 窗口里时，DOS 经 BIOS 功能 17 把块复制到低端内存再处理，返回时写回。

## BIOS 版本

`ember/roms/bbg1_bios.bin` 是 BIOS 1.0（功能 `$FF` 返回 A=`$40`、X=`$61`、Y=1）。它的分发表只有 43 项，加上功能 60、63-65、255；功能 43-59、61、62、66 以上被直接忽略，调用后 A、X、Y 不变。因此在 `bbg1` 上调用手册里的 BiosSetPalette（43）没有效果。`bbg98_bios.bin` 的向量与分发代码位置都不同，没有分析。

## 文件查找（FILE_FIRST、FILE_NEXT）

由 `BBGDOS.SYS` 的处理代码读出，并已用 [apps/bbg/filetest](../../../../apps/bbg/filetest/README.md) 在 Ember（`bbg1`）里实测：列出 `BBGDOS.IMG` 根目录的 3 个文件，属性、文件名与大小都正确，结束时 A=`$12`。

- 通道块 `FH_COMMAND` 为 6（FILE_FIRST）或 22（FILE_PATH_FIRST）；`FH_NAME` 起的 11 字节是查找用的文件名，经文件名转换后存放，`?` 为通配；缓冲区页与地址（`FH_PAGE`、`FH_BUFFER`）指向调用者里的 11 字节文件名，实测用 11 个 `?` 列出全部文件，DOS 逐字符取出并检查后写入 `FH_NAME`；字符检查规则（如小写、点、空格的处理）未确认。
- FILE_FIRST 先把 `FH_ATTRIBUTE` 置为 `$FF`，并把 `FH_BUFFER` 改为指向通道块里偏移 `$17` 的结果区，因此通道块至少要 48 字节。
- 找到文件后，结果区里依次是属性（`$17`）、时间（`$18`）、日期（`$1A`）、大小（`$1C`）、11 字节文件名（`$20`）。
- FILE_NEXT 沿用通道块里的查找状态，找不到更多文件时 A=`$12`（ERR_SEARCH_ENDING）。
- FILE_FIRST 与 FILE_PATH_FIRST 是两个不同的处理例程：后者把属性掩码取反后调用同一个查找例程，并在 `FH_SEARCH_STATE`（`$2B`）起记下页号与当前目录簇。

## 与手册的差异

| 项目 | 手册 | 反汇编结果 |
| --- | --- | --- |
| DOS 功能 16 | 未列 | 存在，返回 A=3、X=0（版本 3.0） |
| 文件功能 24 | 未列 | 存在，按 `$16` 的值改写目录项属性 |
| DOS 功能 12 与 13 的编号 | 列表里 12、13 重复 | 12 是 DosFileNameAccs，13 是 DosGetSetInitScrn，14 是 DosCheckKeyBoard，15 是 DosRunPathProgram |
| 文件功能 20、21、23 | 各自独立 | 与 1、8、10 共用处理例程，区别在功能标志（路径解析） |
| BIOS 功能 43-59 等 | 列出 | bbg1 的 BIOS 1.0 不实现 |
| BIOS 日期时间 | 功能 63-65 | BIOS 1.0 只读写 `$5FE6-$5FEA` 里的变量，没有读实时钟，开机默认日期由 DOS 在启动时询问 |
