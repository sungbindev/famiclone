# 步步高系统接口说明

BIOS 调用、DOS 调用与文件调用的约定、已核对的行为，以及与使用手册的差异。符号与功能号见 [symbols-reference.md](symbols-reference.md)（由 `src/include` 下的符号文件生成），反汇编工程在 `../../disasm/`。

## 调用约定

| 入口 | 地址 | 参数 | 返回 |
| --- | --- | --- | --- |
| BIOS 调用 | `$5800` | A 为功能号，X、Y 视功能而定 | 视功能而定 |
| 文件调用 | `$5803` | X 为文件通道块地址高字节，Y 为低字节，A 不用设置 | A 为出错码，0 成功；C=1 出错 |
| 外设调用 | `$5809` | X 为子功能 | 视子功能而定 |
| DOS 调用 | `$580C` | A 为功能号，X、Y 视功能而定 | C=0 成功；C=1 出错且 A 为出错码 |

- 四个入口都是 `JSR` 调用。`$5803` 与 `$580C` 指向 BBGDOS.SYS 初始化时装入低端内存的桩代码：桩代码先把 `$8000-$BFFF` 窗口切到 DOS 页，调用 DOS，返回前再切回调用者的页，所以调用者的 A 在文件调用里不起作用。
- 文件通道块与缓冲区的页号由调用者给出：块在 `$8000-$BFFF` 窗口里时，DOS 经 BIOS 功能 17 把块复制到低端内存再处理，返回时写回。

## BIOS 版本

`ember/roms/bbg1_bios.rom` 是 BIOS 1.0（功能 `$FF` 返回 A=`$40`、X=`$61`、Y=1）。它的分发表只有 43 项，加上功能 60、63-65、255；功能 43-59、61、62、66 以上被直接忽略，调用后 A、X、Y 不变。因此在 `bbg1` 上调用手册里的 BiosSetPalette（43）没有效果。`bbg98_bios.rom` 的向量与分发代码位置都不同，没有分析。

## 文件查找（FILE_FIRST、FILE_NEXT）

由 `BBGDOS.SYS` 的处理代码读出，并已用 [apps/bbg/filetest](../../../../apps/bbg/filetest/README.md) 在 Ember（`bbg1`）里实测：列出 `BBGDOS.IMG` 根目录的 3 个文件，属性、文件名与大小都正确，结束时 A=`$12`。

- 通道块 `FH_COMMAND` 为 6（FILE_FIRST）或 22（FILE_PATH_FIRST）；`FH_NAME` 起的 11 字节是查找用的文件名，经文件名转换后存放，`?` 为通配；缓冲区页与地址（`FH_PAGE`、`FH_BUFFER`）指向调用者里的 11 字节文件名，实测用 11 个 `?` 列出全部文件，DOS 逐字符取出并检查后写入 `FH_NAME`；字符检查规则（如小写、点、空格的处理）未确认。
- FILE_FIRST 先把 `FH_ATTRIBUTE` 置为 `$FF`，并把 `FH_BUFFER` 改为指向通道块里偏移 `$17` 的结果区，因此通道块至少要 48 字节。
- 找到文件后，结果区里依次是属性（`$17`）、时间（`$18`）、日期（`$1A`）、大小（`$1C`）、11 字节文件名（`$20`）。
- FILE_NEXT 沿用通道块里的查找状态，找不到更多文件时 A=`$12`（ERR_SEARCH_ENDING）。
- FILE_FIRST 与 FILE_PATH_FIRST 是两个不同的处理例程：后者把属性掩码取反后调用同一个查找例程，并在 `FH_SEARCH_STATE`（`$2B`）起记下页号与当前目录簇。

## 文件调用的字段与行为

全部由 Ember 里的库测试程序（`vscode/test/fixtures/bbg/file.s`）核对，字段见 `dos-calls.inc` 的 `FH_*`：

- 打开（`FILE_OPEN`、`FILE_PATH_OPEN`）：出口偏移 2 为属性、3-4 为日期、5-6 为时间、`$0D` 起 4 字节为长度，读写位置为 0；不存在为 `ERR_FILE_NOT_EXIST`。
- 读（`FILE_READ`）、写（`FILE_WRITE`）：从读写位置（偏移 7，4 字节）起，可跨扇区；到文件末尾时 `FH_BYTES` 是实际字节数；写时 `FH_BYTES` 为 0 表示在读写位置截断；出口 `FH_BUFFER` 是缓冲区结束地址。不检查只读属性。
- 关闭（`FILE_CLOSE`）把长度、日期、时间写回目录项；`FILE_ATTRIBUTE` 设置属性、日期、时间；`FILE_RENAME` 给已打开的文件改名。
- 建立（`FILE_CREATE`）后文件已打开、长度为 0；删除（`FILE_DELETE`）不检查只读属性。
- 驱动器（`FILE_DRIVE`）读取返回默认盘号 1（A 盘）与逻辑驱动器数 2；`FILE_DRIVE_SIZE` 返回每簇扇区数、每扇区字节数、空闲簇数与总簇数。
- 目录：`FILE_MAKE_DIR`、`FILE_CHANGE_DIR`（含“..”回上级）、`FILE_REMOVE_DIR`；`FILE_GET_DIR` 返回 DOS 页里的路径串地址；路径查找 `FILE_PATH_FIRST` 的通配符是 `*` 与 `?`。
- 绝对扇区（`FILE_READ_ABS`、`FILE_WRITE_ABS`）：位置是扇区号（从 0 起），长度是扇区数。

## DOS 调用的实测

- `DOS_DISPLAY_STRING`：`X` 是地址高字节、`Y` 是低字节，与手册文字相反。
- `DOS_RUN_PROGRAM`：`$FF` 为盘号，`X:Y`（`X` 高）指向 11 字节文件名，扩展名必须是 `CMD`、`EXC` 或 `GAM`（DOS 用它判断程序类型，不会自己依次试）；`DOS_RUN_PATH_PROGRAM` 用以 0 结尾的路径；成功时 `C=0`、`A` 是被运行程序的退出码；`$0100` 起的参数交给被运行的程序。
- `DOS_FILE_NAME_ACCESS`：把 `D:FFFFFFFF.XXX` 转成 11 字节的内部格式，结果写回原地址，`A` 返回盘号。
- `DOS_READ_KB_CLEAR`：先清键盘缓冲区，再执行 `$FF` 指定的键盘功能。

## 程序文件与启动配置（来自 `BBGDOS.SYS` 反汇编，未全部实测）

- 程序类型只看扩展名：`CMD`、`EXC`、`GAM`；`CMD` 走 `.CMD` 装入，`EXC` 与 `GAM` 走同一个段表装入（`.EXC` 装入程序），两者在 DOS 里没有别的区别。
- `.CMD`：开头 2 字节是装入地址（低、高），也是入口地址；正文被读进 DOS 分配的空闲页的该地址处（超过 `$C000` 的部分的处理未确认），随后切到该页并跳到入口。
- `.EXC`：开头是 `$1A` 字节的头，被读到 DOS 工作区 `$043D` 起；头里依次有标识“MY”（偏移 0-1）、段数（偏移 6）、标志（偏移 `$0A`）、起始页（偏移 `$0C`）、类型（偏移 `$0D`，0、1、3 有效）、所需页数（偏移 `$10`）、所需资源（偏移 `$11`）、入口地址减 1（偏移 `$14`-`$15`）、段表位置（偏移 `$18`-`$19`）；段表每项 4 字节：3 字节文件偏移加 1 字节段类型，DOS 认识的类型有 `$02`、`$04`、`$05`、`$06`、`$0B`、`$0C`、`$0D`、`$0E`、`$10`（各类型的含义见 `bbgdos` 工程 `screen-pages` 模块里 `exe_load_type_` 开头的例程说明，其中经 BIOS 功能 `$25`、`$13` 的部分含义未确认）。头无效返回 `$0B`，显示方式与程序不符 `$28`，页数不够 `$08`，资源不足 `$29`，读文件失败 `$1E`。
- 程序嵌套运行：运行栈 `run_stack` 共 40 字节、每层 5 字节，代码上限 8 层，超过时返回 `Y=$2A`（手册写 4 层，未实测）；运行失败时出错码在 `Y` 里，成功时 `A` 为程序的退出码。
- 启动配置：DOS 初始化后读系统盘的 `CONFIG.SYS`，只认两条命令：`DEVICE=` 与 `SHELL=`（后接 `[盘符:]程序名 参数`）；`DEVICE` 的程序扩展名必须是 `CMD`，每行最长 `$4F` 字符，出错显示“Error in CONFIG.SYS line 行号”。没有 `CONFIG.SYS` 或没有 `SHELL=` 时运行 `\COMMAND.CMD`；找不到时提示“Missing DOS shell COMMAND.CMD”并停机。

## 与手册的差异

| 项目 | 手册 | 反汇编结果 |
| --- | --- | --- |
| DOS 功能 16 | 未列 | 存在，返回 A=3、X=0（版本 3.0） |
| DOS 功能 4 的参数 | X 低地址、Y 高地址 | X 高地址、Y 低地址（`bbg_dos_put_string` 已验证） |
| DOS 功能 5 的文件名 | 文件名地址 | X:Y 指向 11 字节内部格式的名字，扩展名必须是 CMD、EXC、GAM |
| 文件调用只读属性 | 未说明 | 写与删除都不检查只读属性 |
| 文件功能 24 | 未列 | 存在，按 `$16` 的值改写目录项属性 |
| DOS 功能 12 与 13 的编号 | 列表里 12、13 重复 | 12 是 DosFileNameAccs，13 是 DosGetSetInitScrn，14 是 DosCheckKeyBoard，15 是 DosRunPathProgram |
| 文件功能 20、21、23 | 各自独立 | 与 1、8、10 共用处理例程，区别在功能标志（路径解析） |
| BIOS 功能 43-59 等 | 列出 | bbg1 的 BIOS 1.0 不实现 |
| BIOS 日期时间 | 功能 63-65 | BIOS 1.0 只读写 `$5FE6-$5FEA` 里的变量，没有读实时钟，开机默认日期由 DOS 在启动时询问 |
