# 步步高工程：计划与进度

## 目标

在小霸王 SB2000 上运行步步高（BBK）的 BIOS 与 BBGDOS：改写步步高 BIOS 源码的硬件层，让它在 SB2000 的 FC 兼容模式（标准 PPU）下工作，由 SB-DOS 里的 EXE 装载并接管机器。

## 原厂源码的完整性

资料在 `reference/docs/BBKDOS源代码/`，共 3 份汇编源码与 3 个二进制：

| 文件 | 类型 | 内容 | 状态 |
| --- | --- | --- | --- |
| `Bios.asm` | 源码，7412 行 | ROM BIOS，位于最后一页（`$C000-$FFFF`）：启动、中断、分页、软驱、键盘、基本显示、BIOS 调用 | 完整；汇编后 16118 字节，除缺符号文件外自成一体 |
| `Command.asm` | 源码，5337 行 | 命令解释器（中文版），不含硬件寄存器访问 | 完整，只调用 BIOS 与 DOS |
| `Smcdos.asm` | 源码，5843 行 | 中文显示驱动，直接写 PPU 与分页寄存器 | 完整 |
| `Bbgdos.sys` | 二进制，14822 字节 | BBGDOS 内核（英文版），起始地址 `$7C00` | **没有源码**：文件系统、内存页管理、DOS 调用（`$580C`）、扩展 BIOS 显示功能都在这里 |
| `Command.sys` | 二进制，15614 字节 | 命令解释器（英文版） | 与 `Command.asm` 不是同一版本 |
| `Smdos.sys` | 二进制，16647 字节 | 另一个内核变体，起始地址 `$7C00` | 没有源码 |

缺失的 `tvdef.asm`：三份源码都 `include tvdef.asm`，里面是系统调用入口、BIOS 与 DOS 功能号、出错码、文件通道结构和固定地址，以及宏 `orgrun`、`orgreal`。使用手册里有功能号与出错码，源码注释里有固定地址，所以能还原；已还原到 [../src/include/tvdef.asm](../src/include/tvdef.asm)，三份源码汇编后未定义符号为 0。

另外 `bbk_bios10.nes`（128KB）的前 7 页从字节内容看是字库点阵数据，第 8 页才是 `Bios.asm` 对应的代码；前 7 页没有逐页核对。

## 已查明的结论

- 汇编语法与常见 6502 汇编器的差别：表达式没有优先级，从左到右计算；立即数前缀 `<` 取高字节、`>` 取低字节，与常规相反（源码里 RTI 返回地址的压栈顺序可以印证）；`^` 取相对页号；`orgrun` 改运行地址而字节顺序存放。
- `Bios.asm` 与 `bbk_bios10.nes` 不是同一次构建，只有 605 字节相同；但把不含绝对地址的指令按 6 条一组去查，274 组里有 239 组（87%）出现在 BIOS 1.0 ROM 里，在 BIOS 2.0 ROM 里是 192 组（70%）。这说明汇编器的编码正确，且三者是同一份代码的不同版本。
- `Command.sys` 里是英文提示串，与中文版 `Command.asm` 只有 7/184 组相同，`Smcdos.asm` 与两个 `.sys` 基本不同。所以不能用这三个 `.sys` 文件验证 `Command.asm`、`Smcdos.asm`。
- 推测值：`DosGetDOSVersion` 取 16、`StackTooDepth` 取 `$2B`，手册与源码都没有给出，需要实机或模拟器核对。

## 步步高与 SB2000 的硬件差异

依据模拟器源码（`virtuanes/VirtuaNES/NES/Mapper/Mapper171.cpp`、`MapperSB2K.cpp`），未在真机上验证：

| 部分 | 步步高 | SB2000 |
| --- | --- | --- |
| 分页 | `$FF04/$FF14/$FF1C/$FF24/$FF2C`，ROM 与 RAM 靠 `$FF01` 位 3 切换 | `$4040-$4043` 四个窗口；FC 模式下是 MMC3 形式，窗口号在 `$5006` |
| 软驱 | 765 控制器在 `$FF80-$FFB8` | 同一种控制器在 `$4100`、`$4200-$4207`，读写方式相同 |
| 语音 | `$FF10/$FF18` | `$4302` |
| 显示 | 标准 PPU，1K 一页的 CHR-RAM，扫描线分屏 | DOS 模式是 6576 专用 PPU；FC 模式是标准 PPU |
| 键盘鼠标、中断 | 手柄口 `$4016/$4017`，扫描线中断 `$FF02/$FF06` | `$4020-$4026`、`$4032/$4033`；FC 模式有 MMC3 扫描线中断 |

## 待验证问题

阶段 4 要回答，决定阶段 5 的做法：

1. FC 模式下 `$8000-$FFFF` 的写入在模拟器里全是 MMC3 寄存器写，BIOS 与 DOS 要往分页 RAM 读程序，需要改用 `$6000-$7FFF`、临时切回 6576 模式，或在进入前用 DMA 预置。
2. MMC3 的 R6/R7 只取低 4 位，`$C000-$FFFF` 固定为窗口末尾，换窗口一起变；步步高的页号模型要改成“窗口号加窗口内 8K 页”，换页例程放在常驻的 `$6000-$60FF`。
3. 模拟器在 `$4301` 里去掉了扩展手柄，FC 模式下键盘输入被丢弃，真机的键盘在 FC 模式下是否可用没有证据。
4. 步步高的名表镜像有 4 种，MMC3 的 `$A000` 只有横竖两种，要查 `Bios.asm` 实际用了哪几种。
