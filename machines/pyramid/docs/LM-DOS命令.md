# 金字塔 LM-DOS 命令

金字塔 PEC-9588 的磁盘操作系统 LM-DOS 3.31 共有 37 个命令。本文给出每个命令的格式与作用，并标明依据是模拟器实测还是反汇编代码。

## 概述

- LM-DOS 固化在 ROM 的块 0（`$8000-$BFFF`），开机画面按任意键进入主菜单，按 `6` 进入磁盘操作系统。
- 提示符是 `]`，环境是带磁盘功能的 Applesoft 风格 BASIC：`PRINT 7` 显示 `7`（实测）。
- 命令的结构与苹果 DOS 3.3 相同：命令名表、参数规则表、选项解析、文件管理器、读写盘程序都能一一对应。空盘是 `blank.dsk`，143360 字节全零，需先 `INIT`。
- 在 BASIC 程序里，先输出命令前缀 Ctrl-D（`$84`，存放在 `$6521`）再输出命令，即可执行 DOS 命令（代码）；直接输入时不需要前缀（实测）。

## 依据说明

| 标注 | 含义 |
| --- | --- |
| 实测 | 在 Ember 里载入 `pec9588` 与 `.dsk`，输入命令并观察到结果 |
| 代码 | 只读了 `bank00_system` 里的处理程序与参数表，没有运行 |

## 命令格式

```text
命令名 [文件名] [,选项 [,选项 ...]]
```

- 文件名最长 30 个字符。`RENAME` 在逗号后再写一个新文件名。
- 选项由一个字母和一个数字组成，数字可写十进制，也可写 `$` 加十六进制，如 `A$6000`。
- 命令名后不带文件名而参数规则又要求文件名时，DOS 不处理这一行，交给 BASIC，BASIC 报 `?SYNTAX ERROR`（`LMDIR` 不带文件名，实测）。

### 选项

| 选项 | 含义 | 取值范围 |
| --- | --- | --- |
| `V` | 卷号，0 表示不限卷 | 0-254 |
| `D` | 驱动器 | 1-2 |
| `S` | 槽号 | 1 |
| `L` | 长度（`BSAVE`）或记录长度（`OPEN`） | 1-65535 |
| `R` | 记录号（`READ`、`WRITE`、`POSITION`、`EXEC`）或扇区号（`LMREAD`、`LMWRITE`、`LMDUMP`） | 0-65535；用作扇区号时 0-13 |
| `B` | 字节偏移（`READ`、`WRITE`）或磁道号（`LMREAD`、`LMWRITE`、`LMDUMP`） | 0-65535；用作磁道号时 0-39 |
| `A` | 内存地址（`BSAVE`、`BLOAD`、`BRUN`、`LMREAD`、`LMWRITE`）或要转换的数（`LMHEX`、`LMDEC`） | 0-65535 |
| `C`、`I`、`O` | 只用于 `MON`、`NOMON` | - |

取值范围来自选项范围表 `$A8A1`，超出范围报 `RANGE ERROR`（代码）。

## 命令一览

`READ`、`WRITE`、`POSITION`、`OPEN`、`APPEND` 的参数规则带“不得直接执行”位，在直接输入状态报 `NOT DIRECT COMMAND`（代码），要写在 BASIC 程序里用。

### 磁盘与目录

| 命令 | 格式 | 作用 | 依据 |
| --- | --- | --- | --- |
| `INIT` | `INIT[,Vn][,Dn][,Sn]` | 格式化整张盘并建立空目录。不带文件名；先问 `Are you sure?(Y/N)`，按 `Y` 才执行；不写 `V` 时卷号为 254。格式化 40 个磁道要几十秒（模拟器里 600 帧后仍在进行，2100 帧后已结束） | 实测 |
| `CATALOG` | `CATALOG[,Vn][,Dn][,Sn]` | 显示目录：`PEC LM-DOS 3.31`、`DISK VOLUME 254`，每个文件一行（类型字母、扇区数、文件名，如 ` A 002 A`），最后是文件个数与空闲扇区数 | 实测 |
| `LMDIR` | `LMDIR 名字[,Vn][,Dn][,Sn]` | 按名字筛选目录，输出格式同 `CATALOG`。必须带文件名；实测 `LMDIR A` 列出文件 `A`，未验证部分匹配 | 实测 |
| `LMUNDIR` | `LMUNDIR[,Vn][,Dn][,Sn]` | 列出已删除、还能用 `LMUNDEL` 恢复的文件。没有删除过文件时显示 `0 FILE(S)` | 实测 |
| `LMDISKMAP` | `LMDISKMAP[,Dn]` | 逐磁道显示扇区占用图：每行一个磁道，先是十六进制磁道号，后跟 14 列，`.` 空闲、`*` 已用；末行是空闲扇区数。输出较长，屏幕会滚动 | 实测 |
| `LMDELDISK` | `LMDELDISK[,Vn][,Dn][,Sn]` | 清空磁盘上全部文件，先问 `Are you sure?(Y/N)`。约 5 秒完成，不重新格式化；清空后 `CATALOG` 显示 `0 FILE(S)`、空闲 532 个扇区 | 实测 |

### 扇区与数值工具

这些命令是 LM 自有的，格式里的磁道、扇区都是物理磁盘上的位置，扇区号经过 RWTS 的交错表转换，与镜像文件里的逻辑扇区顺序一致。

| 命令 | 格式 | 作用 | 依据 |
| --- | --- | --- | --- |
| `LMREAD` | `LMREAD Aaddr,Btrack,Rsector[,Vn][,Dn][,Sn]` | 把指定磁道、扇区读到内存地址 `addr`，`A`、`B`、`R` 必须全部给出 | 代码 |
| `LMWRITE` | `LMWRITE Aaddr,Btrack,Rsector[,Vn][,Dn][,Sn]` | 把内存地址 `addr` 起的 256 字节写到指定磁道、扇区 | 代码 |
| `LMDUMP` | `LMDUMP Btrack,Rsector[,Vn][,Dn][,Sn]` | 读指定扇区到 `$6200`，以 32 行、每行 8 字节的十六进制显示 | 代码 |
| `LMHEX` | `LMHEX A$hhhh` | 把十六进制数显示成十进制 | 代码 |
| `LMDEC` | `LMDEC Annnnn` | 把十进制数显示成 `$` 加四位十六进制 | 代码 |
| `VERSION` | `VERSION` | 显示版本：`PEC LM-DOS 3.31`、`(C)Copyright LiuMin 1993.8`、`Programmer: Liu Min (ECNU)`，再显示一行中文“磁盘操作系统程序设计：刘 民” | 实测 |

## 参数规则表

命令名表在 `$A77A`，参数规则表在 `$A843`，每个命令 2 字节，按命令名表的顺序排列；处理程序地址表在 `$9D1E`，每项 2 字节，存的是入口减 1。

### 第 1 字节

| 位 | 含义 |
| --- | --- |
| `$80`、`$40` | 没有写文件名时：都为 0 表示这行不是 DOS 命令；`$40` 表示文件名可省；`$80` 表示不可省（效果同样是这行不由 DOS 处理） |
| `$20` | 命令后跟文件名 |
| `$10` | 允许逗号后再跟第二个文件名（`RENAME`） |
| `$08` | 命令后跟一个 0-7 的数（`PR#`） |
| `$02` | 不得在直接输入状态执行，否则报 `NOT DIRECT COMMAND` |
| `$01` | 文件不存在时创建（`SAVE`、`BSAVE`、`OPEN`） |

### 第 2 字节

按位列出允许的选项：`$40` 为 `V`，`$20` 为 `D`，`$10` 为 `S`，`$08` 为 `L`，`$04` 为 `R`，`$02` 为 `B`，`$01` 为 `A`，`$80` 为 `C`、`I`、`O`。写了不允许的选项时这一行不由 DOS 处理（代码）。

## 文件类型

文件类型码与苹果 DOS 3.3 相同，`CATALOG` 用字母显示：`T` 文本（0）、`I` 整数 BASIC（1）、`A` BASIC 程序（2）、`B` 二进制（4）。`SAVE` 保存的是 `A`（实测）；`LMRUN`、`LOAD` 对类型的判断见上表。其余类型码（8、16、32、64）的使用情况未核对。

## 未确认的部分

- 标志表第 1 字节里 `$80` 与 `$40` 的区别只看了“都不当作 DOS 命令”这一条路径，没有分别实测。
- `CHAIN` 与 `RUN` 在 BASIC 一侧的差别。
- `MON`、`NOMON` 三个选项各自对应的显示内容，以及 `PR#` 对设备的实际效果，没有运行验证。
- 表中“代码”依据的命令没有逐个在模拟器里执行。
