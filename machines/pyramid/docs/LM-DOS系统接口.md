# 金字塔 LM-DOS 系统接口

金字塔 PEC-9588 的程序可以调用的系统接口：磁盘部分（LM-DOS 的向量页、文件管理器、读写盘程序）与 ROM 里的控制台、键盘入口。每一项标明依据：核对表示读了对应代码，推定表示只按命名或调用方式判断。

## 概述

LM-DOS 与苹果 DOS 3.3 的分层相同，自上而下是：

1. BASIC 与命令解释器：通过输入输出钩子（`$36-$39`）截获命令行，识别 37 个命令（见 [LM-DOS 命令](LM-DOS命令.md)）。
2. 文件管理器：按参数表 `$6530` 里的操作码完成打开、读写、目录等操作。
3. 读写盘程序（RWTS）：按参数表 `$6456`（IOB）读写扇区、格式化。
4. 磁盘控制器：`$5600-$56FF`，见 Ember 的硬件模块文档。

LM-DOS 固化在 ROM 块 0（`$8000-$BFFF`），固定块 31（`$C000-$FFFF`）里放系统跳转表与苹果监控程序同址的入口。

## 页 3 向量

LM-DOS 启动时把 `$9DFF` 起的 48 字节复制到 `$03D0-$03FF`，布局与苹果 DOS 3.3 相同（核对）。

| 地址 | 内容 | 作用 |
| --- | --- | --- |
| `$03D0` | `JMP $9D8A` | 热启动：重新安装输入输出钩子并回到 BASIC |
| `$03D3` | `JMP $9D74` | 冷启动：初始化 DOS 变量与缓冲区 |
| `$03D6` | `JMP $A9E0` | 文件管理器入口 |
| `$03D9` | `JMP $B3A1` | RWTS 入口 |
| `$03DC` | `LDA $9D0F`、`LDY $9D0E`、`RTS` | 取文件管理器参数表地址，返回 `A=$65`、`Y=$30`（`$6530`） |
| `$03E3` | `LDA $A9A5`、`LDY $A9A4`、`RTS` | 取 RWTS 的 IOB 地址，返回 `A=$64`、`Y=$56`（`$6456`） |
| `$03EA` | `JMP $A747` | 重新安装输入输出钩子（`dos_install_hooks`） |
| `$03F0-$03F1` | `$FA59` | BRK 向量 |
| `$03F2-$03F3` | `$9D8A` | 复位向量 |
| `$03F4` | `$38` | 上电检查字节，值为复位向量高字节 `$9D` 异或 `$A5` |
| `$03F5` | `JMP $FF58` | `&` 命令向量 |
| `$03F8` | `JMP $FF65` | Ctrl-Y 向量 |
| `$03FB` | `JMP $FF65` | NMI 向量 |
| `$03FE-$03FF` | `$FF65` | IRQ 向量 |

## 文件管理器

调用方法：填好 `$6530` 起的参数表，执行 `JSR $03D6`。返回时进位清零表示成功；进位置位表示出错，错误号在 `$653A`（核对：`$A602` 处检查进位后读 `$653A`）。

### 参数表

| 偏移 | 地址 | 含义 | 依据 |
| --- | --- | --- | --- |
| +0 | `$6530` | 操作码 | 核对 |
| +1 | `$6531` | 子操作码 | 核对 |
| +2、+3 | `$6532-$6533` | 记录号或记录长度（`OPEN` 的 `L`） | 核对 |
| +4 | `$6534` | 卷号（`CATALOG` 返回实际卷号） | 核对 |
| +5 | `$6535` | 驱动器 | 推定 |
| +6 | `$6536` | 槽号 | 核对 |
| +7 | `$6537` | 文件类型 | 核对 |
| +8、+9 | `$6538-$6539` | 单字节读写的数据，或区间读写的起始地址 | 核对 |
| +10 | `$653A` | 错误号 | 核对 |

### 操作码

操作码表在 `$A9AC`，共 13 项，超过 12 报错。

| 操作码 | 作用 | 处理程序 | 依据 |
| --- | --- | --- | --- |
| 1 | 打开 | `$AA05` | 核对（`OPEN`、`SAVE` 等经 `$A278` 设为 1） |
| 2 | 关闭 | `$AAE9` | 核对（`$A2CC`） |
| 3 | 读 | `$AB3B` | 核对（`$A5E6` 子操作码 1 读单字节） |
| 4 | 写 | `$AB53` | 核对（`$A39C` 子操作码 1 写单字节） |
| 5 | 删除（`LMUNDEL` 带恢复标志） | `$AC12` | 核对 |
| 6 | 目录 | `$AC8C` | 核对 |
| 7 | 锁定 | `$ABD6` | 核对 |
| 8 | 解锁 | `$ABDD` | 核对 |
| 9 | 改名 | `$AB1D` | 核对 |
| 10 | 定位 | `$ABF9` | 核对 |
| 11 | 初始化 | `$ADE5` | 核对（`$A4FE` 起，子操作码取 `$9D`） |
| 12 | 校验 | `$ABFF` | 核对 |

读写的子操作码 2 表示按区间读写（`$A3BB` 起）；区间长度字段的位置没有逐项核对。

### 错误号

错误号与信息见 [LM-DOS 命令](LM-DOS命令.md) 的“错误信息”一节。其中 5 `END OF DATA` 在读到文件尾时由 `$A599` 报出，`$A602` 对它做了特殊处理。

## 读写盘程序（RWTS）

调用方法：`Y` 放 IOB 地址低字节，`A` 放高字节，执行 `JSR $03D9`。入口 `$B3A1` 先保存标志并关中断，再经 `$B737` 把 `Y`、`A` 存入 `$48`、`$49`，切换到磁盘模式后调用 `rwts_entry`（`$BC16`）。返回时进位清零成功，进位置位失败（核对）。

系统自带的 IOB 在 `$6456`（地址由 `$03E3` 取得），初值来自 `$B8AF`，布局与苹果 DOS 3.3 相同：

| 偏移 | 地址 | 初值 | 含义 |
| --- | --- | --- | --- |
| +0 | `$6456` | `$01` | 表类型 |
| +1 | `$6457` | `$10` | 槽号乘 16 |
| +2 | `$6458` | `$01` | 驱动器 |
| +3 | `$6459` | `$00` | 卷号，0 表示不限 |
| +4 | `$645A` | `$00` | 磁道 |
| +5 | `$645B` | `$00` | 扇区 |
| +6、+7 | `$645C-$645D` | `$B8C2` | 设备特征表（DCT）地址 |
| +8、+9 | `$645E-$645F` | `$7000` | 数据缓冲区地址 |
| +12 | `$6462` | `$00` | 命令 |
| +13 | `$6463` | `$00` | 错误码 |
| +15 | `$6465` | `$00` | 上次使用的槽号 |
| +16 | `$6466` | `$00` | 上次使用的驱动器 |

设备特征表在 ROM `$B8C2`，内容是 `00 01 EF D8`，与苹果 DOS 3.3 的 DCT 相同。

### 命令

命令字节在 IOB 偏移 +12（核对：`rwts_entry` 对它做 `BEQ`、`CMP #$04` 与 `ROR` 判断）。

| 命令 | 作用 | 依据 |
| --- | --- | --- |
| 0 | 只寻道，不读写 | 核对（`$BCBB` 起命令为 0 时转 `$BD1B`） |
| 1 | 读扇区 | 核对（`LMREAD` 设 1） |
| 2 | 写扇区 | 核对（`LMWRITE` 设 2） |
| 4 | 格式化当前磁道 | 核对（命令为 4 时转 `$BDBF`，那里清空数据缓冲并准备写地址场，格式化例程 `rwts_format_track` 在 `$BE1D`） |

错误码字节（偏移 +13）各位的含义沿用苹果 DOS 3.3（`$10` 写保护、`$20` 卷号不符、`$40` 驱动器错、`$80` 读错），没有逐位核对。

### 调用示例

读磁道 17 扇区 0 到 `$7000`：

```asm
        jsr $03E3          ; A=IOB 高字节，Y=IOB 低字节
        pha                ; 保存 IOB 地址
        tya
        pha
        lda #17
        sta $645A          ; 磁道
        lda #0
        sta $645B          ; 扇区
        sta $6459          ; 卷号 0：不限
        sta $645E          ; 缓冲区地址低字节
        lda #$70
        sta $645F          ; 缓冲区地址高字节
        lda #1
        sta $6462          ; 命令 1：读
        pla
        tay                ; Y=IOB 低字节
        pla                ; A=IOB 高字节
        jsr $03D9
        bcs error          ; 进位置位：读失败
```

这个调用顺序与 `LMREAD` 的处理程序（`$B7DB` 填写 IOB 字段）一致，没有单独运行。

## 控制台与键盘

固定块里有一组和苹果监控程序同址的入口，LM-DOS 与 BASIC 都用它们。

| 地址 | 名字 | 作用 | 依据 |
| --- | --- | --- | --- |
| `$FDED` | `monitor_cout` | 输出字符 `A` | 推定，`$FDF0` 的标准输出入口经核对 |
| `$FDF0` | - | 标准字符输出入口，先保存 `Y`，再跳到 `$80FE`（`console_cout1`） | 核对 |
| `$FD1B` | `monitor_keyin` | 等待并读一个键，等待时闪烁光标，跳到 `$8131`（`console_keyin`） | 核对 |
| `$FD6A` | `monitor_getln` | 读一行到 `$0200` 起的行缓冲，提示符字符在 `$33`，跳到 `$819E`（`console_getln`） | 核对 |
| `$FD0C` | `monitor_rdkey` | 读一个键 | 推定 |
| `$FD8E` | `monitor_crout` | 输出回车 | 推定 |
| `$FDDA` | `monitor_prbyte` | 把 `A` 显示成两位十六进制 | 推定 |
| `$FC58` | `monitor_home` | 清屏并让光标回到左上角 | 推定 |

`console_out_char`（`$805B`）把字符写到文字屏幕：`$A0` 起的可显示字符写到当前位置，`$8D` 回车，`$8A` 换行，`$88` 退格，`$87` 响铃（核对）。

屏幕窗口与光标变量与苹果相同：`$20-$23` 是窗口左边、宽度、上边、下边，`$24`、`$25` 是光标列与行，`$28-$29` 是当前行的显示地址（核对 `console_out_char`），`$33` 是提示符，`$36-$37` 与 `$38-$39` 是输出与输入钩子。

## 系统跳转表

固定块 `$C000-$C038` 是 19 个 `JMP`，其中 8 个先跳到块 0 的 `$86E2-$86F7` 中转，再到真正的子程序。名字来自反汇编工程的命名，行为只在调用处观察过。

| 入口 | 目标 | 说明 |
| --- | --- | --- |
| `$C000` | `$86E2` → `$8C5E` | 读键盘，无键返回 0；`console_keyin` 在等待循环里调用（推定，`$8C5E` 没有逐条核对） |
| `$C003` | `$C13E` | 未分析 |
| `$C006` | `$86E5` → `$8A41` | 未分析 |
| `$C009` | `$86E8` → `$953B` | 未分析 |
| `$C00C` | `$86EB` → `$8728` | 清空显存任务计数后重绘窗口（读代码，用途未完全确认） |
| `$C00F` | `$86EE` → `$87F4` | 读光标处的字符格并反相，用于光标闪烁（`cursor_cell_read_inverse`，推定） |
| `$C012` | `$86F1` → `$8794` | 读键并处理重复（`key_read_with_repeat`，推定） |
| `$C015` | `$86F4` → `$8937` | 键盘扫描（`keyboard_scan`，推定） |
| `$C018` | `$C1E0` | 未分析 |
| `$C01B` | `$C272` | 未分析 |
| `$C01E` | `$C801` | 未分析 |
| `$C021` | `$C611` | 未分析 |
| `$C024` | `$C293` | 未分析 |
| `$C027` | `$C320` | 未分析 |
| `$C02A` | `$C384` | 未分析 |
| `$C02D` | `$C51E` | 未分析 |
| `$C030` | `$C6FB` | 未分析 |
| `$C033` | `$C72C` | 未分析 |
| `$C036` | `$C780` | 未分析 |

块 0 的 `$86F7` 跳到 `$877F`，供 NMI 处理程序（`nmi_handler`，`$C039`）在帧中断里提交排队的显存任务时调用；`$86FA` 的 `wait_key` 反复读键直到有键，每 4 次循环闪烁一次光标。

## 未确认的部分

- 系统跳转表里标“未分析”的 14 个入口，以及 `$8C5E`、`$8A41`、`$953B`。BASIC 本身在固定块里，没有拆开。
- 监控程序同址入口里标“推定”的几个。
- 文件管理器参数表偏移 +5 的含义、区间读写时长度字段的位置、RWTS 错误码各位。
- `$03D0` 与 `$03D3` 两个启动入口回到 BASIC 的具体分支。
