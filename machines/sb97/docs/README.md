# SB97 BIOS 分析结论

## 文件

- `ember/roms/sb97.bin`：1MB 的纯程序区（64 页，每页 16K），没有 CHR，也没有文件头。这台机器按 mapper 168 处理，程序区的 CRC32 是 `40a4c574`，用它认定 BIOS。
- 这个文件只供开发与测试使用，Ember 不随发布包分发 BIOS。

## 内存映射

| 地址 | 内容 |
| --- | --- |
| `$0000-$07FF` | 内部 RAM，2K，镜像到 `$1FFF` |
| `$2000-$3FFF` | PPU 寄存器 |
| `$4000-$4017` | APU、精灵 DMA、手柄口 1、键盘（`$4016` 写、`$4017` 读） |
| `$4100-$5FFF` | 整机寄存器，见下 |
| `$6000-$7FFF` | 8K RAM |
| `$8000-$FFFF` | 程序窗口，由 `$5000`、`$5200` 决定（见下） |

整机寄存器：

| 地址 | 读写 | 作用 |
| --- | --- | --- |
| `$5000` | 写 | 程序页选择，位 7 为 0 选 ROM、为 1 选 128K 的程序 RAM（PRAM） |
| `$5200` | 写 | 位 0：名称表镜像（1 水平、0 垂直）；位 2：32K 模式；位 0、1 的取值为 2 时背景图案表按名称表序号选（见下） |
| `$5300` | 读写 | 语音芯片：读状态（`$80` 就绪、`$8F` 播放结束），写码流字节 |
| `$5500-$5507` | 写 | 软驱控制器：`$5501` 对应寄存器 2（DOR），`$5500` 对应寄存器 7（数据率），其余取地址低 3 位 |
| `$5600-$5607` | 读 | 软驱控制器：`$5604` 是状态寄存器，`$5605` 是数据 |
| `$480D` | 写 | 键盘指示灯（静态统计里只写 `$00`、`$02`） |

软驱控制器的中断接 CPU 的 IRQ 线；复位时写 `$4017=$C0`，帧 IRQ 被禁止。

程序窗口：

- 16K 模式（`$5200` 位 2 为 0）：`$8000-$BFFF` 是第 `$5000` 页，`$C000-$FFFF` 固定是第 0 页。
- 32K 模式（位 2 为 1）：`$5000` 的值是 32K 页号，`$8000-$FFFF` 是第 2n、2n+1 两页。
- 页号按 64 页取模，所以 `$5000=$40` 选到的还是第 0 页。
- RAM 模式（`$5000` 位 7 为 1）：16K 模式下 `$8000` 是 PRAM 的第 `$5000&7` 个 16K，`$C000` 仍是第 0 页；32K 模式下整个窗口是 PRAM 的第 `$5000&3` 个 32K，可写。

背景图案表：画背景时，名称表序号为 2 的图块一定用图案表 1；序号为 1、3 的图块在 `$5200` 的位 0、1 等于 2 时也用图案表 1；其余按 `$2000` 位 4。精灵不受影响。菜单的下半屏就在名称表 2，要靠这个才有图形。

## 功能分派器

第 0 页 `$FFE0` 是 `JMP $C0C2`，功能号放在 `$0100`，`$C0C2` 按功能号切换窗口页后用 `JMP ($00C8)` 跳转，返回后恢复原来的页：

| 功能号 | 页与入口 |
| --- | --- |
| `$00-$0F` | 查 RAM 里 `$013D` 起的三字节表（页、入口低字节、入口高字节），运行时填 |
| `$10-$6F` | 当前页不变，查第 0 页 `$C000` 起的功能表（每项 2 字节，`$C0C0` 表示没有实现） |
| `$70-$7E` | 切到第 63 页，跳 `$8000` |
| `$7F` | 切到第 47 页，跳 `$E0BE`（在第 0 页里） |
| `$80-$9F` | 切到第 64 页（就是第 0 页），查 `$8000` 起的表 |
| `$A0-$BF` | 切到 RAM 模式的 PRAM 第 0 页，查 `$8000` 起的表（运行时才有） |
| `$C0-$EF` | 切到第 1 页，查 `$8000` 起的表 |
| `$F0-$FF` | 切到第 5 页，查 `$B380` 起的表 |

## 静态分析的覆盖

分页统计的结果（分析工具已删除）：

| 页 | 推断 | 说明 |
| --- | --- | --- |
| 0 | 固定页 | 从复位向量 `$FF00`、`$FFE0` 起的跳转桩与功能表出发，没有被拒绝的位置，约 9400 字节是代码 |
| 1 | 窗口程序页 | 功能 `$C0-$EF` 的实现，几乎整页都是代码 |
| 2-8 | 窗口程序页 | 页首有三个 `JMP` 跳转桩（`$8000`、`$8003`、`$8006`）；第 2 页是菜单程序 |
| 63 | 窗口程序页 | 功能 `$70-$7E` 的实现，用 JSR 后面内嵌跳转表与内嵌字符串 |
| 其余 | 数据或未找到入口 | 第 10-62 页静态找不到入口，多半是字库、图形与压缩数据，也可能是经 RAM 模式功能（`$A0-$BF`）与运行时填的功能表进入的代码；要靠运行时采集补全 |

分析识别两种内嵌写法：`JSR` 后面紧跟的字表（子程序弹出返回地址按下标取一项当跳转目标）和以 `$00` 结尾的字符串（子程序弹出返回地址逐字符打印）。

## 静态统计的寄存器访问

对 $2000-$5FFF 访问的统计结果（只统计立即数能追踪到的写入，分析工具已删除）：

| 地址 | 结论 |
| --- | --- |
| `$5000` | 写过 `$01`、`$05`、`$2F`、`$3F`、`$40`、`$80`，都来自功能分派器；窗口页与 RAM 模式靠它切换 |
| `$5200` | 只有写，静态能追踪到的值只有 `$00` |
| `$4016`、`$4017` | 键盘扫描：写 `$05` 回到起点、`$04` 前进并读前半边、`$06` 翻转读后半边，读 `$4017` 位 1-4（按下为 0），共 13 个位置；`$4017` 读到的值与 `$00` 比较判断有没有键 |
| `$5300` | 读状态、写 `$0F` |
| `$4014` | 精灵 DMA，页 `$02` |
| `$2000-$2007` | 标准 PPU 访问 |
