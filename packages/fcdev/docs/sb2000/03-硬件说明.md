# SB2000 硬件说明

本文是 SB2000（小霸王学生电脑）硬件行为的结论，来源是模拟器源码（`virtuanes/VirtuaNES/NES/Mapper/MapperSB2K.cpp` 等）和实际运行观察。“已确认”指来自模拟器源码或实际运行，真机均未测试；程序接口见 [系统调用手册](02-系统调用手册.md)。

| 项目 | 结论 | 状态 |
| --- | --- | --- |
| CPU | 标准 6502（含非官方指令），不是新指令集；“6576”是映射器 ASIC 的工作模式 | 已确认 |
| 进入 6576 模式 | 依次向 `$4031` 写入 `$65`、`$76`；BIOS 启动后自行完成 | 已确认 |
| 返回 FC 兼容模式 | 向 `$4301` 写 `$55`：复位 6576、`RAM 启动`，`$8000` 以上改走 MMC3 仿真 | 已确认 |
| 程序窗口 | `$4040-$4047` 各选一个 4K 页，对应 `$8000-$FFFF` 的 8 个窗口；值小于 `$80` 是 BIOS ROM 页（512KB，共 128 页），不小于 `$80` 是扩展 RAM 页（512KB） | 已确认 |
| 启动后的窗口 | `$C000-$FFFF` 固定为 ROM 第 4-7 页，`$8000-$BFFF` 由 BIOS 换页 | 已确认 |
| 向量 | NMI `$C084`，RESET `$C000`，IRQ `$C12B`（ROM 偏移 `$7FFA` 起） | 已确认 |
| 内部 RAM | 6576 模式下 `$0000-$1FFF` 为 8K 且不镜像；`$5000-$5FFF` 为 2K 工作 RAM，`$6000-$7FFF` 为 8K 扩展 RAM | 已确认 |
| DMA | `$4048-$404F`；写 `$4048` 的最高位启动；源为 ROM 或扩展 RAM，目的为工作 RAM 或显存 | 已确认 |
| 软驱控制器 | `$4200-$4207`；1.44MB（每道 18 扇区、2 面、80 道），LBA = 磁道×36 + 磁头×18 + 扇区 − 1 | 已确认 |
| 键盘 | 经 `$4020-$4022` 串行收发，扫描码与 DirectInput 的 DIK 值一致 | 已确认 |
| 显存 | 512KB，经 `$4300` 选 32KB 的 bank | 已确认 |
| 中断屏蔽与状态 | `$4032` 读写屏蔽寄存器：写入值中为 1 的位屏蔽（禁止）该中断源，同时把 `$4033` 里对应的待处理标志清除（`$4033 &= ~写入值`），为 0 的位允许该中断源。位 7 定时器、位 6 鼠标、位 5 键盘、位 3 软驱，复位时为 `$FF`（全部屏蔽）；`$4033` 只读，位含义相同，为 1 表示该源有待处理中断 | 已确认（模拟器源码） |
| 并口打印机 | 模拟器实现了 Epson ESC/P 虪拟打印机（`LPT.cpp`）。数据写 `$4025`；写 `$4016` 的位 0 为 #选中打印机、位 1 为 #换行、位 2 为复位；写 `$4026` 的位 2 为 #选通（strobe）；读 `$4017` 位 2 为出错、位 3 为 #忙；读 `$4026` 位 3、4、5 依次是应答、缺纸、已选中（模拟器里状态固定为“不忙、已应答、有纸、已选中、无错”）。收到 `ESC @`（`$1B $40`）开始一页，弹出“Print to...”对话框，可选系统打印机或输出 PDF、PNG 文件；收到换页 `$0C`、复位或约 6 秒没有数据就结束这一页 | 已确认（模拟器源码） |
| 语音端口 `$4302` | 读：位 7 为 1 表示可以接收下一个字节（缓冲未满），语音播完时低 4 位为 `$F`。写：把一个语音数据字节送进环形缓冲，由模拟器的 LPC 语音线程解码播放。`$4026` 位 6 的上升沿复位语音（清缓冲）。BIOS 的 `$74`、`$75`（`API_74_PORT4302_CONTROL`、`API_75_PORT4302_SEND`）就是操作它 | 已确认（模拟器源码）；`$74`、`$75` 的发送序列与“播完”结束都已实测（见 [系统调用手册](02-系统调用手册.md) 5.13 节）；模拟器曾缺 `case 0x4302:`，已修复 |

## 软件环境

| 项目 | 结论 | 状态 |
| --- | --- | --- |
| 版本 | `SB-DOS V2.00`，`SUBOR 1989-1998`，启动后依次询问日期与时间，提示符 `A:\>` | 已确认 |
| 软盘格式 | 标准 1.44MB FAT12（本工具生成的镜像能被 `dir` 读出并运行 `ATTRIB.EXE`、`EDIT.EXE`） | 已确认 |
