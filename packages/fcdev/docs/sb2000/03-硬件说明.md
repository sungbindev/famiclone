# SB2000 硬件说明

本文是 SB2000（小霸王学生电脑）硬件行为的结论，来源有三类：芯片手册（SH6578 官方手册，下称“芯片手册”）、模拟器源码（`virtuanes/VirtuaNES/NES/Mapper/MapperSB2K.cpp` 等）与实际运行观察、真机实测（`apps/sb2000/memtest`，2026-11-12；`apps/sb2000/hwtest`，2026-11-13，真机为 PAL 制式）。SB2000 的真机芯片是 UM6576，芯片手册是 SH6578，两颗芯片有差别，两者不一致时以真机实测为准。“已确认”指来自模拟器源码或实际运行；没有写“真机”的结论都没有在真机上测过。模拟器已按真机实测修改内部 RAM、`$4400-$5FFF`、DMA、定时器与图形端口（见对应行），memtest、hwtest 在模拟器里的结果与真机一致（仍有差异的项见“真机与模拟器仍有差异的行为”一行）；模拟器与芯片手册不一致、也没有真机数据的地方，在对应行里写明。程序接口见 [系统调用手册](02-系统调用手册.md)。

| 项目 | 结论 | 状态 |
| --- | --- | --- |
| CPU | 标准 6502（含非官方指令），不是新指令集；“6576”是向 `$4031` 依次写入 `$65`、`$76`（芯片手册称这一步为初始设置）之后的工作模式 | 已确认 |
| 进入 6576 模式 | 依次向 `$4031` 写入 `$65`、`$76`；BIOS 启动后自行完成。芯片手册要求两次写入在两个指令周期内连续完成（`LDA #$65 / LDX #$76 / STA $4031 / STX $4031`），模拟器只按顺序识别，不检查间隔 | 已确认（芯片手册、模拟器源码） |
| 返回 FC 兼容模式 | 向 `$4301` 写 `$55`：复位 6576、`RAM 启动`，`$8000` 以上改走 MMC3 仿真 | 已确认 |
| 程序窗口 | `$4040-$4047` 各选一个 4K 页，对应 `$8000-$FFFF` 的 8 个窗口；值小于 `$80` 是 BIOS ROM 页（512KB，共 128 页），不小于 `$80` 是扩展 RAM 页（512KB） | 已确认 |
| 启动后的窗口 | `$C000-$FFFF` 固定为 ROM 第 4-7 页，`$8000-$BFFF` 由 BIOS 换页 | 已确认 |
| 向量 | NMI `$C084`，RESET `$C000`，IRQ `$C12B`（ROM 偏移 `$7FFA` 起） | 已确认 |
| 内部 RAM | 芯片手册：工作 RAM 共 10KB，在 `$0000-$1FFF`（8KB）与 `$5000-$57FF`（2KB）。模拟器（6576 模式）已按真机实测修改，行为与下面的真机实测相同；模拟器在 FC 兼容模式下仍保留 `$5000-$5FFF` 的 2K RAM（镜像两次），这个模式没有在真机上测过。真机实测：内部 RAM 只有 2K，`$0800-$1FFF` 是 `$0000-$07FF` 的镜像；`$4400-$5FFF` 读出的都是 `$68`，写 `$55`、`$AA` 后读回仍是 `$68`，既不是 RAM 也不是会应答的寄存器（`$5006` 的写入仍有效果）；`$6000-$7FFF` 是 8K，各 1K 互相独立 | 已确认（真机实测；模拟器已在 SB-DOS 下用真实 CPU 指令读写核对）；内存大小与芯片手册不一致，以真机为准 |
| DMA | `$4048-$404F`，把主存储器的数据复制到显存或工作 RAM；写 `$4048` 的最高位启动（模拟器瞬时完成）。`$4048`：位 7 使能；位 6 传输速率（0 为 890KB/s，1 为 1.78MB/s）；位 5 目的（0 为显存，1 为工作 RAM），其余位为 0。芯片手册要求先把 `$4020` 位 7 置 1，位 6、5 才起作用（模拟器不检查；BIOS 在系统初始化时写 `$4020=$80`）。`$4049`：源 bank，低 5 位对应 XA20-XA16，位 4 为 1 取扩展 RAM，否则取 ROM；`$404A`、`$404B`：源地址的低、高字节，`$404B` 的低 7 位是 A14-A8，位 7 是 A15（真机要求为 1，模拟器已按真机处理：为 0 时不传输）；`$404C`、`$404D`：目的地址低、高字节，目的是显存时位 15 为 1 表示扩展显存；`$404E`、`$404F`：长度寄存器的值是字节数减 1，真机实际搬“长度 + 1”个字节（BIOS 也传“字节数 − 1”），最大 32KB（`$8000` 不屏蔽，写 `$8010` 会搬 `$8011` 个字节）。每搬一个字节，源地址与目的地址各加 1。芯片手册：目的是显存时只在垂直消隐期间或显示关闭时运行，没搬完的数据留到下一次垂直消隐再继续；目的是工作 RAM 时没有这个限制。BIOS 把 `$C0` 用于复制到显存，`$A0`、`$E0` 用于复制到 CPU 地址。真机实测：只有目标是 ERAM 且 `$404B` 位 7 为 1 时成功，模式 `$A0`、`$E0` 都行；`$4020` 位 7 为 0 时，模式位 5 不起作用，目的总是显存，位 7 为 1 时才由模式位 5 选择工作 RAM 或显存（与芯片手册的说法一致）；模拟器已对齐：`$404B` 位 7 为 0 时不传输，目的在程序窗口（`$8000` 以上）时写不进去，长度按“长度 + 1”，`$4020` 位 7 为 0 时目的总是显存，memtest、hwtest 在模拟器里的结果与真机相同 | 已确认（芯片手册、模拟器源码；位的作用已在模拟器里逐项核对）；真机实测 |
| 软驱控制器 | `$4200-$4207`；1.44MB（每道 18 扇区、2 面、80 道），LBA = 磁道×36 + 磁头×18 + 扇区 − 1 | 已确认 |
| 键盘 | 经 `$4020-$4022` 串行收发。芯片手册：键盘口收发 AT 键盘的 11 位串行帧（起始位、8 位扫描码、奇偶位、停止位），收完整帧后产生键盘中断，要在下一位到来前读走 `$4020` 里的扫描码；`$4022` 位 7 是键盘时钟 CLK（接收时必须保持 1，BIOS 处理完一个码后写 `$80`），位 2 允许“发送命令完成”中断，位 0 是方向（0 为键盘到系统，1 为系统到键盘）；发送时先把数据写入 `$4021`，再置位 0 为 1、CLK 拉低大于 60ms 后拉高，硬件自动发出。模拟器直接给出与 DirectInput 的 DIK 值一致的扫描码（即 IBM 码集 1 的按下码），在 CLK 上升沿且位 0 为 1 时把 `$4021` 发给键盘；真机键盘实际是否按此工作没有测过；BIOS 初始化键盘时（功能 `$17`）会发 `$F0`、`$01` 选择扫描码集 1 | 已确认（芯片手册、模拟器源码） |
| 显存 | 512KB，经 `$4300` 选 32KB 的 bank | 已确认 |
| 中断屏蔽与状态 | `$4032` 读写屏蔽寄存器：写入值中为 1 的位屏蔽（禁止）该中断源，同时把 `$4033` 里对应的待处理标志清除（`$4033 &= ~写入值`），为 0 的位允许该中断源。位 7 定时器、位 6 鼠标、位 5 键盘、位 4 INT4（芯片手册：实时时钟）、位 3 软驱、位 2 INT2（芯片手册：打印机的 IRQ2）、位 1 INT1（芯片手册：φ 使能的 IRQ1），位 0 未用，复位时为 `$FF`（全部屏蔽）；`$4033` 只读，位含义相同，为 1 表示该源有待处理中断。BIOS 为位 4、2、1 各留了钩子，模拟器里没有设备置位它们 | 已确认（芯片手册、模拟器源码） |
| 鼠标 | `$4023` 位 0 选手柄 2 或鼠标（1 为鼠标）；鼠标数据经 `$4024` 读，是微软串口鼠标的 3 字节包。复位信号：BIOS（功能 `$14`）与模拟器都用 `$4026` 的位 1（EIO1），拉低再拉高，模拟器在上升沿发 RTS。芯片手册在鼠标一节把复位信号写作 `$4026` 的 D2，在扩展 I/O 一节又写 EIO1 产生鼠标复位，两处说法不一致，这里按 BIOS 与模拟器的用法，真机没有核实；手册要求复位时间大于 30ms，并可写 `$4024` 设置波特率（NTSC 为 `$A3`、PAL/B 为 `$A9`），BIOS 没有写它 | 已确认（芯片手册、模拟器源码、BIOS 代码）；复位位的说法见左 |
| 定时器 | `$4034` 控制：位 7 允许，位 6 连续重载（0 只计一次），位 5 基准时钟（0 为 CPU 时钟，1 为行消隐时钟 15625Hz），位 3-0 为预分频 PS；`$4035` 写预置值 TP，同时装入当前值；`$4036` 读当前值（递减）。周期 = 基准周期 × (PS + 1) × (TP + 1)，下溢时置 `$4033` 位 7（`$4032` 位 7 为 0 才产生中断）。真机实测：`$4035` 可读（读回写入的预置值）；一次计时（位 6 为 0）下溢一次后，当前值保持预置值，不再计时，也不再置中断标志，模拟器已对齐（旧版把当前值置 0）；真机一帧是 PAL 的 50Hz，模拟器的计数与真机相同。BIOS 开机设 `$4034=$EF`、`$4035=$3C`（连续、行消隐时钟、PS=15、TP=60，周期 64µs × 16 × 61 约 62.5ms，即约 16Hz），用作软件时钟的节拍；播放 WAV 时用 `$4034=$C0`（CPU 时钟、PS=0），`$4035` 取 `$28`、`$51`、`$A2` 作采样节拍 | 已确认（芯片手册、模拟器源码；开机后的寄存器值已在模拟器里读出）；`$4035` 可读与一次计时的行为为真机实测 |
| 声音 | 芯片手册：4 通道 PSG，通道 1、2 方波，通道 3 三角波，通道 4 噪声，寄存器为 `$4000-$4003`、`$4004-$4007`、`$4008`、`$400A`、`$400B`、`$400C`、`$400E`、`$400F`，`$4015` 低 4 位依次使能通道 1-4；没有定义 NES 的 DMC 寄存器 `$4010-$4013`，语音改用 `$4027` 的 DAC 输出。BIOS 的声音引擎在 RAM 里维护这些寄存器的影子，再写到芯片（见 [系统调用手册](02-系统调用手册.md) 5.5 节） | 芯片手册 |
| DAC | `$4027` 是 8 位 DAC，输出语音（PCM）。芯片手册：实际输出发生在定时器溢出时，所以使用 DAC 必须同时设置定时器；输出带约 1/2 Vcc 的直流偏置，输出语音前要把电平从 0 缓慢升到偏置值，否则开始时有“噗”声。BIOS 播放 WAV 时写它（`$65/$0C`） | 芯片手册；BIOS 的用法已验证 |
| 实时时钟 | 芯片手册：`$4080` 写 RTC 地址，`$4081` 读写 RTC 数据，使用前先设地址。SB2000 的 BIOS 不访问它们，系统时钟由定时器中断软件计时；模拟器的 `$4026` 位 0（EIO0）没有接 RTC | 芯片手册；BIOS 没有使用 |
| 图形端口 | 寄存器 `$2000-$2008` 与调色板 `$2040-$207F`。`$2000`：位 7 允许 NMI，位 5 精灵 8×16，位 2 地址增量（0 加 1，1 加 32），位 1-0 背景页；`$2001`：位 0 黑白，位 1、2 屏蔽背景、精灵最左 8 个像素，位 3、4 背景、精灵显示，位 7-5 红绿蓝增强；`$2002` 读：位 7 垂直消隐，位 6 精灵与背景碰撞，位 5 一行超过 8 个精灵；`$2008`：位 7 背景 4 色（0）或 16 色（1），位 3-2 精灵图案表起始，位 0 名称表起始（为 1 时名称表在显存 `$2000-$27FF`，只能显示一页）。名称表项 2 字节，高 4 位是调色板组，低 12 位是图案号；调色板 64 项，每项低 4 位颜色、位 5-4 亮度。显存、调色板、精灵 RAM 只能在垂直消隐期间或显示关闭时更新，精灵用 `$4014` 的 DMA 更新。BIOS 功能 `$10` 修改的就是这些位（见 [系统调用手册](02-系统调用手册.md) 5.7 节）。真机实测（`hwtest`，与芯片手册不一致的地方以真机为准）：① `$2001` 位 1、2 的极性与 NES 相同，为 1 表示显示最左 8 个像素，为 0 表示屏蔽（芯片手册写反，BIOS 影子初值 `$0E` 即两位都显示）；位 0 为 1 时黑白，背景底色也变灰；位 5 增强绿、位 6 增强红、位 7 增强蓝（PAL 顺序，芯片手册写位 5 蓝、位 6 绿、位 7 红）。② 精灵属性位 6 为水平镜像，位 7 为垂直翻转，位 5 为 1 表示在背景之后（只被不透明的背景像素盖住）；读回 OAM 时属性字节只有 `$F3` 的位有效（位 4-2 读 0）。③ `$2000` 位 1-0 选 4 个互相独立的名称表；`$2008` 位 0 为 1 时名称表从 `$2000` 起；8×16 精灵的图案号最低位被忽略（相邻的偶数号、奇数号显示同一对图块），上半取偶数号。④ 调色板每项低 4 位是色相、位 5-4 是亮度，与芯片手册相同，16 色模式可用；读调色板得到 `(值 & $3F) | $40`。⑤ `$2002` 位 6（精灵 0 碰撞）、位 5（一行超过 8 个精灵）有效，低 5 位是最后一次写 PPU 总线的值。模拟器的 UM6576 PPU（`PPU_UM6576.cpp`）已按以上实测实现；颜色的亮度与饱和度渲染与真机电视的差别没有对齐，不影响程序行为 | 芯片手册；位的作用为真机实测（`hwtest`），模拟器已对齐 |
| 真机与模拟器仍有差异的行为 | `hwtest` 在真机上测到、模拟器没有对齐的项目（程序不应依赖这些值）。真机读数：`$203F`、`$2080` 为 `$20`，`$3FFF` 为 `$68`（`$2009` 为 `$00`）；`$4018`、`$4019`、`$401F` 为 `$40`，`$4037` 为 `$A0`；`$4015` 写 `$FF` 后读出位 4 为 1、写 `$1F` 后读出位 4 为 0（模拟器反过来）；`$4022` 开机值 `$C0`、`$4023` 开机值 `$81`（位 6、7 是输入线，取决于接线；模拟器为 `$80`、`$01`）；`$4026` 读出 `$3F`（位 4 为 1，模拟器按虚拟打印机固定为 `$2F`）；`$4016` 读出 `$44`、`$4017` 读出 `$40`（模拟器为 `$40`、`$48`）；实时时钟 `$4081` 读出 `$60`（模拟器读出 `$00`）；`$4033` 位 6 在清除后仍为 1（鼠标待处理，没接鼠标时的真机状态，模拟器为 0）。`$4036` 运行中的当前值取决于读取时刻，通用 DMA 在 `$8010` 起的采样取决于源 RAM 里原来的内容，两者无法逐值比对 | 真机实测（`hwtest`）；模拟器没有对齐 |
| 并口打印机 | 模拟器实现了 Epson ESC/P 虚拟打印机（`LPT.cpp`）。数据写 `$4025`；写 `$4016` 的位 0 为 #选中打印机、位 1 为 #换行、位 2 为复位；写 `$4026` 的位 2 为 #选通（strobe）；读 `$4017` 位 2 为出错、位 3 为 #忙；读 `$4026` 位 3、4、5 依次是应答、缺纸、已选中（模拟器里状态固定为“不忙、已应答、有纸、已选中、无错”）。芯片手册只定义了 `$4016` 的位 1、0（OUT1、OUT0）、`$4017` 的位 0、`$4025`（数据寄存器，写入时产生选通）与 `$4026`（EIO7-EIO0）；这里 `$4016` 位 2、`$4017` 位 2、3 的用法来自模拟器源码的注释，芯片手册没有定义，真机没有核实。收到 `ESC @`（`$1B $40`）开始一页，弹出“Print to...”对话框，可选系统打印机或输出 PDF、PNG 文件；收到换页 `$0C`、复位或约 6 秒没有数据就结束这一页 | 已确认（模拟器源码） |
| 语音端口 `$4302` | 读：位 7 为 1 表示可以接收下一个字节（缓冲未满），语音播完时低 4 位为 `$F`。写：把一个语音数据字节送进环形缓冲，由模拟器的 LPC 语音线程解码播放。`$4026` 位 6 的上升沿复位语音（清缓冲）。BIOS 的 `$74`、`$75`（`API_74_PORT4302_CONTROL`、`API_75_PORT4302_SEND`）就是操作它 | 已确认（模拟器源码）；`$74`、`$75` 的发送序列与“播完”结束都已实测（见 [系统调用手册](02-系统调用手册.md) 5.13 节）；模拟器曾缺 `case 0x4302:`，已修复 |
