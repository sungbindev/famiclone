请求

请求 简介
filemanager.setRoot 设置目录并开始监视与扫描（目录里的镜像文件与文件夹有变化时核心自己重新扫描）
filemanager.tree 目录里一个文件夹的直接内容：全部子文件夹（空文件夹也列出）与全部文件（不分扩展名，含隐藏文件
filemanager.list 列出镜像里一个文件夹的内容（directory 为空是根目录），顺序与磁盘上的目录一致
filemanager.rename 重命名镜像里的条目（不改所在文件夹）
filemanager.remove 删除镜像里的条目，文件夹连同里面的全部内容
filemanager.move 把条目移到镜像里的另一个文件夹，名称不变
filemanager.copy 把条目（文件夹连同里面的内容）复制到另一个文件夹，可以在同一个镜像里，也可以复制到另一个镜像（用来在两个镜像之间搬文件）
filemanager.makeDirectory 在镜像里新建文件夹
filemanager.undo 撤销这个镜像里最近一次管理操作（每个镜像各有一份撤销记录，只在内存里，核心重启后清空）
filemanager.readEntries 读出条目的内容用来导出：文件给出原样内容与建议的 Windows 文件名（DOS 3.3 与 ProDOS 带类型对应的扩展名），文件夹带着里面的全部内容
filemanager.importFiles 把 Windows 上的文件与文件夹导入镜像的一个文件夹（文件夹连同里面的文件）
filemanager.createImage 在目录的一个文件夹里新建空白镜像，文件名自动取不重名的“新建磁盘镜像.扩展名”
filemanager.renameItem 重命名目录里的文件或文件夹（不换所在文件夹）
filemanager.removeItems 把目录里的文件或文件夹（连同里面的内容）移进系统回收站，立即生效，不确认
filemanager.moveItems 把目录里的文件或文件夹移进另一个文件夹，名称不变，目标里已有同名项时拒绝
filemanager.copyItems 把目录里的文件或文件夹（连同里面的内容）复制进另一个文件夹
filemanager.makeFolder 在目录里的文件夹中新建子文件夹，名称取 name，重名时依次加“ (2)”“ (3)”…
filemanager.blankKinds 能新建的空白镜像种类
filemanager.imagePath 镜像文件在磁盘上的完整路径，给外壳用：载入软驱、在文件管理器里显示

filemanager.setRoot

界面里只能由主进程发起，调试服务可以调用

设置目录并开始监视与扫描（目录里的镜像文件与文件夹有变化时核心自己重新扫描）；path 为 null 表示取消。路径只来自用户在系统窗口里选的文件夹，界面不能传。

参数

名称 类型 必填 说明
path string | null 是 目录的路径；null 表示取消

结果

字段 类型 必填 说明
available boolean 是 目录是否存在、能否读取

错误码：filemanager.invalidPath

示例

在 VS Code 的命令“FCDEV：调用调试请求”里输入： 

filemanager.setRoot path=<string | null>

filemanager.tree

目录里一个文件夹的直接内容：全部子文件夹（空文件夹也列出）与全部文件（不分扩展名，含隐藏文件；支持的种类是软盘镜像 img、ima、vfd、dsk、flp、do、po、nib、woz，nes 卡带，png 图片，以及录音机支持的音频 m4a、mp3、wav、aac、flac、ogg、opus、mp4、mka，其他文件标为 unsupported），文件夹在前、按名称排序；只读这一层的文件名、大小与种类，不读文件内容，不递归。

参数

名称 类型 必填 说明
directory string（长度 ..1024） 是 目录里的相对文件夹路径；空串是目录本身

结果

字段 类型 必填 说明
root string | null 是 目录的路径，用来显示；没有设置时为 null
available boolean 是 目录是否存在、能否读取
nodes filemanager.ImageNode[] 是 这个文件夹里的节点，文件夹在前、名称排序；path 是节点相对目录的完整路径

错误码：filemanager.invalidPath

示例

在 VS Code 的命令“FCDEV：调用调试请求”里输入： 

filemanager.tree directory=<string>

filemanager.list

列出镜像里一个文件夹的内容（directory 为空是根目录），顺序与磁盘上的目录一致；镜像插在软驱里时读软驱里的盘片，否则读文件。

参数

名称 类型 必填 说明
image string（长度 1..1024） 是 镜像的相对路径
directory string（长度 1..255）[] 是 镜像里的文件夹路径，逐级的名称；空数组是根目录

结果

字段 类型 必填 说明
fileSystem filemanager.FileSystemInfo 是
capacity integer（0..） 是 文件系统能存放文件内容的全部空间（字节）：FAT 按簇、DOS 3.3 与金字塔 DOS 按扇区、ProDOS 按块算
freeSpace integer（0..） 是 现在还空着的空间（字节）
entries filemanager.EntryInfo[] 是 目录里的条目
drive integer | null 是 镜像插在哪个软驱里（编号从 0 起）；没有插入时为 null
readOnlyReason string | null 是 不能修改的原因（位流格式、软驱里的盘片写保护）；可以修改时为 null
undoDepth integer（0..） 是 这个镜像里可以撤销的操作数

错误码：filemanager.noRoot、filemanager.invalidPath、filemanager.imageNotFound、filemanager.imageUnreadable、filemanager.unknownFormat、filemanager.entryNotFound、filemanager.corrupt

示例

在 VS Code 的命令“FCDEV：调用调试请求”里输入： 

filemanager.list image=<string> directory=<string>

filemanager.rename

重命名镜像里的条目（不改所在文件夹）；立即生效：镜像插在软驱里时改软驱里的盘片并随后写回文件，否则直接改文件。名称规则按文件系统：FAT 是 8.3，DOS 3.3 最长 30 个字符，ProDOS 最长 15 个字符。

参数

名称 类型 必填 说明
image string（长度 1..1024） 是 镜像的相对路径
entry string（长度 1..255）[] 是 条目的路径：从根目录开始逐级的名称

结果

（无）

错误码：filemanager.noRoot、filemanager.invalidPath、filemanager.imageNotFound、filemanager.imageUnreadable、filemanager.unknownFormat、filemanager.readOnly、filemanager.entryNotFound、filemanager.exists、filemanager.invalidName、filemanager.corrupt、filemanager.saveFailed

示例

filemanager.rename image=<string> entry=<string> name=<string>

结果

filemanager.undo

参数

名称 类型 必填 说明
image string（长度 1..1024） 是 镜像的相对路径

结果

字段 类型 必填 说明

filemanager.treeChanged

目录的树变了：文件夹或文件被创建、删除、改名；用 filemanager.tree 重新读取已经展开的文件夹。

（无）

filemanager.imageChanged

一个镜像的内容变了：管理操作、机器写盘、别的程序改了镜像文件；正在查看它的界面要重新读取。

字段 类型 必填 说明
image string 是 镜像的相对路径

数据类型

ImageNode

目录树里的一个节点：文件（软盘镜像、卡带、音频、图片、不支持的文件）或文件夹。

字段 类型 必填 说明
path string 是 相对目录的路径，用 / 分隔，不以 / 开头
name string 是 完整的文件名或文件夹名
directory boolean 是 是否是文件夹
kind string 是 种类：folder（文件夹）、floppy（软盘镜像）、cartridge（nes 卡带）、audio（录音机支持的音频）、picture（png 图片）、unsupported（其他文件，包括隐藏文件与符号链接）
size integer（0..） 是 文件的大小（字节）；文件夹为 0
formatName string 是 界面显示的文件种类名称：NES 卡带、PNG 图片、MP3 音频这样的名称，不支持的文件是“不支持”；文件夹与软盘镜像为空（软盘镜像的文件系统格式在 filemanager.list 的 fileSystem 里）

FileSystemInfo

一个镜像的文件系统。

字段 类型 必填 说明
format string 是 格式标识：fat12、fat16、appledos33、prodos、pascal（Apple Pascal，只读）、pyramid（金字塔 PEC-9588，只读）
formatName string 是 界面显示的格式名称
writable boolean 是 能否修改文件系统里的内容
subdirectories boolean 是 有没有子目录：没有时不能新建文件夹，也不能移动文件

EntryInfo

镜像里的一个文件或文件夹。

字段 类型 必填 说明
name string 是 完整名称
directory boolean 是 是否是文件夹
type string 是 类型文字：FAT 是扩展名，DOS 3.3、金字塔 DOS、ProDOS 与 Apple Pascal 是类型名，文件夹是“文件夹”
size integer（0..） 是 大小（字节）；文件夹为 0
sizeIsAllocated boolean 是 大小是占用的空间而不是准确的字节数（DOS 3.3 与金字塔 DOS 只知道占用的扇区数）
modified string 是 修改时间，形如 2026-11-25 14:30；文件系统没有时间时为空
locked boolean 是 只读或锁定的标记，只作显示

BlankKind

一种能新建的空白镜像。

字段 类型 必填 说明
id string 是 标识：fat1440、fat720、fat2880、fat1200、fat360、appledos33、prodos、pyramid（金字塔 PEC-9588，扩展名 nib，266240 字节，已格式化）
title string 是 界面显示的名称
extension string 是 新建文件的扩展名，不带点

ExportItem

导出的一个文件或文件夹。

字段 类型 必填 说明
path string[] 是 在导出的内容里的路径：第一项是选中条目的 Windows 文件名，其后是它里面的层级
directory boolean 是 是否是文件夹（文件夹没有内容）
content string 是 文件的内容，Base64 编码；文件夹为空

ImportOutcome

导入一个文件或文件夹的结果。

字段 类型 必填 说明
name string 是 拖入的文件或文件夹的名称
ok boolean 是 是否成功
message string 是 失败的原因，面向用户；成功时为空
