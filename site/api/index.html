调试接口手册

请求与事件总览

调试服务的全部请求与事件，按模块分页。连接、认证、报文格式、二进制帧、限制与关闭码见连接与报文。

错误

错误响应的 error.code 是 JSON-RPC 错误码（-32700 报文不是 JSON、-32600 不是合法请求、-32601 方法不存在、-32602 参数不合格、-32603 核心内部错误、-32000 业务错误），error.data.code 是模块登记的错误码（如 runtime.noCartridge）。扩展的调试客户端把它抛成 EmberRequestError（code 为错误码）。

模块

cartridges

请求 简介
cartridges.load 读取 NES 文件，解析文件头，按 mapper 号与变体匹配插件，装配主机并插入卡槽
cartridges.eject 取出卡带：主机随之拆除，电源状态变为断电
cartridges.info 当前卡带的描述、匹配到的插件与存储区清单

事件：cartridges.loaded

debug

请求 简介
debug.hello 握手：每条连接上第一个请求必须是它，令牌不对时连接被关闭（关闭码 4001）
debug.subscribe 订阅事件
debug.unsubscribe 取消订阅：写法要与订阅时一致
debug.status 调试服务的状态：是否开启、是否在监听、端口与当前的连接

事件：debug.statusChanged、debug.eventsDropped

input

请求 简介
input.getBindings 读取手柄绑定：两个玩家槽位（对应手柄口 1、2）
input.setBindings 替换全部手柄绑定：核心校验后保存到文件，并发出 input.bindingsChanged
input.resetBindings 把手柄绑定恢复为出厂默认
input.getFamilyKeyboard 读取是否给经典 FC 接上了 Family BASIC 键盘
input.setFamilyKeyboard 给经典 FC 接入或断开 Family BASIC 键盘：对当前主机立即生效，之后装配的主机也按它设置
input.key 按下或松开一个物理键：键盘属于机器时交给机器，否则按手柄绑定变成手柄口的按键
input.mouse 鼠标事件，交给机器
input.gamepad 游戏手柄一个手柄的当前全部状态，按手柄绑定变成手柄口的按键
input.pad 直接设置主机某个手柄口上标准手柄的按键，不经 mapper 脚本
input.releaseAll 松开经 key 按下的全部键、把经 pad 设置过的手柄口清零、并让经 gamepad 注入的手柄断开

事件：input.bindingsChanged、input.familyKeyboardChanged

inspector

请求 简介
inspector.listSpaces 列出全部内存空间：总线视角的 cpu 与 ppu，主板与芯片里的存储，以及卡带上的存储区（cart.<存储区标识>）
inspector.readMemory 读一段内存，不改变主机的任何状态：cpu 与 ppu 空间里寄存器类地址读出 0（不读寄存器，所以不会清标志），卡带脚本的寄存器也不会被回调
inspector.writeMemory 写一段内存
inspector.resolve 解析一个总线地址：它落在哪块存储区的哪个偏移，或哪个寄存器
inspector.getState 读状态：cpu（寄存器与周期数）、ppu（扫描线、点、帧数、滚动寄存器、标志）与卡带的脚本状态（mapper）
inspector.snapshot 取得完整快照：各模块的状态、断点与监视项，以及此刻的 CPU 周期数，都在同一个时刻读出，是一致的
inspector.watch 监视一个状态项：它的取值变化时发事件 inspector.stateChanged
inspector.unwatch 取消监视
inspector.disassemble 从 address 起反汇编 count 条指令（CPU 总线上的地址）
inspector.cdlStart 开始代码与数据标记（CDL）：给卡带 PRG-ROM 的每个字节打标记，标记清零后，运行与单步执行的每条指令都记：Code（0x01，被当作指令执行，含操作数字节）、Data（0x02，被指令当数据读取，不含只写的存储指令、栈与中断向量）、JumpTarget（0x04，JMP 或成立的分支的目标）、SubEntry（0x08，JSR 的目标）
inspector.cdlStop 停止标记，已有的标记保留到下一次 cdlStart 或换卡带
inspector.cdlSave 把当前的标记写成调试输出目录下的文件：PRG-ROM 每个字节一个标记字节，没有文件头，位定义同 Mesen
inspector.traceStart 开始跟踪，内容记在内存里，traceStop 时写成调试输出目录下的文件
inspector.traceStop 结束跟踪并把内容写成文件
inspector.callLogStart 开始调用记录：每次执行到 address 这条指令之前记一行，含寄存器、周期数、栈顶的若干字节（SP 之上，栈顶在前）与指定的内存段
inspector.callLogStop 结束调用记录并把内容写成文件
inspector.addBreakpoint 添加断点
inspector.listBreakpoints 列出全部断点，按编号升序
inspector.removeBreakpoint 删除一个断点
inspector.clearBreakpoints 删除全部断点
inspector.setState 修改一个模块的状态：目前只有 cpu 可以改（pc、a、x、y、sp、status，只在指令之间生效），其余模块只读

事件：inspector.stateChanged

machines

请求 简介
machines.list 机型清单，顺序固定为 fc、sb97、sb2000、bbg1、bbg98、pec9588、pec586、yuxing
machines.setRom 读取并检查 ROM 文件，复制进 ROM 目录（新文件写好之后才删旧文件，失败时原有的 ROM 不变）
machines.setRoms 读取目录里的 .bin 文件（不含子目录，按文件名排序），按内容的校验值认出各是哪个机型的 ROM，把还没有 ROM 的机型的 ROM 添加进来
machines.removeRom 删除机型的 ROM 文件
machines.boot 整机机型开机：读入已设置的 ROM，装配该机型的主机，已有的卡带与主机被替换，任何一步失败都不改动原有的

事件：machines.changed

mappers

请求 简介
mappers.list 列出生效的插件：同一标识有多个来源时只列版本最高的，版本相同时用户安装的优先
mappers.info 返回一个插件的摘要与清单详情
mappers.install 安装一个 .emap 插件包：检查通过后放进用户插件目录
mappers.uninstall 卸载用户安装的插件
mappers.setEnabled 启用或停用一个插件
mappers.reload 重新读取预装目录与用户目录里的插件包，下次装配或硬复位时生效

事件：mappers.changed

media

请求 简介
media.floppyInsert 读取盘片镜像文件（上限 16 MB）放进驱动器，替换已有的盘片
media.floppyEject 取出盘片并丢弃镜像
media.floppySave 立即把驱动器里的镜像写回放入时的文件，并清除“已修改”标志
media.floppyWriteProtect 设置或取消盘片的写保护
media.floppyStatus 全部软驱的状态
media.floppyFault 故障注入：取盘、写保护、无索引脉冲、磁头卡住、控制器无响应、指定扇区校验错、全部清除
media.printerStatus 打印机的状态：空闲、打印中、打印完成，当前页是否有内容，已输出的页数与最近一页的文件名
media.printerFlush 立即输出当前页，等同打印机收到换页
media.tapeLoad 把声音文件放进磁带机当磁带（解码由核心内置的 FFmpeg 库完成，m4a、mp3、wav 等都可以），位置回到开头，替换已有的磁带
media.tapeEject 取出磁带
media.tapePlay 开始播放
media.tapeRecord 开始录音：录的是主机的声音（游戏、学习机里的声音）加主机经数据线送来的 1 位信号，与主机型号无关
media.tapeStop 停止播放或录音
media.tapeStatus 磁带机的状态
media.tapeSeek 把磁带定位到某个位置
media.tapeTimeline 磁带的时间轴：载入磁带后核心在后台读一遍声音，得出数据线上各时刻的声音大小与空白段，用来在磁带上找到程序的位置

事件：media.changed、media.tapeAnalyzed、media.printed、media.printFailed、media.floppySaveFailed

output

请求 简介
output.setVolume 设置声音的音量与静音
output.screenshot 截取最近一次完成的画面（256x240，暂停与断电后也有上一帧）

preferences

请求 简介
preferences.list 列出全部分组与设置项（含当前取值）
preferences.set 修改一个设置项：核心按登记的种类校验取值，保存到文件，并发出 preferences.changed
preferences.reset 把一个设置项恢复为出厂默认值

事件：preferences.changed

runtime

请求 简介
runtime.status 返回电源、运行模式、主机型号、卡带、帧号、总周期数、速度与是否带鼠标
runtime.powerOn 上电：创建或重置全部芯片，卡带的存储区重新从文件载入
runtime.powerOff 断电：停止运行，芯片状态丢弃
runtime.reset 复位：soft 只发 RESET 线，不改变电源与运行模式
runtime.pause 暂停：已暂停时没有效果
runtime.resume 继续：按真实帧率连续运行
runtime.run 授权运行：不限速地连续运行指定的帧数后暂停（运行中不输出声音，每帧之间照常处理输入等命令）
runtime.step 单步：先暂停（正在进行的授权运行被打断），再按单位运行指定的数量后保持暂停
runtime.setFrameEvents 设置 runtime.frame 事件的发布间隔：每 frames 帧发一次，0 表示不发（默认）

事件：runtime.stateChanged、runtime.frame、runtime.runFinished、runtime.breakpointHit、runtime.error

system

请求 简介
system.version 返回应用版本与核心版本

rpc

请求 简介
rpc.discover 返回本文档
