请求

请求 简介
input.getBindings 读取手柄绑定：两个玩家槽位（对应手柄口 1、2）
input.setBindings 替换全部手柄绑定：核心校验后保存到文件，并发出 input.bindingsChanged
input.resetBindings 把手柄绑定恢复为出厂默认
input.getFamilyKeyboard 读取是否给经典 FC 接上了 Family BASIC 键盘
input.setFamilyKeyboard 给经典 FC 接入或断开 Family BASIC 键盘：对当前主机立即生效，之后装配的主机也按它设置
input.key 按下或松开一个物理键：键盘属于机器时交给机器，否则按手柄绑定变成手柄口的按键
input.mouse 鼠标事件，交给机器
input.gamepad 游戏手柄一个手柄的当前全部状态，按手柄绑定变成手柄口的按键
input.pad 直接设置主机某个手柄口上标准手柄的按键，不经 mapper 脚本
input.releaseAll 松开经 key 按下的全部键、把经 pad 设置过的手柄口清零、并让经 gamepad 注入的手柄断开

input.getBindings

读取手柄绑定：两个玩家槽位（对应手柄口 1、2）。

参数

（无）

结果

字段 类型 必填 说明
slots input.PadSlot[] 是 玩家槽位，第 1 项是手柄口 1

错误码：无专有错误码（参数不合格返回 core.invalidParams）

示例

在 VS Code 的命令“fcdev：调用调试请求”里输入：

input.getBindings

input.setBindings

替换全部手柄绑定：核心校验后保存到文件，并发出 input.bindingsChanged；内容没有变化时不发事件。

参数

名称 类型 必填 说明
slots input.PadSlot[] 是 玩家槽位，第 1 项是手柄口 1

结果

字段 类型 必填 说明
slots input.PadSlot[] 是 保存之后的玩家槽位

错误码：input.invalidBindings

示例

在 VS Code 的命令“fcdev：调用调试请求”里输入：

input.setBindings slots=<input.PadSlot[]>

input.resetBindings

把手柄绑定恢复为出厂默认；内容没有变化时不发事件。

参数

（无）

结果

字段 类型 必填 说明
slots input.PadSlot[] 是 恢复之后的玩家槽位

错误码：无专有错误码（参数不合格返回 core.invalidParams）

示例

在 VS Code 的命令“fcdev：调用调试请求”里输入：

input.resetBindings

input.getFamilyKeyboard

读取是否给经典 FC 接上了 Family BASIC 键盘；每次启动都是未接入，不保存。

参数

（无）

结果

字段 类型 必填 说明
connected boolean 是 是否已接入

错误码：无专有错误码（参数不合格返回 core.invalidParams）

示例

在 VS Code 的命令“fcdev：调用调试请求”里输入：

input.getFamilyKeyboard

input.setFamilyKeyboard

给经典 FC 接入或断开 Family BASIC 键盘：对当前主机立即生效，之后装配的主机也按它设置；接入后电脑键盘的按键按 Family BASIC 键盘的键位送给机器，不再当作手柄按键；学习机用自己内置的键盘，不受影响。状态只在本次运行里保留，不保存；有变化时发出 input.familyKeyboardChanged。

参数

名称 类型 必填 说明
connected boolean 是 true 接入，false 断开

结果

字段 类型 必填 说明
connected boolean 是 设置之后是否已接入

错误码：无专有错误码（参数不合格返回 core.invalidParams）

示例

在 VS Code 的命令“fcdev：调用调试请求”里输入：

input.setFamilyKeyboard connected=<boolean>

input.key

只经调试服务开放（界面不能发起）

按下或松开一个物理键：键盘属于机器时交给机器，否则按手柄绑定变成手柄口的按键；没有开机时被丢弃。

参数

名称 类型 必填 说明
code string（长度 1..32） 是 物理键位，取 KeyboardEvent.code，如 KeyW、Space、Numpad1、Enter
down boolean 是 true 按下，false 松开

结果

（无）

错误码：无专有错误码（参数不合格返回 core.invalidParams）

示例

在 VS Code 的命令“fcdev：调用调试请求”里输入：

input.key code=<string> down=<boolean>

input.mouse

只经调试服务开放（界面不能发起）

鼠标事件，交给机器；坐标单位是标准帧（256x240）的像素，省略的数值按 0 处理。

参数

名称 类型 必填 说明
kind "move" | "down" | "up" | "wheel" | "leave" 是 事件种类
x number 否 指针在标准帧上的横坐标，可以超出画面范围
y number 否 指针在标准帧上的纵坐标，可以超出画面范围
dx number 否 相对上一次事件的横向位移
dy number 否 相对上一次事件的纵向位移
buttons integer（0..7） 否 当前按住的按键位：1 左键、2 右键、4 中键
wheel number 否 滚轮的滚动量，向下为正，只有 wheel 事件用

结果

（无）

错误码：无专有错误码（参数不合格返回 core.invalidParams）

示例

在 VS Code 的命令“fcdev：调用调试请求”里输入：

input.mouse kind=<"move" | "down" | "up" | "wheel" | "leave">

input.gamepad

只经调试服务开放（界面不能发起）

游戏手柄一个手柄的当前全部状态，按手柄绑定变成手柄口的按键；拔掉时 connected 为 false，按键与轴省略。

参数

名称 类型 必填 说明
index integer（0..7） 是 手柄编号，同浏览器 Gamepad API 的 index
id string（长度 ..256） 否 手柄的设备标识，取 Gamepad.id；省略时按空处理
connected boolean 是 是否连着
buttons boolean[] 否 各按键是否按下，顺序同浏览器的标准映射
axes number[] 否 各轴的值，范围 -1 到 1，顺序同浏览器的标准映射

结果

（无）

错误码：无专有错误码（参数不合格返回 core.invalidParams）

示例

在 VS Code 的命令“fcdev：调用调试请求”里输入：

input.gamepad index=<integer> connected=<boolean>

input.pad

只经调试服务开放（界面不能发起）

直接设置主机某个手柄口上标准手柄的按键，不经 mapper 脚本；位：1 A、2 B、4 选择、8 开始、16 上、32 下、64 左、128 右。

参数

名称 类型 必填 说明
port integer（0..7） 是 手柄口编号，从 0 开始
buttons integer（0..255） 是 按键掩码，1 表示按下

结果

（无）

错误码：input.invalidPort

示例

在 VS Code 的命令“fcdev：调用调试请求”里输入：

input.pad port=<integer> buttons=<integer>

input.releaseAll

只经调试服务开放（界面不能发起）

松开经 key 按下的全部键、把经 pad 设置过的手柄口清零、并让经 gamepad 注入的手柄断开。

参数

（无）

结果

（无）

错误码：无专有错误码（参数不合格返回 core.invalidParams）

示例

在 VS Code 的命令“fcdev：调用调试请求”里输入：

input.releaseAll

事件

事件要先用 debug.subscribe 订阅才会收到，以 JSON-RPC 通知送达。

input.bindingsChanged

手柄绑定变了（界面修改、恢复默认都会发出）。

字段 类型 必填 说明
slots input.PadSlot[] 是 新的玩家槽位

input.familyKeyboardChanged

Family BASIC 键盘的接入状态变了（界面或调试服务设置后发出，没有变化时不发）。

字段 类型 必填 说明
connected boolean 是 新的接入状态

数据类型

PadKeyBinding

手柄的一个键绑定到键盘的一个物理键。

字段 类型 必填 说明
button "a" | "b" | "select" | "start" | "up" | "down" | "left" | "right" | "turboA" | "turboB" 是 手柄的键：turboA、turboB 是连发 A、连发 B
code string（长度 1..32） 是 物理键位，取 KeyboardEvent.code，如 KeyZ、ArrowUp、Enter

PadGamepadBinding

手柄的一个键绑定到实体手柄的一个按钮或一个轴的一个方向。

字段 类型 必填 说明
button "a" | "b" | "select" | "start" | "up" | "down" | "left" | "right" | "turboA" | "turboB" 是 手柄的键
kind "button" | "axis" 是 来源：button 是一个按钮，axis 是一个轴的一个方向
index integer（0..31） 是 按钮或轴的编号，同浏览器 Gamepad API 的数组下标
direction "negative" | "positive" 否 轴的方向：negative 是小于 -0.5，positive 是大于 0.5；只有 axis 用

PadGamepadAssignment

一个玩家槽位用的实体手柄，以及它的键绑定。

字段 类型 必填 说明
id string（长度 1..256） 是 手柄的设备标识，取 Gamepad.id（含设备名）
occurrence integer（0..15） 是 同一个设备标识连着多个手柄时，按编号从小到大排的第几个，从 0 开始
bindings input.PadGamepadBinding[] 是 手柄的键的绑定；没有写的键没有绑定，同一个键只能写一次

PadSlot

一个玩家槽位：键盘的绑定，以及可选的一个实体手柄。

字段 类型 必填 说明
keys input.PadKeyBinding[] 是 键盘的绑定；没有写的键没有绑定，同一个键只能写一次
gamepad input.PadGamepadAssignment 否
