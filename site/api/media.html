请求

请求 简介
media.floppyInsert 读取盘片镜像文件（上限 16 MB）放进驱动器，替换已有的盘片
media.floppyEject 取出盘片并丢弃镜像
media.floppySave 立即把驱动器里的镜像写回放入时的文件，并清除“已修改”标志
media.floppyWriteProtect 设置或取消盘片的写保护
media.floppyStatus 全部软驱的状态
media.floppyFault 故障注入：取盘、写保护、无索引脉冲、磁头卡住、控制器无响应、指定扇区校验错、全部清除
media.printerStatus 打印机的状态：空闲、打印中、打印完成，当前页是否有内容，已输出的页数与最近一页的文件名
media.printerFlush 立即输出当前页，等同打印机收到换页
media.tapeLoad 把声音文件放进磁带机当磁带（解码由核心内置的 FFmpeg 库完成，m4a、mp3、wav 等都可以），位置回到开头，替换已有的磁带
media.tapeEject 取出磁带
media.tapePlay 开始播放
media.tapeRecord 开始录音：录的是主机的声音（游戏、学习机里的声音）加主机经数据线送来的 1 位信号，与主机型号无关
media.tapeStop 停止播放或录音
media.tapeStatus 磁带机的状态
media.tapeSeek 把磁带定位到某个位置
media.tapeTimeline 磁带的时间轴：载入磁带后核心在后台读一遍声音，得出数据线上各时刻的声音大小与空白段，用来在磁带上找到程序的位置

media.floppyInsert

界面里只能由主进程发起，调试服务可以调用

读取盘片镜像文件（上限 16 MB）放进驱动器，替换已有的盘片；软驱是独立于主机的设备，没有主机、没有通电时也可以插入。镜像的格式由大小推断（160、180、320、360、720、1200、1440、2880 KB，其他大小按 1.44MB 处理）。

参数

名称 类型 必填 说明
drive integer（0..3） 是 驱动器编号
path string（长度 1..） 是 镜像文件的路径
writeProtected boolean 否 是否写保护，默认 false

结果

字段 类型 必填 说明
status media.FloppyStatus 是

错误码：media.noDrive、media.fileNotFound、media.fileUnreadable、media.imageInvalid、media.saveFailed

示例

在 VS Code 的命令“FCDEV：调用调试请求”里输入： 

media.floppyInsert drive=<integer> path=<string>

media.floppyEject

取出盘片并丢弃镜像；有尚未写回的修改时先写回放入时的文件，写回失败则不取出；没有盘片时没有效果。

参数

名称 类型 必填 说明
drive integer（0..3） 是 驱动器编号

结果

字段 类型 必填 说明
status media.FloppyStatus 是

错误码：media.noDrive、media.saveFailed

示例

在 VS Code 的命令“FCDEV：调用调试请求”里输入：

media.floppySave

参数

名称 类型 必填 说明
drive integer（0..3） 是 驱动器编号

结果

字段 类型 必填 说明
status media.FloppyStatus 是

错误码：media.noDrive、media.noDisk、media.saveFailed

示例

media.floppySave drive=<integer>

media.floppyWriteProtect

参数

名称 类型 必填 说明
drive integer（0..3） 是 驱动器编号
writeProtected boolean 是 是否写保护

结果

字段 类型 必填 说明
status media.FloppyStatus 是

错误码：media.noDrive

示例

media.floppyStatus

全部软驱的状态；软驱是独立于主机的设备，一直存在（目前只有软驱 A）。

参数

（无）

结果

字段 类型 必填 说明
drives media.FloppyStatus[] 是 各驱动器的状态，按编号排列

错误码：无专有错误码（参数不合格返回 core.invalidParams）

示例

在 VS Code 的命令“FCDEV：调用调试请求”里输入： 

media.floppyStatus

media.floppyFault

只经调试服务开放（界面不能发起）

故障注入：取盘、写保护、无索引脉冲、磁头卡住、控制器无响应、指定扇区校验错、全部清除；用来检查学习机程序对软驱故障的处理。

参数

名称 类型 必填 说明
drive integer（0..3） 是 驱动器编号
fault "ejected" | "writeProtected" | "noIndex" | "seekFail" | "unresponsive" | "badSector" | "clear" 是 故障：ejected 取盘（放回时内容不变），writeProtected 写保护，noIndex 无索引脉冲，seekFail 磁头卡住，unresponsive 控制器无响应，badSector 指定扇区校验错，clear 关闭全部故障、放回盘片、取消写保护
enabled boolean 否 打开还是关闭这个故障，默认 true；clear 不用这一项
sector integer（0..） 否 badSector 的逻辑扇区号（磁道×每道扇区数×面数 + 磁头×每道扇区数 + 扇区号 - 1），badSector 必填

结果

字段 类型 必填 说明
status media.FloppyStatus 是

错误码：media.noDrive、media.sectorRequired

示例

在 VS Code 的命令“FCDEV：调用调试请求”里输入： 

media.floppyFault drive=<integer> fault=<"ejected" | "writeProtected" | "noIndex" | "seekFail" | "unresponsive" | "badSector" | "clear">

（无）

media.tapeLoad

界面里只能由主进程发起，调试服务可以调用

把声音文件放进磁带机当磁带（解码由核心内置的 FFmpeg 库完成，m4a、mp3、wav 等都可以），位置回到开头，替换已有的磁带；磁带机与主机无关，没有主机、没有通电时也可以载入；磁带机播放或录音时不能载入。播放时磁带的声音（立体声取左声道，单声道取唯一的声道）经主机的声音输出播放；单声道文件整路是数据线，立体声文件右声道是数据线。

参数

名称 类型 必填 说明
path string（长度 1..） 是 声音文件的路径

结果

字段 类型 必填 说明
status media.TapeStatus 是

错误码：media.tapeBusy、media.fileNotFound、media.fileUnreadable、media.tapeUnsupported

示例

在 VS Code 的命令“FCDEV：调用调试请求”里输入： 

media.tapeLoad path=<string>

media.tapeEject

取出磁带；没有磁带时没有效果；播放或录音时先停止再取出（录音的文件先写完）。

参数

（无）

结果

字段 类型 必填 说明
status media.TapeStatus 是

错误码：无专有错误码（参数不合格返回 core.invalidParams）

示例

在 VS Code 的命令“FCDEV：调用调试请求”里输入： 

media.tapeEject

media.tapePlay

开始播放；磁带放完后再播放从头开始；已经在播放或录音时没有效果；主机没有通电时不能播放（暂停也算通电，与主机型号无关）。

参数

（无）

结果

字段 类型 必填 说明
status media.TapeStatus 是

错误码：media.noTape、media.tapeNotConnected

示例

在 VS Code 的命令“FCDEV：调用调试请求”里输入： 

media.tapePlay

media.tapeRecord

界面里只能由主进程发起，调试服务可以调用

开始录音：录的是主机的声音（游戏、学习机里的声音）加主机经数据线送来的 1 位信号，与主机型号无关；给出 path 时放入一盘空白磁带，录成 32 kHz、单声道、16 位的 WAV 文件（已有的文件被覆盖）；没有 path 时在磁带机里已有的磁带上从当前位置开始录，覆盖到哪录到哪，位置之前与录音结束处之后的内容保留，录好的内容写回这盘磁带的文件，磁带文件必须是 WAV（96 kHz、16 位、立体声，新录的部分左右声道相同）；停止后这个文件自动成为磁带机里的磁带，位置停在录音停止处，可以直接播放；磁带机播放或录音时不能开始录音；主机没有通电时不能录音。

参数

名称 类型 必填 说明
path string（长度 1..） 否 录音文件的路径；不给时在磁带机里已有的磁带上录

结果

字段 类型 必填 说明
status media.TapeStatus 是

错误码：media.tapeBusy、media.tapeNotConnected、media.saveFailed、media.noTape、media.tapeNotWritable、media.fileNotFound、media.fileUnreadable、media.tapeUnsupported

示例

在 VS Code 的命令“FCDEV：调用调试请求”里输入： 

media.tapeRecord

media.tapeStop

停止播放或录音；录音停止时把录到的内容写完，文件成为磁带机里的磁带；已经停止时没有效果。

参数

（无）

结果

字段 类型 必填 说明
status media.TapeStatus 是

错误码：media.fileUnreadable、media.tapeUnsupported

示例

在 VS Code 的命令“FCDEV：调用调试请求”里输入： 

media.tapeStop

media.tapeStatus

磁带机的状态；磁带机一直存在，没有接在通电的主机上时 connected 为 false。

参数

（无）

结果

字段 类型 必填 说明
status media.TapeStatus 是

错误码：无专有错误码（参数不合格返回 core.invalidParams）

media.tapeSeek

timeline media.TapeTimeline 是

错误码：无专有错误码（参数不合格返回 core.invalidParams）

示例

在 VS Code 的命令“FCDEV：调用调试请求”里输入： 

media.tapeTimeline

事件

事件要先用 debug.subscribe 订阅才会收到，以 JSON-RPC 通知送达。

media.changed

介质的状态变化：盘片插入、取出、保存、注入故障与马达开关，磁带的载入、取出、播放、录音与停止，磁带机接上或断开主机（connected 变化时随运行状态事件刷新，不另发本事件）。

字段 类型 必填 说明
device "floppy" | "tape" 是 设备
drive integer（0..） 是 驱动器编号；磁带机恒为 0

media.tapeAnalyzed

磁带的时间轴分析结束（完成或失败）；用 media.tapeTimeline 读取结果。

字段 类型 必填 说明
serial integer（0..） 是 分析的是哪一盘磁带（对应 TapeStatus 的 serial）

media.printed

打印机输出了一页：已经保存成 PNG 文件。

字段 类型 必填 说明
fileName string 是 文件名，不含路径
page integer（1..） 是 本次运行以来的页序号

media.printFailed

打印机输出的一页无法保存（目录无法写入等），这一页已丢弃。

字段 类型 必填 说明
message string 是 原因，面向用户

media.floppySaveFailed

盘片镜像无法自动写回文件（文件被占用、没有写权限等）；修改仍在内存里，核心之后每 5 秒重试一次，写回成功前只通知这一次。

字段 类型 必填 说明
drive integer（0..） 是 驱动器编号
message string 是 原因，面向用户

数据类型

FloppyFaults

软驱上注入的故障；全部关闭是正常状态。

字段 类型 必填 说明
ejected boolean 是 取盘：盘片被暂时取出（镜像还在，放回后内容不变）
noIndex boolean 是 没有索引脉冲：读扇区编号、读写与格式化命令一直不结束
seekFail boolean 是 磁头卡住：寻道与回零不移动
unresponsive boolean 是 控制器无响应：收到命令字节后不再处理
badSectors integer（0..）[] 是 读时数据校验出错的逻辑扇区号

FloppyStatus

一个软驱的状态。

字段 类型 必填 说明
drive integer（0..） 是 驱动器编号，从 0 开始
inserted boolean 是 里面有没有盘片
fileName string 否 盘片来源的文件名，不含路径；没有盘片时没有这一项
writeProtected boolean 是 盘片是否写保护
modified boolean 是 镜像是否有尚未写回文件的修改（学习机写盘后置位，核心自动写回后清除）
size integer（0..） 是 镜像的大小（字节）；没有盘片时为 0
cylinder integer（0..） 是 磁头所在的磁道
motor boolean 是 马达是否在转
faults media.FloppyFaults 是

PrinterStatus

并口打印机的状态。

字段 类型 必填 说明
state "idle" | "printing" | "done" 是 状态：idle 空闲（机器没有运行，或还没有内容），printing 打印中（当前页上有内容），done 打印完成（输出过一页且下一页还没有内容）
hasContent boolean 是 当前页上是否已经有内容
pages integer（0..） 是 本次运行以来已输出的页数
lastFile string 否 最近一页的文件名，不含路径；还没有输出过时没有这一项
directory string 是 图片保存的目录（首选项“打印机”里设置的位置，留空时是用户数据目录下的 printer-output）

TapeStatus

磁带机的状态。

字段 类型 必填 说明
connected boolean 是 磁带机是否接在通电的主机上（有主机并已通电，暂停也算，与主机型号无关）；没接上时可以载入与取出磁带，但不能播放与录音
loaded boolean 是 里面有没有磁带
fileName string 否 磁带（声音文件）的文件名，不含路径；没有磁带时没有这一项
mode "stopped" | "playing" | "recording" 是 工作状态：stopped 停止，playing 播放，recording 录音
position number（0..） 是 当前位置（秒）；录音时是已录的时长
duration number（0..） 是 总时长（秒）；不知道或没有磁带时为 0
stereo boolean 是 是否是立体声磁带：是则左声道是声音、右声道是数据；否则整路既是声音也是数据
serial integer（0..） 是 磁带的序号：每放入、取出或换掉一盘磁带加 1（同一个文件重新放入也加 1），时间轴据此判断读到的是不是当前这盘磁带的

TapeBlank

磁带上的一段空白：数据线上连续没有声音的一段。

字段 类型 必填 说明
start number（0..） 是 起点（秒）
end number（0..） 是 终点（秒）

TapeTimeline

磁带的时间轴：数据线上各时刻的声音大小与空白段，载入磁带后由核心在后台分析。

字段 类型 必填 说明
serial integer（0..） 是 分析的是哪一盘磁带（对应 TapeStatus 的 serial）；没有磁带时为当前的序号，其余项为空
state "none" | "analyzing" | "ready" | "failed" 是 状态：none 没有磁带或没有可分析的内容，analyzing 分析中，ready 分析完成，failed 分析失败（文件无法读取或解码）
progress number（0..1） 是 分析的进度，0 到 1；分析完成时为 1
duration number（0..） 是 磁带的总时长（秒），按实际解码出的采样数算；分析完成后才有，否则为 0
step number（0..） 是 peaks 里每一项占的时间（秒）；分析完成后才有，否则为 0
peaks integer（0..100）[] 是 数据线的声音大小：每 step 秒一项，取这段时间里的最大幅度占满幅的百分比（有声音时至少为 1）；分析完成后才有
blanks media.TapeBlank[] 是 空白段，按时间排列：连续 0.5 秒以上、幅度低于满幅 3% 的一段（含磁带开头与结尾的空白）；分析完成后才有
