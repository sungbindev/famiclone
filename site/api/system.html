调试接口手册

system 模块

连接、认证与报文规则见连接与报文，全部请求见请求与事件总览。

请求

请求 简介
system.version 返回应用版本与核心版本

system.version

返回应用版本与核心版本。

参数

（无）

结果

字段 类型 必填 说明
appVersion string（长度 1..） 是 应用版本，取自程序的版本号
coreVersion string（长度 1..） 是 核心版本，取自核心的构建参数

错误码：无专有错误码（参数不合格返回 core.invalidParams）

示例

在 VS Code 的命令“FC Dev：调用调试请求”里输入：

system.version

数据类型

UpdateStatus

应用升级的状态；只由外壳维护。

字段 类型 必填 说明
state "unsupported" | "idle" | "checking" | "downloading" | "ready" | "upToDate" | "error" 是 unsupported 当前运行方式不支持升级（开发版、免安装目录、非 Windows），idle 还没有检查过，checking 正在检查，downloading 发现新版本、正在下载，ready 新版本已下载、重启后生效，upToDate 已是最新版本，error 检查或下载失败
version string（长度 1..） 否 新版本的版本号，只在 ready 时有，升级服务器没有给出版本号时没有这一项
message string（长度 1..） 否 失败的原因，只在 error 时有
