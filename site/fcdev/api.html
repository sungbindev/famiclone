本文由运行库头文件 sb2000-*.h 的文档注释生成。 共 204 个函数，17 个模块。随时查询用命令“FCDEV：查询 C 接口”（或 Copilot 工具 fcdev_api）：输入函数名看完整文档，输入模块名看模块的函数列表，输入 $7B 看用到某个系统调用的函数，输入其他词按名称与说明搜索。

约定：

  • 所有函数用 #include <sb2000.h> 引入；返回 DOS 出错码或软驱状态码的函数，0 表示成功，结果经指针参数带回。
  • 字符串、缓冲区、结构体指针必须在程序窗口 $8000-$BFFF 里（系统服务换页后程序窗口不可见的，函数内部已经处理好，调用者不用管）。
  • 程序最大 16K（窗口 $8000-$BFFF，C 软件栈占顶端 1K）。
  • 汇编程序调用这些函数时，函数名前加下划线（如 _sb_puts），参数按 cc65 的 fastcall 约定传递；系统调用号、地址与寄存器的符号见 SB2000 符号参考。

sb_disk_read_sectors 

unsigned char sb_disk_read_sectors(unsigned char head, unsigned char track, unsigned char sector, unsigned char page, unsigned char page_sector, unsigned int count, unsigned char mode);

从起始扇区连续读若干扇区到扩展 RAM 页里，扇区号递增，满 18 换面，两面满换磁道。先检测盘片。

系统调用：$80/$04

参数：

  • head：起始面，0 或 1。
  • track：起始磁道，0 到 79。
  • sector：起始扇区号，1 到 18。
  • page：接收数据的扩展 RAM 页号。
  • page_sector：数据从页内第几个 512 字节开始放，0 到 7；每页放 8 个扇区，页要有足够的连续页。
  • count：扇区数。
  • mode：SB_DISK_STOP_ON_ERROR 或 SB_DISK_SKIP_ERRORS，见这两个常量的说明。

返回：0 成功；SB_ERR_NO_DISK 驱动器中没有磁盘；SB_ERR_CRC 等扇区出错码（mode 为 SB_DISK_STOP_ON_ERROR 时）。

系统调用：$80/$05

  • track：起始磁道，0 到 79。
  • sector：起始扇区号，1 到 18。

  • page_sector：数据从页内第几个 512 字节开始，0 到 7。
  • count：扇区数。
  • mode：SB_DISK_STOP_ON_ERROR 或 SB_DISK_SKIP_ERRORS。

返回：0 成功；SB_ERR_WRITE_PROTECT 磁盘写保护；SB_ERR_NO_DISK 驱动器中没有磁盘。

sb_disk_scan_track 

unsigned char sb_disk_scan_track(unsigned char head, unsigned char track, unsigned char *bad_map);

逐个读一个磁道的 18 个扇区，读不出的在位图里置位。不检测盘片，直接读每个扇区。

系统调用：$80/$08

显示、窗口与图片（sb2000-display.h）

函数 说明 系统调用
sb_cells_fill 从指定位置起线性地（先列后行，到行尾接下一行）把 count 个单元写成同一个值，写完刷新一次名称表到显存。 $40
sb_cells_rect 把一个矩形区域的单元写成同一个值，每行刷新一次。 $40
sb_cells_copy 把程序窗口里的一块单元数据逐行复制到屏幕，写完刷新一次名称表。 $40
sb_screen_clear 清屏：把屏幕缓冲里指定名称表的全部单元填成同一个值（只写缓冲，不刷新显存）。 $30/$0A
sb_screen_flush 把一张名称表缓冲经 DMA 写到显存，并等一帧。 $30/$00-$03
sb_cell_address 求屏幕缓冲里一个单元的远地址，可以交给 sb_far_read、sb_far_write 读写。 $30/$04-$07
sb_text_field 在屏幕上显示一行文字（可混排汉字与西文）：把字符串画成点阵写进显存的图块，再把上下两行单元写进名称表缓冲并刷新。 $45
sb_text_field_ascii 同 sb_text_field，但只处理单字节字符，不补空白图块，只写一行单元：第 i 列的单元值是 cell + 步长 × i；步长在大字体（8×16 字模，DOS 的默认）下是 2，小字体下是 1。 $46

屏蔽一个中断源（不再响应它）。中断源用 SB_IRQ_SOURCE_ 开头的常量： 0 定时器，1 鼠标，2 键盘，3 中断 4，4 软驱，5 中断 2，6 中断 1。 屏蔽键盘时系统还向 $4022 写 $40。中断源超出 0-6 时什么都不做。

系统调用：$13/$00-$06

参数：

  • source：中断源，0 到 6。

sb_irq_enable 

void sb_irq_enable(unsigned char source);

允许一个中断源。中断源编号同 sb_irq_mask。 允许定时器时系统设置定时器寄存器；允许鼠标时按鼠标是否接入更新 $0634。 注意：中断源 5、6 的允许，系统用的屏蔽值取自表后相邻字节（原程序的疏漏）： 允许中断源 5 实际清掉的是中断源 6 的屏蔽位，允许中断源 6 会把除定时器外的全部屏蔽位清 0。 不建议对这两个中断源使用。

系统调用：$13/$80-$86

参数：

  • source：中断源，0 到 6。

sb_irq_hook_set 

void sb_irq_hook_set(unsigned char hook, unsigned char group, unsigned int entry);

登记一个中断钩子：对应的中断发生后，系统映射页组并调用入口例程。钩子是汇编例程，在中断里运行，以 RTS 返回，不能调用 C 函数。 钩子号：0 定时器，1 中断 3（系统不会调用它），2 中断 1，3 中断 4，4 鼠标，5 键盘，6 中断 2。 钩子号超出 0-6 时什么都不做。

参数：

  • hook：钩子号，0 到 6。
  • group：钩子所在页组的首页号，自己程序里的例程传 SB_BYTE_AT(SB_PROGRAM_START_PAGE)。
  • entry：入口例程的地址。

sb_irq_hook_reset 

void sb_irq_hook_reset(unsigned char hook);

把一个中断钩子恢复成空钩子。钩子号：0 定时器，1 中断 3，2 中断 1，3 中断 4，4 鼠标，5 键盘。 钩子号超出 0-5 时什么都不做；系统不提供中断 2 钩子的复位。

系统调用：$13/$88

参数：

  • hook：钩子号，0 到 5。

sb_display_option 

unsigned char sb_display_option(unsigned char option, unsigned char value);

把值按位并入显示相关的硬件寄存器并写入硬件。选项与它修改的位： 0 扩展控制 $2008 的位 7；1 $2008 的位 0；2 $2008 的位 2、3；3 $2000 的低 2 位（名称表选择）； 4 精灵显示：$2001 的位 4，同时值非 0 时打开 NMI 里的精灵 DMA；5 $2000 的位 5（8x16 精灵）； 6 $2001 只保留位 1-4 再并入；7 $2001 的位 3（背景显示）。 值要已经放在寄存器相应的位上，如选项 7 打开背景显示传 0x08。

系统调用：$10

参数：

  • option：选项，0 到 7。
  • value：要并入的位。

返回：0 成功；选项超出范围时为 $FF，寄存器不变。

void sb_display_on(void);

系统调用：$1A

sb_system_state 

unsigned char sb_system_state(unsigned char query);

查询显示与系统状态。查询号与结果（位类的结果保持在原来的位上，不移位）： 0 $2008 的位 7；1 $2008 的位 0；2 $2008 的位 2、3；3 $2000 的低 2 位（名称表选择）； 4 $2001 的位 4（精灵显示）；5 $2000 的位 5（精灵尺寸）； 6 显示模式号 0-3，同时把当前字库的位置放进系统的字库参数单元； 7 NMI 服务开关 $0630 的位 1-7，位 0 换成“NMI 是否开着”；8 中断屏蔽影子； 9 鼠标是否在线（1 在线）；10 恒为 1；11 键盘自检结果；12 $2001 的位 3、4（背景与精灵是否显示）。 查询号超出 0-12 时不调用，返回 0。

系统调用：$1E

参数：

  • query：查询号，0 到 12。

返回：查询结果。

sb_system_init 

void sb_system_init(void);

系统硬件与状态初始化：重设显示、中断屏蔽、定时器、各钩子、键盘手柄鼠标状态、系统时钟（12:00:00）、DOS 内部状态等。 程序一般不需要调用，调用后程序此前的显示与输入设置都会丢失。

系统调用：$18

sb_call_banked 

void sb_call_banked(unsigned char group, unsigned int entry);

映射页组到 $8000-$BFFF 后调用其中的例程，例程以 RTS 返回，返回后窗口恢复成调用前的样子。 调用 ROM 里的运行库时页组为 0。要调用自己程序里的函数，页组传 SB_BYTE_AT(SB_PROGRAM_START_PAGE)。

系统调用：$25

参数：

  • group：页组的首页号，连续 4 页。
  • entry：例程在窗口里的地址。

sb_jump_banked

映射页组到 $8000-$BFFF 后跳转到其中的例程，不再回到本函数。 例程的 RTS 直接返回到调用本函数的位置，相当于尾调用。

系统调用：$26

参数：

  • group：页组的首页号，连续 4 页。
  • entry：例程在窗口里的地址。

sb_exec 

unsigned char sb_exec(const char *path);

运行另一个程序，运行完返回。系统按文件大小分配扩展 RAM 页、读入文件、检查文件头魔数 AA 55， 运行完关闭文件并释放页；子程序以 RTS 返回，用的窗口与页都是它自己的，不影响本程序。

系统调用：$7F/$00

参数：

  • path：程序的路径，零结尾，最长 28 个字符。

返回：0 成功；SB_ERR_FILE_NOT_FOUND 文件不存在；$3E 文件头魔数不符；SB_ERR_NO_MEMORY 没有足够的连续空闲页。

sb_stack_pointer 

unsigned char sb_stack_pointer(void);

取硬件栈指针。返回的是本函数被调用之后的值，即调用者的栈指针减 2。

返回：硬件栈指针的低字节（高字节固定为 $01）。

sb_context_save 

void sb_context_save(unsigned char group, unsigned int entry, unsigned char stack_pointer);

把一个恢复点压入系统的上下文栈（最多 10 项，满了不保存），类似 setjmp。 之后 sb_context_restore 或按 ESC 中断（sb_break_enable）会取出它，把硬件栈指针设成保存的值并跳到入口例程。 入口例程是新的执行起点，不要用 RTS 返回。

系统调用：$1C

参数：

  • group：入口例程所在页组的首页号，自己程序里的例程传 SB_BYTE_AT(SB_PROGRAM_START_PAGE)。
  • entry：入口例程的地址。
  • stack_pointer：恢复时要设的硬件栈指针，通常取 sb_stack_pointer() 的返回值。

sb_context_restore 

void sb_context_restore(void);

弹出上下文栈顶的恢复点并跳过去，类似 longjmp：关闭 NMI 里的各项服务与声音，恢复保存的栈指针后跳转。 栈里有恢复点时不会返回；栈空时直接返回。

系统调用：$1D

$7D sb_dir_make、sb_dir_remove、sb_dir_current 子功能 $00 没有封装（作用没有查清）。
