FC Dev 开发手册

FC Dev 是 6502 兼容机（NES、小霸王学习机等）的 VS Code 扩展：用 cc65 把 C 或 ca65 汇编构建成机型对应的程序，可以在模拟器里运行与调试，也能把已有程序反汇编回 ca65 源码。这个扩展是 FC Dev 唯一的开发环境，使用前先按“安装与入门”安装。命令“FCDEV：运行”“FCDEV：调试运行”与调试命令就是经 Ember 的调试服务运行与调试程序的，所以手册放在这里，直接就能查。

手册随 FC Dev 扩展一起发布，这里是同一份内容；在 VS Code 里用命令“FCDEV：打开使用文档”也能查到。

通用

手册 内容
安装与入门 安装扩展的方式与位置、环境要求、模拟器位置设置、第一次新建、构建与运行
构建 任务与命令、构建规则、配置文件 fcdev.json、构建流程、设置
模拟器与调试 运行方案、模拟器位置设置、调试服务与调试命令
反汇编 反汇编的命令、输入、追踪规则与限制
新建项目与模板 新建项目命令、模板与生成内容
整机 ROM 工程开发指南 构建各机型的 BIOS 与固件：底固件与覆盖、机型与磁盘镜像的配置、构建与运行

NES

手册 内容
NES 开发指南 NES 目标的内存与映射器、fcnes 函数、字库、运行

SB2000（小霸王学习机）

手册 内容
SB2000 开发指南 程序格式、内存布局、运行库、大程序换页、常用做法、易错点与示例
SB2000 示例程序源码 手册里提到的示例程序（hello、show、copy、pad、mouse、play 等）的完整源码，由示例项目生成
SB-DOS 系统调用手册 系统调用的参数、结果、出错码与可靠程度
SB2000 硬件说明 SB2000 的硬件行为与寄存器
SB2000 C 接口参考 运行库全部函数的签名、参数、返回值与系统调用，由头文件文档注释生成，查询用命令“FCDEV：查询 C 接口”
SB2000 符号参考 功能号、子功能号、系统变量地址、出错码、硬件寄存器与位、运行库入口的汇编名与 C 名，由 sb2000.inc 生成
