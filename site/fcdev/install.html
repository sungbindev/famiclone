FC Dev 开发手册

安装与入门

本页目录

  • 2. 安装扩展

  • 3. 模拟器
  • 4. 第一次使用

本文说明怎样安装 FC Dev 扩展、扩展装在哪里、运行程序需要哪些额外的东西，以及第一次使用的步骤。构建的细节见 01-构建，模拟器与调试见 02-模拟器与调试。

1. 环境要求

  • Windows 64 位。扩展只支持这个平台，构建用的 cc65 工具链随扩展一起发布。
  • VS Code 1.101 或更高版本。
  • 不需要另外安装 cc65、Node.js 或任何 npm 包。
  • 使用 Copilot 的反汇编与模拟器工具需要 GitHub Copilot；不用 Copilot 时，扩展的命令照常可用。

2. 安装扩展

在 VS Code 的扩展商店里安装：

  1. 打开 VS Code，按 Ctrl+Shift+X 打开扩展视图。
  2. 搜索 fcdev（显示名为 FC Dev，发布者 sungbin），点“安装”。
  3. 安装完成后扩展立即可用，有新版本时 VS Code 会自动更新。

2.1 安装位置

VS Code 把扩展装在用户目录下：

%USERPROFILE%\.vscode\extensions\sungbin.fcdev-<版本>-win32-x64

卸载时在扩展视图里点“卸载”即可，目录会一并删除。

3. 模拟器

扩展不自带模拟器。运行程序、调试运行、用 Copilot 启动模拟器，都需要 Ember（一个单独的 Windows 程序，Ember.exe）。

  1. 得到 Ember 的 zip 包 Ember-<版本>-学习机开发模拟器.zip，解压出 Ember.exe，放在任意文件夹里，解压即用，不需要安装。
  2. 在 VS Code 设置里搜索 fcdev.emulator.path，把它设为 Ember.exe 的完整路径，例如 D:\Ember\Ember.exe。

这个设置只能在用户设置里指定，工作区设置不能指定要运行的程序。没有设置时，运行命令会提示你到这里设置。

调试运行使用的端口由 fcdev.emulator.debugPort 指定，默认 5699，一般不需要改。

4. 第一次使用

  1. 执行命令“FC Dev：新建项目”，选择目标（NES、SB2000、SB97、裕兴或步步高）和语言（C 或汇编；SB97、裕兴与步步高只有汇编），选一个空文件夹。扩展会生成 fcdev.json、示例程序 hello 与构建任务。新建项目的细节见 04-新建项目与模板。
  2. 执行命令“FC Dev：构建项目”，构建成功后产物出现在项目的输出目录里。
  3. 执行命令“FC Dev：运行”，Ember 会打开并运行刚构建的程序。如果没有运行，先检查 fcdev.emulator.path。

学习机程序（SB2000）运行时需要 BIOS 文件，由 fcdev.json 里的 firmware 指定。BIOS 文件不随扩展发布，需要自己准备。
