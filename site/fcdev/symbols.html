本文由符号定义文件 sb2000.inc 生成。 共 433 个符号，32 节：系统调用的功能号、子功能号、系统变量的地址、出错码、硬件寄存器与位、运行库入口。

用法：

  • 汇编程序用 .include "sb2000.inc" 引入，直接写“汇编名”；文件只含符号，不占空间，值不超过 $FF 的符号按零页寻址。
  • C 程序 #include <sb2000.h> 已包含 sb2000-symbols.h，名字是“C 名”：汇编名前加 SB_，值是同一个数。
  • 汇编程序调用运行库的 C 函数时，函数名前加下划线（如 _sb_puts），参数按 cc65 的 fastcall 约定传递；全部函数见 SB2000 C 接口参考。
