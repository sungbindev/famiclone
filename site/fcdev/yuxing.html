裕兴开发指南

用 fcdev 为裕兴学习机（学习卡 V8.0-C、V8.2-D、V8.3-D、V9.0-98）的 DOS 开发程序：构建出能在 DOS 提示符下运行的 .EXE。裕兴目标只支持 ca65 汇编，没有 C 运行库。目标的定义与启动代码随 fcdev 包安装，在包里的 targets/yuxing/ 下。本文只写已经在 Ember 里用 V8.2-D 的 ROM 验证过的用法，没验证的在第 7 节列出。

1. 目标定义

项 值
目标名 yuxing
cc65Target none
链接配置 link.cfg，段见第 3 节
启动代码 lib/crt0.o：文件最前面的 JMP，初始化后调用 _main
库 无
汇编引入 asminc/yuxing.inc：ROM 的显示功能入口与字符串控制码
预定义宏 __YUXING__
打包器 flat-exe，文件第一个字节必须是 4C（JMP），大小不超过 8192 字节
产物 大写主名的 .EXE
程序名规则 dos-8.3
磁盘镜像 fat-floppy，1.44MB，构建时默认生成，见 01-构建 4.5
运行方案 firmware-disk，机型 yuxing，需要固件（ember/roms/yuxing_v8.2-d.bin 那样的 1MB ROM 文件）

2. 程序格式

  • DOS 把文件原样装进工作 RAM $6000 起，再从 $6000 开始执行；文件没有头，也没有签名。官方软盘里的程序（reference/floppy-images/裕兴）都是这样，有的第一条指令是 JMP，有的直接是代码。
  • 官方程序偏移 3 起常有一段标题文字（如“裕兴加载V1.1”），它只是文字，不是 DOS 要求的内容；目标的 crt0.s 没有这一段。
  • 在 DOS 提示符下运行程序必须写扩展名：hello.exe 能运行，hello 报“Bad command or file name.”。DOS 也不接受命令行参数：hello.exe abc 同样报这个错。
  • 程序不能返回 DOS（没有验证过返回的做法），_main 返回后 crt0.s 停在原地，要退出只能复位。

3. 内存与段

内存区 地址 段
零页 $0000-$00FF ZEROPAGE
内部 RAM $0400-$07FF BSS
程序（装在工作 RAM 里） $6000-$7FFF STARTUP、CODE、RODATA、DATA
  • 程序所在的是 RAM，DATA 段可以直接读写，不用复制。
  • 程序超过 8192 字节时链接报错。官方软盘里有更大的程序（最大 16384 字节），装入方式没有验证。
  • 内部 RAM 里 DOS 与 ROM 功能占用的单元没有核对：DOS 运行程序时在 $0300 起放命令行、目录项等内容，调用 ROM 功能的程序要自己确认没有冲突。

4. 显示文字

用 ROM 的三个功能显示文字，入口在 yuxing.inc（模板的 hello.s 就是这样做的）：

  1. JSR BIOS_INIT_TEXT：初始化文字屏。
  2. JSR BIOS_CLEAR：清屏。
  3. A 放字符串地址的低字节、Y 放高字节，JSR BIOS_PRINT：显示字符串。

字符串的格式：STR_LOCATE（$15）后跟列、行两个字节，之后的字符显示在这个位置；以 STR_END（$9F）结束。文字可以是 ASCII，也可以是 GB2312 的汉字码。一个字符串里可以多次定位。

5. 硬件寄存器

yuxing.inc 目前只有第 4 节的入口与控制码。整机寄存器的说明见 Ember 文档 ember/docs/02-硬件模块.md 第 6.12 节。

6. 构建与运行

  • 构建：任务“fcdev：构建”，产物 build/yuxing/<NAME>.EXE 与 build/yuxing/<NAME>.img。
  • 运行：任务“fcdev：运行”，需要在设置 fcdev.emulator.path 里指定 Ember，在 fcdev.json 里用 firmware 指定裕兴学习卡的 ROM。扩展依次添加 ROM、开机、放入镜像，开机运行 300 帧后按空格，等 120 帧进主菜单，按下键 3 次选中“学DOS”，回车，等 300 帧让动画播完，按空格，等 120 帧后按下键 2 次选中“三.DOS系统操作”，回车，再等 120 帧出现提示符，输入程序名加 .EXE 并回车。按键都是按下 8 帧、松开 8 帧。程序名只能用字母与数字。
  • 手动进入 DOS（真机或模拟器）：开机画面按任意键，进主菜单，选“学DOS”，等动画后按空格，选“三.DOS系统操作”进入命令行；dir 列目录要等几秒。

7. 还没有验证的内容

  • 其他学习卡 ROM（V8.0-C、V8.3-D、V9.0-98）：只用 V8.2-D 验证过开机流程与程序运行。
  • 大于 8192 字节的程序、程序返回 DOS、读写磁盘文件的 ROM 功能。
  • 命令行参数：DOS 不接受参数，程序要读文件时自己约定文件名。
  • C 语言支持：没有运行库，也没有 C 模板。
  • 真机运行：只在 Ember 里验证过。
