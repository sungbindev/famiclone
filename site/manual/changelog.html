0.4.5

  • 修复电脑关掉代理后检查更新与下载 ROM 连接超时的问题：代理开关关闭时直接连接，不再使用已关闭的代理。

0.4.4

  • 学习机的 ROM 文件改用 .rom 扩展名：添加 ROM 与从目录添加只认 .rom 文件，随软件提供的 ROM 也全部改为 .rom，已经添加的 ROM 不受影响。
  • “机型与 ROM”新增“下载 ROM”：一键下载全部支持机型的 ROM 并自动添加，已有 ROM 的机型保持不变；下载包不再附带 ROM 文件，需要时用“下载 ROM”获取。

0.4.3

  • 媒体库能查看 Apple Pascal 格式的苹果软盘：列出文件并导出，不能修改。
  • 35 道的苹果盘存放在 40 道的镜像里也能在媒体库认出并查看。
  • 认不出格式的镜像不再误标成金字塔 DOS；“（有未保存的修改）”只在自动写回失败时显示，正常的实时保存不再一直提示。
  • 金字塔 PEC-9588 支持 .nib 软盘镜像（266240 字节）：能载入、INIT 格式化、保存和读回文件，这种镜像插进 BMOW Floppy Emu 虚拟软驱也能识别；媒体库能查看金字塔盘（.nib 与 .dsk）里的文件并导出，新建空白镜像里金字塔的盘就是 .nib 空盘。
  • .nib 镜像的同步字节按真机时序读出，格式化后的盘再读回不会出错。
  • 修复金字塔 PEC-9588 已格式化的 .nib 盘再次 INIT 报 I/O ERROR 的问题，重新格式化能正常完成。

0.4.2

  • 中华学习机（CEC-I）修正垂直消隐状态，画面同步更接近真机。
  • 高分辨率图形中相邻的同色点之间补上实心色，画面颜色更完整。

0.4.1

  • 帮助的“FC Dev 开发手册”新增“中华学习机（CEC-I）”一组，介绍用 FC Dev 为中华学习机开发汇编程序并在 Ember 里运行。

0.4.0

  • 新增“媒体库”（“文件→媒体库”，或设备面板里软驱一行的第一个按钮）：选一个放文件的文件夹，左边像资源管理器一样列出里面的文件夹和文件，需要时展开右边查看文件内容；文件夹展开时才读取，目录再大也不会卡，里面的变化会自动显示。
  • 媒体库能查看和编辑软盘镜像里的文件：重命名、删除、剪切、复制、粘贴（可以在两个镜像之间复制）、移动、新建文件夹、撤销，从 Windows 拖入文件导入、拖出导出，还能新建空白镜像；支持 FAT12/16、Apple DOS 3.3、ProDOS 镜像，.nib、.woz 只能查看。
  • 媒体库也管理磁盘上的文件和文件夹：重命名、剪切、复制、粘贴、删除（先确认，放进回收站）、新建文件夹、拖到文件夹上移动；不支持的文件类型也会列出来，图标是问号。
  • 媒体库的右键菜单按文件种类给出操作：软盘镜像“载入软驱 A”，卡带“运行卡带”，声音文件“载入磁带”，图片“预览”，所有文件都有“在资源管理器中显示”。
  • 媒体库贴在主窗口的左边：拖近主窗口左边会像磁铁一样吸住，上沿对齐、高度一致，之后跟着主窗口一起移动；两个窗口的最小化、还原、置前、置顶互相同步；“文件→媒体库”前面的对勾会记住，开着没关就退出的话，下次启动会同时打开。
  • 主窗口每次启动都居中显示，不再记住上次关闭时的位置。
  • 删除等确认询问改用与程序风格一致的对话框，默认选“否”。

0.3.24

  • 中华学习机的英文字符改用苹果 IIe 的字形（5×7 点阵），笔画变细，更接近真机。

0.3.23

  • “开机与复位后隐藏最初的画面”遮黑的时间加长到 12 帧，中华学习机开机时不再漏出花屏。
  • 新增中华学习机 CEC-I（兼容苹果 II）：在“设置→机型与 ROM”里给“中华学习机 CEC-I”添加 ROM（两块芯片 U7、U35 的内容依次拼成的 64 KB 文件，1.1a 与 1.21 任选一个），再用“机器→选择机型”开机。
  • 中华学习机有自带键盘、一个手柄口、磁带、一个苹果格式的 5.25 英寸软驱和一块打印机接口卡，可以载入 Apple DOS 3.3、ProDOS 的 .dsk、.do、.po 镜像（143360 或 163840 字节）以及 .nib、.woz 镜像从软盘启动并读写；无盘时进入 BASIC。键盘的 F1 到 F5、F6（中文）、F7（西文）、F8（自检）和 Pause（退出）对应机器上的同名键。汉字系统可以直接使用，汉字字形来自 Ember 内置的开源字库（GNU Unifont），字形与真机不同；ROM 文件后面可以再接字库芯片 U33、U34 的内容（各 128 KB），接上后使用真机字形。PR#1 可以把输出送到打印机。
  • 金字塔 PEC-9588 接上 5.25 英寸软驱：主菜单里的“磁盘操作系统”可以使用，在设备面板里给软驱载入 .dsk 镜像，用 INIT 格式化、SAVE、LOAD、CATALOG 等命令读写软盘；没有盘片时读盘报 I/O ERROR。

0.3.5

  • 调整 FC 与裕兴、金字塔等学习机的画面颜色：整体比之前更亮，颜色更接近常见的模拟器。
  • 学习机运行时在“设置→机型与 ROM”里换了 ROM 后，点硬复位（或断电后再开机）会按新的 ROM 启动，不再继续用开机时的旧 ROM。
  • 在资源管理器里双击 .nes 文件就能用 Ember 打开并运行；Ember 已在运行时，会在已有的窗口里打开这张卡带。Ember 启动时会把自己登记为 .nes 的打开方式，.nes 还没有默认程序时它就是默认程序。
  • 修复设置实体手柄时，点了键后马上按手柄按钮绑不上、且这个键必须取消后重新点才能再绑的问题；点键时手柄上还按着按钮会提示“请松开”，松开后再按即可绑定。
  • “机型与 ROM”对话框新增“从目录添加 ROM”：选一个文件夹，把里面认得出的各机型 ROM 一次添加。
  • 学习机开机后，系统栏在机型名右边显示正在使用的 ROM 版本（如“裕兴 V9.0-98”）。
  • 添加 ROM 时只接受不带 NES 文件头的 .bin 文件。
  • 新增裕兴学习机：在“设置→机型与 ROM”里给“裕兴”添加 ROM（V8.0-C、V8.2-D、V8.3-D、V9.0-98 四个学习卡里任选一个，想换另一个就替换），再用“机器→选择机型”开机。
  • 裕兴有自带键盘、鼠标、两个手柄口和一个软驱：主菜单可以用方向键或鼠标选择，“磁盘管理”能读写软驱里的软盘，V8.2-D 与 V8.3-D 的学习卡也能从软盘运行 WPS。
  • 裕兴支持磁带：游戏 BASIC 里用 SAVE"A" 把程序存进磁带机、用 LOAD"A" 读回；V8.0-C 主菜单的“声像学习”可以放声像教学磁带，课文跟着磁带出现，磁带里的声音从扬声器播出。
  • 修复步步高软驱一号与步步高 98 不能格式化软盘的问题：在 DOS 里输入 format a: 现在可以正常完成。
  • 设备面板里软驱与磁带机的状态文字（无盘片、无磁带等）左边对齐，磁带机的“取出”按钮移到最右，与软驱的“取出”在同一位置。
  • 设备面板里设备名前加了图标并用醒目的样式，名称列变窄，盘片名与磁带名有更多的显示空间。
  • 点设备面板里磁带机的位置（如“0:23 / 0:40”）会弹出磁带时间轴：显示磁带上各处声音的大小，连续没有声音的空白段用浅色底标出，用鼠标点击或拖动后松开就能把磁带定位到那里，方便在一盘磁带里找到某个程序的位置（停止和播放时都可以定位）。

0.3.0

  • Ember 改为 Windows 原生程序，支持 Windows 7 SP1 到 Windows 11 的 64 位系统；发布为单个 Ember.exe，解压即用，不需要安装。
  • 升级只替换 Ember.exe，检查更新、下载、重启安装的用法不变。
  • 显示画面优先用支持 Direct3D 11 的显卡；没有显卡或驱动的电脑（虚拟机、远程桌面等）会改用系统自带的软件渲染，也能显示画面。
  • 不再自带学习机的 BIOS，也不会在电脑里自己查找：需要哪个机型，就在“设置→首选项→机型与 BIOS”里给它添加 BIOS 文件。
  • 首选项新增“用户数据目录”：可以在软件所在目录旁的 ember-data 与当前用户的应用数据目录之间切换，全部数据一起带过去。
  • 帮助文档和更新记录改用系统默认浏览器打开。
  • 首选项“画面”里新增“开机与复位后隐藏最初的画面”，默认关闭。
  • 经典 FC 游戏不再独占键盘，F8、F9、Ctrl+O 等快捷键和 Alt 加字母的菜单键随时可用；学习机以及接入 Family BASIC 键盘时仍独占键盘。
  • 画面右下角的提示改为半透明的毛玻璃提示框，新增键盘被独占时的提示。
  • “关于 Ember”里的版本、核心版本和编译时间移到右上角，项目地址的焦点框贴着链接文字。
  • 对话框的标题栏有了 Ember 图标和最小化按钮，按钮样式与主窗口一致；对话框打开时不再聚焦到某个按钮或链接上；对话框里的滚动条贴着对话框右边。
  • 二级菜单放不下时不再盖住一级菜单。
  • 对话框打开时不再先闪一下白色。
  • 复位后，画面右下角的键盘独占与鼠标捕获提示会再次显示；鼠标捕获提示的文字缩短为“点击捕获鼠标，双击右键释放”。
  • 画面右下角的键盘独占提示与鼠标捕获提示各用一个毛玻璃圆角提示框。
