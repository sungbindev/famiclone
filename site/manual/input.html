键盘在哪里生效

  • 键盘只在画面获得焦点时送给机器。主窗口里点过任何地方后，焦点都会回到画面；在文字输入框里不采集。
  • 窗口失去焦点、页面隐藏或关闭时，所有按键自动松开。
  • Windows 上运行学习机或接入 Family BASIC 键盘时，画面获得焦点期间独占键盘；经典 FC 游戏不独占。金字塔学习机自带键盘，和学习机一样独占键盘。说明见窗口、菜单与快捷键。
  • 键盘按物理键位识别，与输入法和键盘布局无关。

手柄设置

点“设置→手柄设置”。手柄绑定全局只有一份，不分机型和卡带，对红白机一直有效；学习机在红白机兼容模式下有效，在 DOS 里键盘整个交给机器。

手柄有 10 个键：上、下、左、右、A、B、连发 A、连发 B、选择、开始。连发键按住时每 2 帧翻转一次对应的 A 或 B。

对话框里有“玩家 1”和“玩家 2”两个页签，每个页签是一张手柄图，图上方是“输入来源”切换：键盘和实体手柄是两份互相独立的绑定，切换来源只改变显示和设置的是哪一份。

设置键盘键位

  1. 点手柄图上的键，按钮变成“请按键”。
  2. 按下想绑定的键盘按键。按 Esc 取消。
  3. 一个物理键只能绑给一个手柄键：绑给新的键时，原来绑着它的键（包括另一个玩家的）自动解除。
  4. 选中某个键后，点“清除”可以解除它在当前来源下的绑定。

设置实体手柄

  1. 切到“实体手柄”，在“使用的手柄”下拉框里选一个已连接的手柄。手柄接上后要先按一下它的任意按钮，系统才会把它交给 Ember。
  2. 点图上的键，再按下手柄上的一个按钮，或把一个摇杆推到底，即完成绑定。点键时如果手柄上还有按钮按着，按钮会显示“请松开”，松开后变成“请按键”，这时再按才会绑定。
  3. 换成别的手柄时，原来的按钮绑定会清空；同一个手柄只能属于一个玩家。

没有指定手柄或手柄未连接时，图上的键不可点。Xbox 类手柄和普通 USB 手柄（如北通的 DInput 模式）都能识别；普通 USB 手柄在下拉框里显示为“名称 (Vendor: … Product: …)”，插入后可能要等约一秒才出现。

学习机的键盘

学习机整机把键盘整个交给机器：画面获得焦点时，按键按物理键位转成学习机键盘的按键，由学习机的 ROM 和程序自己决定怎么用。学习机进入红白机兼容模式后，键盘不再整个交给机器，而是按手柄绑定当手柄用。

Family BASIC 键盘

给经典 FC 接上 Family BASIC 键盘：勾选“机器”菜单里的“接入 Family BASIC 键盘”。这个选项不保存，每次启动 Ember 都是未接入。接入后，键盘按键按 Family BASIC 键盘的键位送给机器，不再当作手柄按键。学习机不受这个选项影响。

金字塔学习机的键盘

用金字塔学习机（PEC-9588、PEC-586、686）开机后，机器自带键盘，不用在“机器”菜单里接入，也不能拔下。按键按电脑键盘的物理位置对应，字母、数字、标点、小键盘、Esc、Tab、Caps Lock、空格、回车、退格、Shift、Ctrl、Alt（左右各一个都可以）、F1 到 F8、Delete、Insert、End、Page Up、Page Down、Home、方向键、Num Lock、Scroll Lock、Print Screen 和 Pause 都对应机器上的键；F9 到 F12 始终留给 Ember，不会送给机器。键盘上没有的键会被忽略。

系统主菜单里按数字键 1 到 8 选择项目，输入 BASIC 或监控命令时直接打字，回车确认。

裕兴学习机的键盘

用裕兴学习机开机后，机器自带键盘，不用在“机器”菜单里接入，也不能拔下。按键按电脑键盘的物理位置对应：字母、数字、标点、小键盘、Esc、Tab、Caps Lock、空格、回车、退格、Shift、Ctrl、Alt（左右各一个都可以）、F1 到 F8、Delete、Insert、End、Page Up、Page Down、Home、方向键、Num Lock、Scroll Lock、Print Screen、Pause 以及左右 Win 键与菜单键都对应机器上的键；F9 到 F12 始终留给 Ember，不会送给机器。键盘上没有的键会被忽略。

裕兴有两个手柄口，手柄绑定里的“玩家 1”“玩家 2”分别对应手柄口 1、2；键盘整个交给机器，所以裕兴上的手柄要用实体手柄。

鼠标

只有机器带鼠标时才能捕获：

  • 学习机整机（小霸王 97 与金字塔学习机除外，它们没有鼠标）自带鼠标，小霸王 2000 进入红白机兼容模式后没有。裕兴的鼠标有左键和右键。
  • 经典 FC 只有卡带的 mapper 插件声明了鼠标时才有。

用法：

  1. 首选项的“输入”分组里“点击画面捕获鼠标”默认开启。
  2. 点击画面，第一次点击只用来捕获，不会送给机器；捕获后指针隐藏，鼠标的移动和按键送给机器。
  3. 双击鼠标右键释放。
  4. 机器带鼠标且在运行或暂停时，画面右下角会显示一个提示框，写着“点击捕获鼠标，双击右键释放”，4 秒后自动消失，复位后会再次显示；键盘被独占时，它上面还有一个提示框，写着“键盘已被机器独占，快捷键无效”。
