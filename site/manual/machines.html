使用说明

机型与 ROM

本页目录

  • 选择机型
  • 添加、替换与移除 ROM
  • 开机
  • 运行面板

选择机型

“机器→选择机型”是一个子菜单，列出几种学习机整机，选中的一项前面有对勾。选过机型后，这一项的名称直接显示已选机型的名字（如“小霸王 2000”），没选过（或最近打开的是卡带）时仍显示“选择机型”。

  • 点一个机型就直接用它的 ROM 开机，并记住这个机型。已经打对勾、而且正在运行（运行或暂停）的机型，再点它什么都不做；点别的机型会立即开机新选的机型。
  • 选过的机型会被记住，下次启动沿用；之后点“机器”菜单里的“开机”（或 F9、运行面板里的“开机”按钮），直接开这个机型。
  • 学习机整机要已添加 ROM 才可选，没有 ROM 的置灰，并注明“未添加 ROM”。
  • 还没有支持的机型置灰，注明“暂未支持”。

经典 FC 不在这个菜单里，用“文件→打开卡带”打开游戏即可。打开卡带成功后，已选机型会回到经典 FC（子菜单里没有对勾）。

添加、替换与移除 ROM

“设置→机型与 ROM”打开的对话框里管理，每个学习机机型一行，显示名称、ROM 状态（未添加，或文件名与大小）和按钮。Ember 不自带 ROM，也不会在电脑里自己查找：要用哪个学习机机型，就在这里给它添加 ROM 文件；想换成别的 ROM 才用“替换”。

  • 添加 ROM 文件：点后选择 ROM 文件（.bin），文件会复制到 Ember 自己的 ROM 目录，开机时直接使用，原文件可以删除或移动。ROM 文件是只含程序的纯 .bin 文件，不能带 NES 文件头，大小要等于这个机型的容量（小霸王 97 为 1024 KB，小霸王 2000 为 512 KB，步步高 软驱一号为 128 KB，步步高 98 为 2048 KB，金字塔 PEC-9588 与金字塔 PEC-586(686) 都是 512 KB，裕兴为 1024 KB，中华学习机 CEC-I 为 64 KB，也可以在后面再接 256 KB 的汉字字库（字库芯片 U33 与 U34 各 128 KB，先 U33 后 U34），共 320 KB）。“金字塔 PEC-586(686)”这一个机型可以添加 PEC-586 或 PEC-686F 的 ROM，两个文件选一个即可。“裕兴”这一个机型可以添加 V7.0、V8.0-C、V8.2-D、V8.3-D、V9.0-98、V9.2-98、V9.2-F 等学习卡中的任何一个，想换另一个学习卡时用“替换”。“中华学习机 CEC-I”的 ROM 是机器上两块 32 KB 芯片（U7 与 U35）的内容依次拼成的一个 64 KB 文件（先 U7 后 U35），1.1a 与 1.21 两个版本任选一个，不要把两块芯片的文件分开添加。
  • 从目录添加 ROM：说明下面的“从目录添加 ROM”按钮，点后选择一个文件夹，Ember 把里面的 .bin 文件（不含子文件夹）按内容认出各自属于哪个机型，给还没有 ROM 的机型一次添加；文件叫什么名字都行。已经有 ROM 的机型保持不变，同一个机型的多个文件只添加文件名排在最前的一个，认不出的文件跳过，结果用一条通知说明。想换已有的 ROM 用“替换”。
  • 替换：选新的文件，复制成功后才删除旧的。
  • 移除：删除 ROM 目录里的文件，不影响你的原文件，也不会再询问。
  • 打开 ROM 目录：对话框顶部说明下面的“打开 ROM 目录”链接，点后用系统的文件管理器打开 Ember 保存 ROM 的目录，可以直接查看里面的文件。
  • 经典 FC 不需要 ROM，不在这个列表里。
  • 还没有支持的机型整行置灰，状态写“暂未支持”。

操作结果和文件不符合机型的错误都以通知显示。ROM 变化后，“机器→选择机型”会立即更新。

开机

开机有三种入口，效果相同：运行面板里的“开机”按钮、“机器”菜单里的“开机”、F9。

  • 学习机整机：已添加 ROM 就能开机，不需要卡带。当前运行的是别的主机时，也会按已选机型重新开机。没有 ROM 时按钮置灰。
  • 小霸王 97：开机后几秒钟出现小霸王开机画面，画面停着循环变色时按任意键，先显示“正在检测”，几秒后进入主菜单（不按键大约一分钟后也会自己进入）；主菜单用方向键选择软件，回车进入：F-BASIC 进入 BASIC 的 ] 提示符，DOS 可以读写软驱里的软盘（先在“设备”面板载入镜像）。小霸王 97 没有鼠标，打印机还不支持。
  • 金字塔 PEC-9588、金字塔 PEC-586(686)：开机后先显示开机画面，PEC-9588 按回车、PEC-586 与 PEC-686F 按空格进入系统主菜单，按菜单里的数字或字母键进入各个程序；机器自带键盘，没有鼠标，支持磁带，见软盘与磁带。PEC-9588 主菜单里的“磁盘操作系统”（按 6）读写 5.25 英寸软盘，先在设备面板里给软驱 A 载入 .dsk 镜像，见软盘与磁带；支持打印机，打印内容保存成图片。
  • 裕兴：开机后先显示“裕兴”开机画面，几秒后进入主菜单（V8.0-C、V8.2-D、V8.3-D、V9.0-98 的菜单各不相同）；机器自带键盘，有鼠标和两个手柄口，有一个软驱，支持磁带与声像卡，见软盘与磁带和输入。主菜单可以用方向键移动选择、回车进入，也可以用鼠标点；V9.0-98 的主菜单一段时间没有操作，机器会回到开机画面。支持打印机，打印内容保存成图片。
  • 中华学习机 CEC-I：兼容苹果 II 的学习机，开机后显示“ZHONG HUA XUE XI JI”与版本号，进入 BASIC 的 ] 提示符；有一个 5.25 英寸软驱，先在设备面板里给软驱 A 载入苹果格式的 .dsk 镜像（DOS 3.3 或 ProDOS，143360 字节或 163840 字节），再“机器→硬复位”或重新开机，机器就会从软盘启动；没有盘片时停在 BASIC。机器自带键盘、一个手柄口（手柄的 A、B 对应苹果的两个按钮，选择与开始是第三个按钮，方向键对应模拟手柄的两端）、一块打印机接口卡（PR#1 后输出的文字会打印成 PNG 图片，见软盘与磁带里的打印机），支持磁带，没有鼠标，见软盘与磁带和输入。按键盘上的“中文”键（F6）进入汉字系统，用 F1 到 F5 选择字母、拼音、区位等输入方式，“西文”键（F7）回到英文；汉字字形用的是 Ember 内置的开源字库（GNU Unifont），英文字符用的是苹果 II 的字形，和中华学习机真机的显示码 ROM 不一定相同。如果有真机汉字字库芯片 U33、U34 的内容，可以接在 ROM 文件后面使用，见上面“添加 ROM 文件”。
  • 经典 FC：要先用“文件→打开卡带”选一个 .nes 文件，选好后直接开机。没有卡带时按钮置灰；断电后按钮可点，直接上电，卡带还在。

学习机整机开机后系统栏会显示主机型号，右边跟着开机所用 ROM 的版本（认得出的 ROM 显示版本名或型号名，如“V9.0-98”“98型”，否则显示文件名）；经典 FC 不显示主机型号，只显示卡带名和 mapper 插件。

运行面板

点系统栏左侧的运行按钮展开，只有一行内容：

内容 说明
开机或断电 通电时是“断电”，未通电时是“开机”
暂停或继续 没有开机时置灰
软复位 只发复位信号，不改变电源、卡带与盘片
硬复位 相当于断电再上电；学习机在“设置→机型与 ROM”里换过 ROM 后，硬复位按新的 ROM 启动
静音与音量 静音按钮、音量滑块与数值

画面上会显示当前状态：没有开机显示“未开机”，并提示怎么开机；断电显示“已断电”；暂停显示“已暂停”。
