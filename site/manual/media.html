卡带、软盘、磁带与打印机

打开卡带（经典 FC 与学习卡）

  • “文件→打开卡带”（Ctrl+O）：选择 .nes 文件，选后直接开机。
  • “文件→最近打开”：最多 10 个，最近的在前，选中即重新打开；没有记录时置灰。
  • “文件→关闭卡带”：取出卡带，主机随之拆除。
  • 拖放：把 .nes 文件直接拖进窗口任何位置，效果等同于“打开卡带”。
  • 双击：在资源管理器里双击 .nes 文件，用 Ember 打开并开机；Ember 已经在运行时，在已有的窗口里打开这张卡带。Ember 启动时会把 .nes 登记为可以用它打开，.nes 还没有默认程序时它就是默认程序；已经有别的默认程序时，右键文件选“打开方式”，选 Ember 并勾选“始终使用此应用”即可。

主机会按卡带的 mapper 号匹配 mapper 插件并自动装配。找不到匹配的插件时会提示，可以在“设置→mapper 插件”里查看和安装，见 mapper 插件。

金字塔学习机与裕兴学习机的学习卡不是 FC 卡带，不能用“打开卡带”打开，要像其他学习机一样在“设置→机型与 ROM”里添加成 ROM（只接受不带文件头的 .rom），再用“机器→选择机型”开机，机器自带键盘，不需要卡带。中华学习机也一样。

设备面板

点系统栏左侧的设备按钮展开。面板里始终列出软驱 A、磁带机和打印机三行，与主机型号无关。软驱与磁带机是独立于主机的设备，随时可以载入和取出，没有开机、没有卡带也可以。

设备按钮的图标是软驱的正面，顶部的方块是软驱读写灯：任一软驱的马达在转时亮绿色，其余时候是暗色。

软驱

一行里显示软驱名称（前面有软盘图标）、盘片（镜像名或“空”）和状态（无盘片、空闲、读写中并带磁道），行尾四个按钮。软驱与磁带机两行的状态文字左边对齐，“取出”按钮也在同一位置。

按钮 作用
媒体库（文件夹图标） 打开“媒体库”窗口，见下面的“媒体库”
写保护 按下表示已写保护
载入镜像 选择软盘镜像文件载入，替换里面的盘片
取出 取出盘片；没有盘片时置灰
  • 可以直接把 .img、.ima、.vfd、.dsk、.flp、.do、.po、.nib、.woz 文件拖进窗口，载入软驱 A。
  • 学习机写盘后，Ember 会自动把镜像写回文件；写回失败时有通知，并每 5 秒重试一次。系统栏与设备面板里的“（有未保存的修改）”只在写回失败、改动还留在内存时出现，正常的实时保存不会一直挂着这个提示。
  • 金字塔 PEC-9588 接的是 5.25 英寸软驱，只能用自己格式的镜像：.nib（266240 字节，40 道；BMOW Floppy Emu 这类虚拟软驱用的也是这种格式，真机上 INIT 后就能当空盘用），或者 143360 字节的 .dsk；SB-DOS、步步高、苹果 II 的镜像都不能用。没有现成的盘时，在媒体库里右键“新建空白镜像”，选“5.25 英寸 140 KB（金字塔 PEC-9588）”，建出来的 .nib 盘已经格式化好，不用在机器里 INIT；开机进入主菜单后按 6 进入“磁盘操作系统”，CATALOG 列出文件，SAVE 名字 保存、LOAD 名字 读回，BASIC 语句可以直接输入。保存要等一会儿，屏幕上再次出现提示符 ] 就是做完了。镜像大小不对或没有盘片时读盘报 I/O ERROR。
  • 中华学习机 CEC-I 接的是苹果格式的 5.25 英寸软驱：可以载入 143360 字节（35 道）或 163840 字节（40 道）的 .dsk、.do、.po 镜像，Apple DOS 3.3 与 ProDOS 的盘都能用（扇区顺序由 Ember 按镜像内容认出）；载入后“机器→硬复位”就会从软盘启动，程序写盘（如 SAVE、INIT）后镜像会自动写回文件。不要用参考资料里的原盘直接写盘，先复制一份。还可以载入 Disk II 位流格式的镜像：.nib（232960 字节或 266240 字节）和 5.25 英寸的 .woz（只支持 5.25 英寸），写盘后同样自动写回文件；用了弱位、磁通型磁道等特殊磁盘格式的防拷贝软件可能运行不了。
  • 系统栏里会显示已载入的软盘镜像名。

磁带机

一行里显示磁带机名称（前面有磁带图标）、磁带（声音文件名或“空”）、位置（当前 / 总时长）和状态（无磁带、已停止、播放中、录音中），行尾四个按钮：播放、录音、停止、取出。

  • 没有磁带时点“播放”会弹出文件选择窗口，选一个声音文件载入；磁带机已经接在通电的主机上时随即开始播放，否则只载入。
  • 磁带可以放 m4a、mp3、wav、aac、flac、ogg、opus、mp4、mka 文件，也可以直接拖进窗口，拖入只载入，不自动播放。
  • “录音”会弹出保存文件窗口（WAV），选定后立即开始录音。停止后录到的文件自动成为磁带机里的磁带，可以直接播放。
  • 播放和录音要求磁带机接在通电的主机上，目前开机后的经典 FC、金字塔学习机、裕兴学习机与中华学习机满足；不满足时这两个按钮置灰。断电时磁带机自动停止，磁带留在里面。
  • 金字塔学习机把程序存到磁带：进入“中西文 BASIC”后，先点“录音”选好保存位置，再输入 SAVE 并回车（PEC-586(686) 要写文件名，如 SAVE "A"）；存完要一分钟多，屏幕上再次出现提示符“]”就是存完了，这时点“停止”。读回时先载入刚才的录音（拖进窗口即可），输入 LOAD 并回车（PEC-586(686) 同样要写文件名），再点“播放”，提示符回来后用 LIST 查看。
  • 金字塔学习机的声像教学：在主菜单选“声像电视教学”（PEC-9588 按 8，PEC-586(686) 按 D），载入声像教学磁带（立体声，左声道是声音、右声道是数据）并点“播放”，课文画面会跟着磁带出现（磁带开头有一段时间只显示标志），磁带里的声音从扬声器播出。
  • 裕兴学习机把程序存到磁带：在主菜单进入“工具软件”，选“游戏 BASIC”，再按 1 进入 BASIC 的 OK 提示符；先点“录音”选好保存位置，再输入 SAVE"A" 并回车，屏幕上出现 OK 就是存完了，这时点“停止”。读回时先载入刚才的录音（拖进窗口即可），输入 LOAD"A" 并回车，再点“播放”，OK 回来后用 LIST 查看。
  • 裕兴学习机的声像卡：在 V8.0-C 的主菜单选“声像学习”，先显示“裕兴声像卡”的标志，载入声像教学磁带（立体声，左声道是声音、右声道是数据）并点“播放”，课文画面会跟着磁带出现，磁带里的声音从扬声器播出。
  • 播放或录音中只有“停止”和“取出”可用，取出会先停止再取出。
  • 时间轴：里面有磁带且不在录音时，点一点“位置”那一列（如“0:23 / 0:40”，鼠标移上去会变手形、底色加深），在它上方、窗口中间的位置弹出一条长长的时间轴，用来在一盘磁带里找到某个程序的位置。
    • 图上的竖条是磁带上各处声音的大小（只看数据那一路：立体声磁带看右声道，单声道磁带整路），连续半秒以上几乎没有声音的空白段用浅色底标出（磁带开头与结尾的空白也算），一段程序通常就是两段空白之间的那一段；下面是刻度与时间，竖线是此刻的播放位置。
    • 鼠标在图上移动时会显示这个位置的时间；点击或按住拖动后松开，磁带就定位到松开的位置（拖动中不会定位）。停止和播放时都可以定位，播放时会从新位置继续播放；没有开机也可以定位。
    • 载入磁带后要先分析一遍声音，这时图上写“分析中”并带进度，还是可以点击或拖动定位，只是看不到声音的大小；分析失败时会写“无法分析这盘磁带的声音”。分析结果只在这次运行里保存，取出或换一盘磁带后重新分析。
    • 按 Esc、点时间轴之外的地方、再点一次“位置”列、开始录音或取出磁带时时间轴关闭；点这一行里的“播放”“停止”等按钮不会关闭它，可以边找边播。

打印机

只显示状态：空闲、打印中、打印完成，没有按钮。主机没有打印机时，这一行显示“空闲”。每输出一页，会用通知告诉你文件名，并保存成 PNG 图片，保存位置在首选项的“打印机”分组里设置。点通知里的“打开图片目录”，就能在文件管理器里看到这些图片。

媒体库

用来管理放在一个文件夹里的磁盘镜像、NES 卡带、声音文件和 PNG 图片，也能查看和编辑软盘镜像里的文件，尤其是 WinImage 打不开的苹果 .dsk 等 5.25 英寸镜像。“文件→媒体库”或设备面板里软驱一行第一个按钮都能打开它。这个窗口打开时主窗口仍然可以照常使用，它也不会一直盖在主窗口上面，有自己的任务栏按钮。窗口标题“媒体库”后面显示现在用的目录。

  • 打开时“文件→媒体库”前面会打对勾，再点一次就关闭。对勾会记住：开着没关就退出的话，下次启动 Ember 会同时打开它；手动把它关掉，下次启动就不再自动打开。

  • 媒体库打开时贴在主窗口的左边，上沿与主窗口对齐，高度与主窗口一样，没有最小化、最大化按钮。拖动主窗口，媒体库会一起移动，两个窗口的最小化和还原互相同步（在任务栏点哪一个都是两个一起回来），在任务栏点其中一个窗口把它提到最前面时另一个也一起提到最前面，主窗口置顶时它也一起置顶；调整其中一个的高度，另一个会跟着改成一样。拖动媒体库可以把它拉开；把它从左边拖近主窗口的左边缘，到一定距离就会像磁铁一样吸住，松开后上沿会立即对齐，高度也会改成与主窗口一样。吸住后点“显示文件内容”，两个窗口会一起重新摆放，不会跑到屏幕外面。主窗口最大化或全屏时不再吸附，还原后会重新吸住。

  • 第一次使用先点左边“资源管理器”标题行里的“选择目录”，选一个放文件的文件夹，以后会记住（点“更改目录”换一个）。

  • 窗口打开时只有左边的资源管理器列表，用来选文件、管理文件；标题行右边除了“选择目录”还有两个按钮：“折叠一级”点一次只收起最里面一层展开着的文件夹，再点收起上一层；“显示文件内容”点一下，窗口变宽并在右边显示所选文件的内容，再点一下收起。只是要载入软驱、运行卡带这类操作时，不用展开右边。窗口拉窄后放不下的内容会出现横向滚动条（按住 Shift 滚动鼠标滚轮也可以左右滚动）。

  • 左边列出这个目录里的文件夹和文件，每一行只有图标和文件名，文件的类型和大小在右边显示；文件夹展开时才读取里面的内容，所以目录再大也不会卡，已经展开的文件夹里的变化会自动显示出来。能查看或使用的有：磁盘镜像（.img、.ima、.vfd、.dsk、.flp、.do、.po、.nib、.woz）、.nes 卡带、.png 图片，以及磁带机能载入的声音（.m4a、.mp3、.wav、.aac、.flac、.ogg、.opus、.mp4、.mka），其他文件（包括 .rom 和隐藏文件）也都会列出来，图标是问号、右边写“不支持的文件类型”，只能重命名、移动、复制、删除和“在资源管理器中显示”，所以文件夹里有别的文件时不会看起来像空目录。文件夹默认是收起的，单击一下就展开或收起；点空白处取消选中。

  • 点一个磁盘镜像，展开右边后就列出它里面的文件；点其他文件，右边只有它自己这一行。表头固定是“名称、类型、大小、修改时间”四列，某个文件没有的内容显示“-”；点磁盘镜像时，列表最后一行的下面还有一行淡色的说明，写着镜像的格式、容量和可用空间，如“FAT12 · 容量 1.4 MB · 可用 1.37 MB”；表头里相邻两列之间的竖线可以拖动，用来调整列宽。双击镜像里的文件夹进入，第一行的“..”或 Backspace 回上一级。

  • 左边的文件和文件夹也可以直接管理（作用在磁盘上的真实文件）：F2 重命名（只选中扩展名前的名字）、Delete 删除（先确认，确认后移进回收站）、Ctrl+X 剪切、Ctrl+C 复制、Ctrl+V 粘贴，右键菜单里还有“新建文件夹”，把文件拖到文件夹上就是移动（会先问一下，剪切后粘贴也一样）（拖动时光标会变成移动的样子，旁边跟着被拖文件的名称）。镜像正插在软驱里时不能重命名、移动、删除，先把它从软驱里取出来。

  • 剪切的文件、文件夹或镜像里的条目会变淡显示，和 Windows 资源管理器一样；粘贴、再剪切或复制别的条目后，原来变淡的恢复正常。

  • 左右两边都可以右键，菜单按文件的种类给出：磁盘镜像是“载入软驱 A”，.nes 卡带是“运行卡带”（载入并开机进入游戏，也会记入“最近打开”），声音文件是“载入磁带”，.png 图片是“预览”（用系统默认的图片查看程序打开），所有文件都有“在资源管理器中显示”。在左边的空白处或文件夹上右键可以“新建空白镜像”“新建文件夹”，建好后名字直接进入改名状态，输入名字回车即可（只选中扩展名前的名字，Esc 保留自动取的名字）。

  • 右边的文件列表里可以直接改磁盘镜像的内容（卡带、声音、图片没有内容可改）：F2 重命名（只选中扩展名前的名字）、Delete 删除（先确认）、Ctrl+X 剪切、Ctrl+C 复制、Ctrl+V 粘贴（可以在两个镜像之间复制）、Ctrl+Z 撤销，右键菜单里也有这些项和“新建文件夹”。除了删除和移动（拖到文件夹上、剪切后粘贴），其他操作都不会再确认，马上写进镜像文件；镜像正插在软驱里时，机器里的盘片也马上跟着变。每个镜像各有一份撤销记录，只在 Ember 运行期间保存。没有“全选”。

  • 导入和导出只用拖放：把文件或文件夹从 Windows 拖进右边的列表就是导入（拖到文件夹上导进那个文件夹）；把列表里的文件（可以多个）拖到资源管理器里就是导出；把文件拖到列表里的文件夹上是移动。

  • 某些操作做不了时（镜像只读、盘片已写保护、Apple DOS 3.3 没有文件夹等），右键菜单里对应的项会变灰，用键盘或拖放触发时在附近弹出一个 2 秒的小提示说明原因，不弹窗。操作出错（名称不合格、重名、没有空间等）用通知说明。

  • .nib、.woz 格式的镜像只能查看，不能修改；Apple Pascal 与金字塔 PEC-9588 的盘（.nib 与 143360 字节的 .dsk）能查看里面的文件并导出，不能重命名、删除或导入。35 道的苹果盘存放在 40 道的镜像里也能认出；认不出格式的镜像会如实标“未识别”，不会误标成别的格式。

拖放小结

拖入的文件 处理
.nes 打开卡带并开机，已选机型变成经典 FC
.img、.ima、.vfd、.dsk、.flp、.do、.po、.nib、.woz 载入软驱 A
m4a、mp3、wav、aac、flac、ogg、opus、mp4、mka 载入磁带机
