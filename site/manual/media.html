卡带、软盘、磁带与打印机

打开卡带（经典 FC 与学习卡）

  • “文件→打开卡带”（Ctrl+O）：选择 .nes 文件，选后直接开机。
  • “文件→最近打开”：最多 10 个，最近的在前，选中即重新打开；没有记录时置灰。
  • “文件→关闭卡带”：取出卡带，主机随之拆除。
  • 拖放：把 .nes 文件直接拖进窗口任何位置，效果等同于“打开卡带”。
  • 双击：在资源管理器里双击 .nes 文件，用 Ember 打开并开机；Ember 已经在运行时，在已有的窗口里打开这张卡带。Ember 启动时会把 .nes 登记为可以用它打开，.nes 还没有默认程序时它就是默认程序；已经有别的默认程序时，右键文件选“打开方式”，选 Ember 并勾选“始终使用此应用”即可。

主机会按卡带的 mapper 号匹配 mapper 插件并自动装配。找不到匹配的插件时会提示，可以在“设置→mapper 插件”里查看和安装，见 mapper 插件。

金字塔学习机与裕兴学习机的学习卡不是 FC 卡带，不能用“打开卡带”打开，要像其他学习机一样在“设置→机型与 ROM”里添加成 ROM（只接受不带文件头的 .bin），再用“机器→选择机型”开机，机器自带键盘，不需要卡带。

设备面板

点系统栏左侧的设备按钮展开。面板里始终列出软驱 A、磁带机和打印机三行，与主机型号无关。软驱与磁带机是独立于主机的设备，随时可以载入和取出，没有开机、没有卡带也可以。

设备按钮的图标是软驱的正面，顶部的方块是软驱读写灯：任一软驱的马达在转时亮绿色，其余时候是暗色。

软驱

一行里显示软驱名称（前面有软盘图标）、盘片（镜像名或“空”）和状态（无盘片、空闲、读写中并带磁道），行尾三个按钮。软驱与磁带机两行的状态文字左边对齐，“取出”按钮也在同一位置。

按钮 作用
写保护 按下表示已写保护
载入镜像 选择软盘镜像文件载入，替换里面的盘片
取出 取出盘片；没有盘片时置灰
  • 可以直接把 .img、.ima、.vfd、.dsk、.flp 文件拖进窗口，载入软驱 A。
  • 学习机写盘后，Ember 会自动把镜像写回文件；写回失败时有通知，并每 5 秒重试一次。
  • 系统栏里会显示已载入的软盘镜像名。

磁带机

一行里显示磁带机名称（前面有磁带图标）、磁带（声音文件名或“空”）、位置（当前 / 总时长）和状态（无磁带、已停止、播放中、录音中），行尾四个按钮：播放、录音、停止、取出。

  • 没有磁带时点“播放”会弹出文件选择窗口，选一个声音文件载入；磁带机已经接在通电的主机上时随即开始播放，否则只载入。
  • 磁带可以放 m4a、mp3、wav、aac、flac、ogg、opus、mp4、mka 文件，也可以直接拖进窗口，拖入只载入，不自动播放。
  • “录音”会弹出保存文件窗口（WAV），选定后立即开始录音。停止后录到的文件自动成为磁带机里的磁带，可以直接播放。
  • 播放和录音要求磁带机接在通电的主机上，目前开机后的经典 FC、金字塔学习机与裕兴学习机满足；不满足时这两个按钮置灰。断电时磁带机自动停止，磁带留在里面。
  • 金字塔学习机把程序存到磁带：进入“中西文 BASIC”后，先点“录音”选好保存位置，再输入 SAVE 并回车（PEC-586、686 要写文件名，如 SAVE "A"）；存完要一分钟多，屏幕上再次出现提示符“]”就是存完了，这时点“停止”。读回时先载入刚才的录音（拖进窗口即可），输入 LOAD 并回车（PEC-586、686 同样要写文件名），再点“播放”，提示符回来后用 LIST 查看。
  • 金字塔学习机的声像教学：在主菜单选“声像电视教学”（PEC-9588 按 8，PEC-586、686 按 D），载入声像教学磁带（立体声，左声道是声音、右声道是数据）并点“播放”，课文画面会跟着磁带出现（磁带开头有一段时间只显示标志），磁带里的声音从扬声器播出。
  • 裕兴学习机把程序存到磁带：在主菜单进入“工具软件”，选“游戏 BASIC”，再按 1 进入 BASIC 的 OK 提示符；先点“录音”选好保存位置，再输入 SAVE"A" 并回车，屏幕上出现 OK 就是存完了，这时点“停止”。读回时先载入刚才的录音（拖进窗口即可），输入 LOAD"A" 并回车，再点“播放”，OK 回来后用 LIST 查看。
  • 裕兴学习机的声像卡：在 V8.0-C 的主菜单选“声像学习”，先显示“裕兴声像卡”的标志，载入声像教学磁带（立体声，左声道是声音、右声道是数据）并点“播放”，课文画面会跟着磁带出现，磁带里的声音从扬声器播出。
  • 播放或录音中只有“停止”和“取出”可用，取出会先停止再取出。
  • 时间轴：里面有磁带且不在录音时，点一点“位置”那一列（如“0:23 / 0:40”，鼠标移上去会变手形、底色加深），在它上方弹出一条长长的时间轴，用来在一盘磁带里找到某个程序的位置。
    • 图上的竖条是磁带上各处声音的大小（只看数据那一路：立体声磁带看右声道，单声道磁带整路），连续半秒以上几乎没有声音的空白段用浅色底标出（磁带开头与结尾的空白也算），一段程序通常就是两段空白之间的那一段；下面是刻度与时间，竖线是此刻的播放位置。
    • 鼠标在图上移动时会显示这个位置的时间；点击或按住拖动后松开，磁带就定位到松开的位置（拖动中不会定位）。停止和播放时都可以定位，播放时会从新位置继续播放；没有开机也可以定位。
    • 载入磁带后要先分析一遍声音，这时图上写“分析中”并带进度，还是可以点击或拖动定位，只是看不到声音的大小；分析失败时会写“无法分析这盘磁带的声音”。分析结果只在这次运行里保存，取出或换一盘磁带后重新分析。
    • 按 Esc、点时间轴之外的地方、再点一次“位置”列、开始录音或取出磁带时时间轴关闭；点这一行里的“播放”“停止”等按钮不会关闭它，可以边找边播。

打印机

只显示状态：空闲、打印中、打印完成，没有按钮。主机没有打印机时，这一行显示“空闲”。每输出一页，会用通知告诉你文件名，并保存成 PNG 图片，保存位置在首选项的“打印机”分组里设置。点通知里的“打开图片目录”，就能在文件管理器里看到这些图片。

拖放小结

拖入的文件 处理
.nes 打开卡带并开机，已选机型变成经典 FC
.img、.ima、.vfd、.dsk、.flp 载入软驱 A
m4a、mp3、wav、aac、flac、ogg、opus、mp4、mka 载入磁带机

一次拖入多个文件时依次处理，不支持的文件类型会用通知说明。拖放只在主窗口生效。
