使用说明

快速开始

本页目录

  • 运行要求
  • 玩红白机游戏
  • 使用学习机
  • 常用操作

运行要求

  • Windows 7 SP1 到 Windows 11 的 64 位系统，不需要安装其他运行库。
  • 电脑最好有可用的显卡与驱动（支持 Direct3D 11）；没有 3D 加速的虚拟机和远程桌面会改用软件渲染显示画面，速度比有显卡时慢，见常见问题。
  • Ember 是一个单独的 Ember.exe，解压后直接运行，不需要安装。

玩红白机游戏

  1. 点“文件→打开卡带”（Ctrl+O），选择 .nes 文件；也可以把文件直接拖进窗口。
  2. 打开后立即开机并开始运行。
  3. 用键盘玩：默认的方向键是 ↑ ↓ ← →，Z 是 B，X 是 A，C、V 是连发 B、连发 A，右 Shift 是选择，回车是开始。键位可以在“设置→手柄设置”里改，见键盘、手柄与鼠标。

最近打开过的卡带在“文件→最近打开”里，最多保留 10 个。

使用学习机

  1. Ember 不自带学习机的 ROM：点“设置→机型与 ROM”，点“下载 ROM”一键下载全部支持机型的 ROM 并自动添加；也可以自己准备 ROM 文件后用“添加 ROM 文件”逐个添加，见机型与 ROM。
  2. 点“机器→选择机型”，点这个机型，就会用它的 ROM 直接开机。
  3. Ember 会记住这个机型，下次启动后点“机器”菜单里的“开机”（或 F9、系统栏左侧运行按钮展开的“运行”面板里的“开机”）就直接开这个机型。
  4. 要载入软盘，展开系统栏左侧的设备按钮，在软驱一行点“载入镜像”，也可以把镜像文件拖进窗口。

没有 ROM 的机型（比如还没有支持的机型）在“选择机型”里是置灰的，旁边写着“未添加 ROM”或“暂未支持”。

常用操作

要做的事 做法
暂停、继续 F8
软复位 F7
硬复位 Ctrl+F7
开机或断电 F9
全屏 F11
静音 “机器”菜单里的“静音”，或运行面板里的静音按钮

在 Windows 上，点击画面后键盘会整个交给模拟的机器，包括 Esc 与 F 键，这时外壳的快捷键不生效。点一下画面以外的地方，快捷键就恢复了。详见窗口、菜单与快捷键。
