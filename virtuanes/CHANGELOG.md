# 更新记录

VirtuaNES 调试版：带调试服务、供 fcdev 使用的模拟器。

## 1.1.0 调试版（2026-11-13）

### 小霸王学习机 SB2000

- 内存与 DMA 按真机实测修改：内部 RAM 只有 2K，`$4400-$5FFF` 不是 RAM，DMA 的长度、目的和限制与真机一致。
- 图形按真机实测修改：灰度、最左 8 像素的显示与屏蔽、颜色增强、精灵的翻转、镜像与前后关系、8x16 精灵、状态标志、名称表选择、精灵与调色板的读回。
- 定时器按真机实测修改：一次计时下溢后保持预置值，预置值可以读回。

### 调试服务

- `trace` 新增 `unique` 选项，每条指令只记录第一次。
- 新增 `dialogs` 命令：自动关闭模拟器弹出的对话框并记录文字，文件对话框按“取消”。
- 新增 `tape` 命令：播放与录制数据录音机。
- `shot` 命令按每一行的黑白与颜色增强出图。
- 步步高键盘也能用 `key` 命令输入。

### 其他

- 编译时不再结束用户自己打开的模拟器。
