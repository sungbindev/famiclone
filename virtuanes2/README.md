# VirtuaNES2

面向 FC 爱好者与开发者的新一代模拟器，重点支持小霸王、步步高、裕兴等学习机。硬件和 mapper 都是可替换的模块：安装 mapper 插件就能增加或更新机型的电路适配，不用升级整套软件。

目前处于设计阶段，还没有可运行的版本。

## 特点

- 按真机的结构运行：主机、卡槽、卡带分开，卡带上的 mapper 芯片由插件提供。
- mapper 以插件安装，程序里不内置任何机型数据；开发者写好插件就能使用全部硬件模块。
- CPU、PPU、声音、软驱、磁带、键盘、手柄、鼠标等都是独立的硬件模块，每个型号一个模块。
- 支持软驱和磁带：软盘镜像、数据磁带，以及声像磁带。
- 虚拟针式打印机：打印内容自动保存为 PNG 图片，不弹出保存窗口。
- 调试服务可开关，通过 TCP 控制模拟器，开发者与 Copilot 不必反复重启模拟器。
- 使用 Electron 界面和 C++ 核心，支持 Windows 与 macOS。
