# 界面

VirtuaNES2 的界面：窗口布局、页面、菜单、状态栏、画面显示和界面状态的保存。界面只做外壳和显示，运行与数据都在 C++ 核心，见 [01-软件架构设计.md](01-软件架构设计.md)。界面不做调试窗口，调试能力只经 [04-调试服务.md](04-调试服务.md) 开放。

界面效果先做成静态原型确认，见第 10 节。

状态说明同 01。

## 1. 决策

| 决策项 | 结论 | 状态 |
| --- | --- | --- |
| 调试窗口 | 界面不做；普通用户看不到调试功能 | 已定 |
| 外壳 | 沿用如见客户端的外壳：标题栏、活动栏、边栏、标签页、页面区、底部面板、状态栏；布局与尺寸取值同如见 | 拟定 |
| 组件来源 | 外壳与页面的全部组件与令牌来自 rujian-ui-kit，客户端不另写组件、不自定义令牌；缺少的组件先加到组件库 | 拟定 |
| 右边栏 | 不使用 | 拟定 |
| 页面与对话框 | 要长时间停留、来回查看的内容做成页面；对话框只用于做完就关的操作，对话框都是独立的系统窗口 | 拟定 |
| 页面与模块 | 页面按模块登记，同如见：页面、菜单项、活动栏按钮、面板、状态项都由模块登记，外壳不写死入口 | 拟定 |
| 操作结果 | 操作结果与错误消息用通知；页面里只显示输入字段的校验提示 | 拟定 |
| 画面显示 | 核心输出完成颜色转换的帧缓冲，界面负责比例、缩放与显示 | 拟定 |
| 主题 | 深色、浅色、跟随系统；在首选项的“外观”里改 | 拟定 |
| 语言 | 界面文字为中文 | 已定 |

## 2. 窗口布局

```text
┌───────────────────────────── 标题栏 ─────────────────────────────┐
│ 活动栏 │ 边栏 │ 标签栏                                                │
│        │      │ 页面区                                                │
│        │      │ 底部面板                                              │
└───────────────────────────── 状态栏 ─────────────────────────────┘
                                              通知固定在右下角，状态栏之上
```

| 区域 | 尺寸 | 内容 |
| --- | --- | --- |
| 标题栏 | 高 36px | 应用图标、名称、菜单；右侧为边栏与底部面板的折叠按钮、系统窗口按钮 |
| 活动栏 | 宽 40px | 运行、卡带库、设备、mapper 插件四个页面按钮 |
| 边栏 | 默认宽 240px | 当前页面声明的内容；没有内容时不打开，折叠按钮置灰 |
| 标签栏 | 高 36px | 已打开的页面 |
| 页面区 | 其余空间 | 当前标签的页面 |
| 底部面板 | 默认高 160px | “消息”页签 |
| 状态栏 | 高 26px | 左侧机器状态，右侧运行速度与服务状态 |

- 尺寸、颜色、交互状态全部取组件库的令牌，规则同如见的外壳文档。
- 边栏只放控件与简短的信息；列表和表格放在页面区；边栏里已有的按钮，页面区不再重复。
- 没有打开的页面时，页面区居中显示淡色标志和入口列表（打开卡带、卡带库、设备、mapper 插件）。

## 3. 页面与模块

| 页面 | 标识 | 所属模块 | 边栏 | 说明 |
| --- | --- | --- | --- | --- |
| 运行 | `run` | `runtime` | 有 | 机器的画面；边栏是机器信息和控制 |
| 卡带库 | `library` | `cartridges` | 有 | 卡带列表与匹配状态 |
| 设备 | `media` | `media` | 有 | 软驱、磁带机与打印机 |
| mapper 插件 | `mappers` | `mappers` | 有 | 插件列表与详情 |
| 首选项 | `preferences` | `preferences` | 无 | 全部设置；有自己的分组导航 |

- 单例页面，重复打开聚焦已有标签。
- 再点一次选中的活动栏按钮，折叠或展开边栏。
- 首选项页没有边栏，所以边栏自动关闭，不留空栏。

## 4. 页面

### 4.1 运行

边栏分三组：

| 分组 | 内容 |
| --- | --- |
| 机器 | 主机型号、卡带、mapper 插件、状态；只读 |
| 控制 | 上电或断电、暂停或继续、软复位、硬复位 |
| 速度与声音 | 速度下拉（100%、50%、25%、200%、最快）、音量滑块与静音按钮 |

- 页面区只有画面，按比例居中显示，周围是黑底；画面左下角有“示意画面”仅在原型里出现，正式版没有。
- 电源与复位等按钮的可用状态：没有卡带时全部置灰；断电时暂停与软复位置灰；硬复位只要有卡带就可用。
- 画面上的提示：没有卡带显示“未插入卡带”，并指明去“文件”菜单或“卡带库”；断电显示“已断电”；暂停显示“已暂停”。
- 机器带鼠标时，画面右下角提示“点击画面捕获鼠标，双击右键释放”。

### 4.2 卡带库

- 页面区是表格：名称、mapper、变体、主机型号、匹配的插件、大小、状态；状态为“可运行”或“缺少插件”。
- 双击一行运行；缺少插件时，用通知说明缺少哪个 mapper 号与变体；单击缺少插件的行，在表格下方的提示块里给出同样的说明和去处。
- 边栏：搜索框、状态筛选（全部、可运行、缺少插件）、“添加文件夹”按钮，以及已添加的库文件夹。
- 库保存的是用户的文件路径，见 01 第 9 节。

### 4.3 设备

- 边栏是设备列表：软驱 A、软驱 B、磁带机、打印机，每项显示当前状态；设备的数量由当前主机与卡带决定，没有对应硬件的设备不显示或置灰。
- 软驱页：状态、镜像、大小、磁头位置、写保护开关；按钮“插入盘片”“取出”“保存镜像”。
- 磁带机页：磁带类型（数据磁带、声像磁带）、状态、文件、位置、进度条；按钮“播放”“录音”“停止”；声像磁带显示两个声道的电平，并且只能播放，不能录音。
- 打印机页：型号、状态（空闲、打印中）、已输出页数、最近一页、保存位置；按钮“输出当前页”“打开保存位置”。打印的每一页保存为一张 PNG，文件名按日期时间自动生成，不弹出保存窗口；每输出一页，用通知告知文件名。保存位置在首选项的“打印机”里改。
- 介质的插拔与录放随时可以操作，与电源无关。

### 4.4 mapper 插件

- 页面区是表格：名称、版本、匹配、主机型号、来源（预装、用户安装、开发目录）、状态；选中一行，下方显示清单摘要：标识、版本、发布者、匹配、主机型号、存储区、挂接设备、寄存器范围、状态声明。
- 边栏：搜索框、来源筛选、“安装插件”按钮。
- 预装插件只能停用，不能删除；用户安装的可以卸载，见 03 第 7 节。

### 4.5 首选项

左侧是分组导航，右侧是设置行（名称与说明在左，控件在右）。

| 分组 | 设置项 |
| --- | --- |
| 外观 | 主题 |
| 画面 | 画面比例（4:3、8:7）、缩放方式（适应窗口、整数倍）、显示全部 240 行 |
| 声音 | 缓冲大小（低延迟、标准、稳定）、启动时静音 |
| 输入 | 点击画面捕获鼠标、手柄按键映射、学习机键盘映射 |
| 调试服务 | 启用、端口、令牌、调试输出目录 |
| 打印机 | 图片保存位置（文本框加“选择”按钮；文件名自动生成，不可设置） |
| 路径 | 用户插件目录（只读）、开发中的插件目录 |

- 设置项由各模块登记，首选项模块汇总，规则同如见；首选项页不显示操作结果，改动立即生效并保存。

## 5. 菜单与快捷键

菜单名带助记字母（Alt 加字母）；菜单项不带图标，显示快捷键，勾选与分隔线同如见。

| 菜单 | 菜单项 |
| --- | --- |
| 文件（F） | 打开卡带、最近打开、关闭卡带、退出 |
| 机器（M） | 上电或断电、暂停或继续、软复位、硬复位、静音、截图 |
| 视图（V） | 运行、卡带库、设备、mapper 插件、边栏、底部面板、全屏 |
| 设置（S） | 首选项、mapper 插件 |
| 帮助（H） | 打开日志目录、关于 VirtuaNES2 |

默认快捷键（拟定）：

| 命令 | 快捷键 |
| --- | --- |
| 打开卡带 | `Ctrl+O` |
| 上电或断电 | `F9` |
| 暂停或继续 | `F8` |
| 软复位 | `F7` |
| 硬复位 | `Ctrl+F7` |
| 截图 | `Ctrl+Shift+S` |
| 切换边栏 | `Ctrl+B` |
| 切换底部面板 | `Ctrl+J` |
| 全屏 | `F11` |
| 首选项 | `Ctrl+,` |

- 快捷键的登记、冲突检查与修改同如见：全部命令之间不重复，用户修改保存在本地配置里，可在首选项的快捷键分组里改（该分组尚未画进原型）。
- 运行中，模拟器画面获得焦点时，键盘事件先交给学习机键盘或手柄；快捷键只在不被设备占用的组合上生效，具体规则在实现时按如见的快捷键规则定。

## 6. 底部面板与状态栏

- 底部面板只有“消息”页签，列出运行消息：主机装配结果、mapper 匹配结果、介质插拔、复位、调试服务的连接。它不是调试器，也不显示内存与寄存器。标题行右侧有“清空”和“关闭”。
- 状态栏左侧：电源状态点和文字（运行中、已暂停、已断电、无卡带）、主机型号、卡带名、mapper 插件；右侧：帧率、速度、音量、调试服务状态、通知按钮。
- 调试服务状态项显示地址与连接数，关闭时显示“调试已关闭”；点击打开首选项的“调试服务”分组。
- 状态点：运行中为绿色，已暂停为黄色，其余为灰色；状态不只靠颜色，旁边有文字。

## 7. 画面显示

- 画面由画布显示，比例可选 4:3 与 8:7，缩放方式为适应窗口或整数倍，边缘用黑底；只影响显示，不影响模拟。
- 点击画面捕获鼠标，双击鼠标右键释放，沿用旧版的做法；只有机器带鼠标时才捕获。
- 全屏用 `F11`；全屏时只显示画面。
- 键盘按物理键位（`KeyboardEvent.code`）采集，映射到学习机键盘或手柄，见 01 第 7 节。

## 8. 对话框、通知、右键菜单、主题

- 对话框、通知、右键菜单、文字选择规则同如见：对话框是独立的系统窗口，通知在右下角，外壳文字不能选中。
- “关于 VirtuaNES2”对话框：标志、名称、版本、核心版本、许可证，以及“第三方依赖”小节：一行说明和表格（名称与版本、作者、许可）；清单由构建脚本从 `third-party.json` 生成，不手写，做法同如见；旧版 VirtuaNES 不在清单里。
- 主题：深色、浅色、跟随系统，在首选项的“外观”里改；系统主题变化时，跟随系统的立即生效。

## 9. 界面状态的保存

| 状态 | 保存 |
| --- | --- |
| 窗口位置与大小、是否最大化 | 保存 |
| 主题、快捷键、首选项各项 | 保存 |
| 边栏、底部面板的展开状态与底部面板高度 | 保存；没有保存过时都展开 |
| 边栏宽度 | 不保存 |
| 已打开的标签 | 不保存，启动时打开“运行”页 |
| 最近打开的卡带、库文件夹 | 保存 |

## 10. 界面原型

- 位置：[prototype/index.html](prototype/index.html)，用浏览器直接打开；样式在 `prototype/styles/`，脚本在 `prototype/scripts/`。
- 范围：外壳、五个页面、菜单与快捷键、通知、关于对话框、深色与浅色主题。电源、复位、暂停、速度、音量、卡带切换、软驱插拔、磁带录放、打印机输出一页、表格筛选与选择、首选项分组切换、主题切换都能操作，用来确认效果；没有真实读写文件，数据都是示意。
- 与正式实现的关系：原型的令牌取值与 rujian-ui-kit 一致，但样式和脚本是手写的，只用于确认效果；正式界面用 React 与 rujian-ui-kit 重做，原型确认后不再维护。
- 已目测：深色主题的运行（有画面、暂停、断电、无卡带）、卡带库、设备（软驱、磁带与打印机）、mapper 插件、首选项的“画面”“调试服务”与“打印机”、菜单、通知、关于对话框、空工作区，以及浅色主题的运行页与关于对话框。
- 未目测：首选项的“外观”“声音”“输入”“路径”分组、窄窗口下的布局、软驱 B 页、键盘操作与焦点轮廓。
- 原型的画面与表格数据仅为示意，不代表真实的匹配规则与画面。
