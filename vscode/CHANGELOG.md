# 更新记录

## 0.13.3

## 0.13.2

- 命令标题统一为 FCDEV。

## 0.13.1

- 扩展显示名改为 FC Dev。

## 0.13.0

- 模拟器工具：`emu_run` 除了按帧数，还可以按 CPU 周期、指令条数或扫描线数运行。
- 模拟器工具：新增 `emu_speed`，调运行速度（百分比或不限速）并可让声音不等声卡；`emu_load` 可只预览 NES 文件头与匹配的 mapper 插件，不装入。
- 模拟器工具：断点支持条件表达式，可以启用、禁用与修改条件，新增 IRQ、NMI、BRK 与复位断点。
- 模拟器工具：检查新增调用栈与调色板；记录的指令跟踪、寄存器读写与中断可以环形记录，并能边记边读。
- 模拟器工具：新增子程序周期统计（`emu_profile`）与 PPU、mapper 寄存器读写及中断的扫描位置记录（`emu_events`）。

## 0.12.0

- 构建：学习机项目默认只生成程序；要软盘镜像时在 `fcdev.json` 里写 `diskName`，值是镜像文件名（如 `"diskName": "sb97-run-game.img"`，没写 `.img` 会自动补上），镜像生成在产物旁边。
- 运行：没有写 `diskName` 的学习机项目，运行时照常生成一张临时镜像，不留在产物目录里。

## 0.11.0

- 目标：步步高新增汇编运行库 `bbg.lib`，封装 BIOS、文件、文字与 DOS 调用共 59 个函数，配套 `bbg.inc` 符号文件，汇编程序直接引用。
- 模板：四个机型的游戏程序统一为 `game` 项目，裕兴、SB97、SB2000 生成 `GAME.EXE`，步步高生成 `GAME.CMD`；不带参数时列出盘上的 `.NES` 文件，手柄上下选择，Start 运行，带参数时直接运行指定的游戏。
- 模板：步步高与裕兴原来的 NES 加载程序（`run-nes`）并入 `game` 模板；裕兴的菜单标题与操作提示改为中文，背景改为蓝色。
- 模板：SB97、SB2000 的游戏菜单背景改为蓝色；SB2000、步步高的游戏菜单全屏显示，不输出到控制台。
- 修复：裕兴游戏在 V9.0-98 上运行 mapper 4 游戏的问题。
- 模板：各机型 `disk` 目录的 `README.TXT` 加入作者与 GitHub 地址，页脚网址为 https://fcdev.cn。

## 0.10.0

- 目标：新增裕兴学习机目标与汇编模板，构建出可在裕兴 DOS 下运行的 `.EXE`，并能在 Ember 里自动开机、进入 DOS 运行。裕兴的 DOS 运行程序需要写扩展名（`hello.exe`），目前只用 V8.2-D 的 ROM 验证过。
- 目标：新增步步高学生电脑目标与汇编模板，构建出可在 BBGDOS 下运行的 `.CMD`。步步高的 DOS 在软盘上，磁盘镜像建在 `fcdev.json` 的 `diskImage`（带 DOS 的系统盘镜像）上，系统盘本身不改；运行时 Ember 自动以软驱一号开机、进入 DOS 并输入程序名（不用写扩展名）。目前只用软驱一号的 ROM 验证过。

## 0.9.0

- 反汇编：映像的各段在文件里首尾相接时（如学习机的 BIOS 映像），生成的 `link.cfg` 把所有段输出到同一个文件，可以直接作为整机 ROM 工程（`rom` 目标）的链接配置，构建出与原映像逐字节一致的固件；段之间有空隙时仍然每段一个输出文件。

## 0.8.1

- 扩展显示名改为 FC 6502 Dev Kit。

## 0.8.0

- 目标：新增“整机 ROM 工程”目标 `rom`，用来构建各机型（步步高、学习机等）的 BIOS 与固件源码；`fcdev.json` 的 `firmware` 指向完整的固件当底，构建时把源码的链接结果覆盖进去，在 `targetOptions` 里写机型 `machine`、覆盖位置 `offset` 与固件大小 `size`。
- 运行：整机 ROM 工程构建后把产物当作该机型的固件在 Ember 里开机运行，不用输入程序名；`fcdev.json` 新增 `diskImage`，可以把一张现成的软盘镜像挂到软驱。

## 0.7.0

- 构建：`fcdev.json` 新增 `linkConfig`，可以指定自己的链接配置，用于目标自带布局之外的内存排布（如整机映像）；写了它，产物不再受目标的大小上限限制。

## 0.6.0

- 构建：学习机（SB2000、SB97）项目构建时默认同时生成软盘镜像，在 `fcdev.json` 里写 `"disk": false` 可以只生成程序。“构建磁盘镜像”命令、任务的 `disk` 命令与 `fcdev_build` 的 `disk` 参数不再需要，已去掉；`tasks.json` 里 `command` 为 `disk` 的任务请删除或改成 `build`。
- 构建：软盘镜像里除程序外，还会放进项目 `disk` 目录下的全部文件（文件名须是 8.3 名字，不能有子目录），用 WinImage 等软件打开镜像就能看到使用说明。
- 新建项目：学习机模板自带 `disk/README.TXT` 使用说明示例，可以改写或再加文件。
- 目标：新增小霸王 97 学习机（SB97）目标与汇编模板，构建出可在 SB97 的 DOS 下运行的 `.EXE`，并能在 Ember 里自动开机、进入 DOS 运行。

## 0.3.0

- 构建：新增任务类型 `fcdev` 与命令“构建项目”“构建磁盘镜像”“构建当前文件”“构建当前目录”，用随扩展发布的 cc65 构建 C 与 ca65 汇编程序，错误出现在“问题”面板并可跳转到源码行。
- 目标：内置 NES 与小霸王学习机 SB2000 两个目标，含头文件、运行库与大程序换页；SB2000 程序里可以直接写汉字，构建时自动转成学习机用的 GB2312。
- 运行：命令“运行”在 Ember 里运行程序，学习机程序自动开机并运行；Ember 的位置在设置 `fcdev.emulator.path` 里指定。
- 调试：命令“调试运行”启动调试模式的 Ember；新增调用调试请求、查看调试请求说明、保存调试截图、监视调试事件、显示调试服务地址 5 个命令；调试端口在设置 `fcdev.emulator.debugPort` 里指定。
- 新建项目：命令“新建项目”选目标（NES、SB2000）与语言（C、汇编），生成项目、示例程序与构建任务。
- 反汇编：命令“反汇编映像文件”把 NES 程序、SB-DOS 程序或平铺二进制反汇编成可重新汇编、逐字节一致的 ca65 工程。
- 查询：命令“查询 C 接口”查 SB2000 运行库的函数与系统调用，“打开使用文档”读随扩展发布的使用文档，“显示项目信息”查看目标与头文件目录。
- Copilot：新增 6 个 fcdev 工具（新建项目、构建、运行、项目信息、C 接口、使用文档），工具共 36 个；反汇编与模拟器工具在没有 `fcdev.json` 的工作区里也能用。
- Copilot：随扩展提供 skill `fcdev-app-development`（用 fcdev 开发 NES 与 SB2000 程序）。
- 要求 VS Code 1.101 或更高版本。

## 0.2.0

- 给 Copilot 提供 19 个 6502 反汇编工具：新建与打开工程、追踪代码、查看带符号与注释的反汇编、交叉引用、例程与调用图、搜索、批量命名与注释、导入运行记录、生成 ca65 源码工程、回读校验。
- 给 Copilot 提供 11 个模拟器工具：启动或连接 Ember、载入 NES 文件或整机、运行、断点、单步、读写内存与寄存器、截图、按键与手柄、记录指令跟踪、CDL 与调用记录。把运行记录导入反汇编工程再追踪，就能找到静态分析看不到的代码。
- 新建反汇编工程和载入程序都可以直接选目标（NES、SB2000）：自动用对应的映像格式、符号名和开机步骤；支持 NES 的常见映射器、SB-DOS 程序（含多页）和学习机的 BIOS。
- 随扩展提供 Copilot 的反汇编指令、skill 与自定义智能体“6502 反汇编工程师”：按识别、追踪、区域分类、命名、注释、分层、生成与回读、构建八步完成，每步有完成标准；附一个可以走一遍的示例工程。
- 会修改工程、运行汇编链接、启动 Ember、修改模拟器内存与寄存器、保存截图、使用工作区之外的文件的调用，执行前需要确认；工程目录必须在工作区里；截图作为图像返回（需要较新的 VS Code）。
- 停用扩展时自动关闭模拟器会话，并结束工具启动的 Ember。
- 打开含反汇编工程的工作区时也会激活扩展。
