# 文档索引

需要某个主题的完整细节（系统调用的参数、硬件寄存器、构建规则、调试请求全表等）时使用。本 Skill 的其他文件只写速查与易错点，细节以 fcdev 的使用文档为准，不在这里复制。

## 读取顺序

1. 用工具 `fcdev_docs`：不带 `query` 列出全部主题；`query` 给主题名（如 `sb2000`、`syscall`）或关键词，只匹配到一份时返回全文，多份时列出摘要。用户也可以用命令“fcdev：打开使用文档”。
2. 工具不可用（没有安装扩展或版本较旧）时，请用户安装或升级 fcdev 扩展；不要让用户克隆 famiclone 仓库。
3. 都读不到时说明限制，不凭记忆补细节。

## 与其他参考文件的分工

- 本目录的其他文件只写入门速查和易错点；与使用文档冲突时以使用文档为准，并提示用户同步本 Skill。
- 接口的唯一来源是头文件的文档注释：用 `fcdev_api` 查询，整本参考用 `fcdev_docs` 查询主题 `api`，不要用 `docs/` 里的描述代替它。
