# SB2000 程序开发

开发小霸王学习机 SB2000（SB-DOS 2.00）的应用程序时使用：构建出能在 DOS 提示符下运行的 `.EXE`。目标文件位于 `targets/sb2000/`（`include/`、`asminc/sb2000.inc`、`link.cfg`、`link-banked.cfg`、`api-reference.md`、`api-unwrapped.json`）。本文只写已在模拟器里验证过的用法，具体功能的做法见 [sb2000-recipes.md](sb2000-recipes.md)。

## 目标定义

| 项 | 值 |
| --- | --- |
| 编译目标 | cc65 的 `none`，用 `none.lib` 提供乘除、移位、`memcpy` 等，不使用它的启动代码 |
| 启动代码 | `lib/crt0.o` |
| 库 | `sb2000.lib`、`none.lib` |
| 预定义宏 | `__SB2000__` |
| 打包器 | `flat-exe`：文件头必须匹配 `4C????AA55`，普通程序不超过 16384 字节 |
| 产物 | 大写主名的 `.EXE`，如 `build/sb2000/HELLO.EXE` |
| 程序名 | 符合 DOS 8.3，不与 DOS 内部命令重名 |
| 磁盘镜像 | `fcdev.json` 配置了 `diskName` 时，构建同时生成 1.44MB FAT12 镜像，里面是这个程序与项目 `disk` 目录下的全部文件；没有配置时不生成 |
| 运行 | 需要固件，`fcdev.json` 的 `firmware` 指向 BIOS 文件 |

## 程序格式

- 映像从 `$8000` 起，窗口 `$8000` 到 `$BFFF` 共 16K；超过用多页（见下文）。
- 文件头 5 字节 `4C lo hi AA 55`（`JMP` 入口加魔数），其后 3 字节：偏移 5 由 DOS 装入时写成起始页号（`sb_puts` 要用），偏移 6 是页数，偏移 7 保留；启动代码全部写 `00`。
- 程序以 `RTS` 返回 DOS，DOS 会清屏，所以显示完要先等键再返回。
- `main` 的返回值被忽略，没有退出码。
- 系统调用：写 `SYS_FUNCTION`、`SYS_SUBFUNCTION`，再 `JSR SYSCALL`（`$FFF0`）；A、X、Y 与进位都不会带回结果，结果只在各服务规定的内存变量里。C 程序直接用运行库函数，不手写这套约定。

## 内存布局

| 区域 | 位置 | 说明 |
| --- | --- | --- |
| 零页 `ZP` | `$0060` 起 `$20` 字节 | C 运行库使用；BIOS 符号表里的零页符号只到 `$50`，开机后 1800 帧内对 `$51` 到 `$FF` 设写断点没有命中；汇编程序自己用零页时，以 `sb2000.inc` 里的零页单元一节为准，避开 DOS 已用的单元 |
| `MAIN` | `$8000` 到 `$BBFF`，共 15K | `HEADER`、`STARTUP`、`LOWCODE`、`ONCE`、`CODE`、`RODATA`、`DATA` 依次放入；`BSS` 紧随其后，不占文件空间但占地址 |
| C 软件栈 | 1K，`$C000` 向下 | `__STACKSTART__`、`__STACKSIZE__`、`__ZPSTART__` 是弱符号，可以覆盖 |
| 硬件栈 | `$0100` 到 `$01FF` | `main` 入口时 `S` 为 `$EA`，约 235 字节可用 |
| 其他区域 | `$5000-$5FFF` 2K 工作 RAM；`$6000-$7FFF` 8K 扩展 RAM（任何窗口映射下都可见，`$6200-$65FF` 一带是 DOS 的状态变量） | 系统调用的参数与结果变量在这里 |

- 程序（含 `BSS`）超过 15K 时 `ld65` 链接失败。
- `DATA` 随文件原位装入，不复制。
- 启动代码处理：写文件头、占页（文件占的页不足 4 页时，紧接着程序的页申请下来，防止 `BSS` 与栈所在页被别人分走，申请不到则带错误 `SB_ERR_NO_MEMORY` 返回 DOS）、设软件栈、清 `BSS`、调构造函数、`_main`、析构函数、释放页、`CLC`/`RTS`。汇编程序不要自己改它。
- 返回 DOS 时不保存也不恢复零页；运行子程序（`sb_exec`）前后库会保存、恢复零页 `$60` 到 `$7F`。

## 大程序（多页）

超过 16K 时在 `fcdev.json` 写 `"targetOptions": { "banks": N }`（N 为 0 到 113，默认 0）。DOS 按文件大小一次装入整个文件，程序用功能 `$29`（`sb_window_map`）把后面的页换进窗口 2，换页由编译器与运行库自动完成。

文件按 4K 一页排列：

| 文件页 | 内容 | 地址 |
| --- | --- | --- |
| 0、1 | 常驻部分 `MAIN`：`main`、运行库、没放进库页的全部代码与数据、`BSS`，共 8K | `$8000` |
| 2 | 库页 1，启动时就在窗口 2 | `$A000` |
| 3 | 栈页（窗口 3，C 软件栈在顶端 1K），不能当库页 | `$B000` |
| 4 起 | 库页 2 到 N | `$A000` |

写法（头文件 `sb2000-bank.h`，`sb2000.h` 已包含）：

```c
/* parser.h：声明放在 SB_BANK_CALLS_BEGIN 里，调用时由编译器经蹦床换页 */
SB_BANK_CALLS_BEGIN(2)
unsigned int parse(unsigned int value, unsigned char mode);
SB_BANK_CALLS_END()

/* parser.c：定义放在 SB_BANK_BEGIN 里，进库页 2 */
SB_BANK_BEGIN(2)
unsigned int parse(unsigned int value, unsigned char mode) { return value + mode; }
SB_BANK_END()
```

- `SB_BANK_BEGIN(n)` 把后面的代码与只读数据放进段 `BANKn`；`SB_BANK_CALLS_BEGIN(n)` 让编译器把对这些函数的直接调用改成经蹦床换页，库页函数之间可以嵌套调用。`sb_bank_select(n)`、`sb_bank_current()` 可自己调用，用来直接读库页里的数据。
- 库页 n 对应的程序页：1 是第 2 页，n 不小于 2 时是第 n+2 页（第 3 页是栈页）。
- 一页放不下时 `ld65` 链接失败；用到的库页号超过 `banks` 时链接失败并提示加大 `banks`。
- 限制：
  - 库页里只放代码与只读数据（`const`）；可写变量与 `BSS` 在常驻部分，常驻部分连同运行库共 8K。
  - 只有按函数名的直接调用经过蹦床；函数指针调用库页函数、变参函数都不行。
  - 库页函数返回指向库页数据的指针时，调用者拿到时窗口 2 已换回，指向的内容可能已被换走；库页里的代码把窗口 2 的地址传给系统服务时，指的是当时换入的库页。
  - 最多 113 个库页，程序文件 116 页（约 468K）；DOS 一次把整个文件装入内存，连续空闲页不够时程序不能启动（实测 116 页能装入，160 页不能）。

## C 运行库

`#include <sb2000.h>` 即可，它包含 `sb2000-symbols.h` 与 13 个模块头文件，并提供 `SB_BYTE_AT(地址)`（读写固定地址字节）和底层 `sb_syscall(功能号, 子功能号)`。共 184 个函数。

| 头文件 | 内容 |
| --- | --- |
| `sb2000-system.h` | 等帧、NMI 与 IRQ 的开关与钩子、显示开关、系统初始化、跨页调用与跳转、上下文保存恢复、`sb_exec` 运行子程序 |
| `sb2000-memory.h` | 页的申请与释放、远读写、窗口映射、窗口地址换算 |
| `sb2000-bank.h` | 大程序换页的宏、`sb_bank_select`、`sb_bank_current` |
| `sb2000-text.h` | `sb_puts`、`sb_newline`、字符与数字输出、光标 |
| `sb2000-input.h` | 键盘、手柄、鼠标 |
| `sb2000-clock.h` | 系统日期与时间 |
| `sb2000-file.h` | 文件与目录：打开、读写、整个加载与保存、删除、改名、属性、遍历 |
| `sb2000-disk.h` | 软驱：按扇区读写、成批读写、扫描、格式化磁道、空闲字节数 |
| `sb2000-display.h` | 屏幕单元、文字、字模、窗口保存还原、调色板、显存 DMA、图片解压与显示 |
| `sb2000-math.h` | 伪随机数、除法、浮点与 40 位整数的文字转换、直线步进、3 字节整数运算 |
| `sb2000-sound.h` | 曲子与音效、WAV、语音 |
| `sb2000-printer.h` | 24 针点阵打印机 |
| `sb2000-ime.h` | 中文输入法 |

约定：

- 命名 `sb_<模块>_<动作>`；返回 DOS 出错码或软驱状态码的函数，0 表示成功，结果经指针参数带回。
- 字符串、缓冲区、结构体指针必须在程序窗口 `$8000` 到 `$BFFF` 里，读写目标不能在窗口 3；系统服务换页后程序窗口不可见的情况，函数内部已经处理。
- 库内部辅助函数以 `sbi_` 开头，不对外，不要调用。
- 链接只带入程序用到的函数。

### 查询接口（必须用，不凭记忆）

- `fcdev_api`（或命令“FC Dev：查询 C 接口”）：不给 `query` 列出全部模块；`query` 给函数名得到完整文档（签名、系统调用、说明、参数、返回值）；给模块名或头文件名得到函数列表，如 `file`；给 `$7B` 或 `$7B/$09` 得到用到某个系统调用的函数；给其他词按名称与说明搜索。
- 整本文档：`targets/sb2000/api-reference.md`，末尾有“系统调用覆盖表”。
- 没有封装的功能：`api-unwrapped.json` 登记了没封装的功能号及原因。主要有文件系统内部步骤（FAT、簇链、扇区定位）、带步长的屏幕单元写入、显存填充与 DMA 变体、卡拉 OK、声音的部分子功能、语音的 NMI 发送与播放列表等。需要时用 `sb_syscall` 加 `sb2000-symbols.h` 的常量自行调用，并按 [sb2000-recipes.md](sb2000-recipes.md) 的约定处理变量与结果，写完在模拟器里验证。

## 符号定义

- 汇编：`.include "sb2000.inc"`，只含符号不占空间：系统调用、零页单元、内核入口、功能号、子功能号、变量（出错码与显示、文件与目录、内存页、磁盘、键盘手柄鼠标、参数单元）、文件打开方式、出错码、运行库入口，每个符号行尾有注释。
- C：同一份符号在 `sb2000-symbols.h`，加 `SB_` 前缀（如 `SYS_FUNCTION` 对应 `SB_SYS_FUNCTION`）。该头文件是由 `sb2000.inc` 生成的，不要手改。

## 汇编程序

- `.export _main`，由启动代码调用；调用库函数用 `.import _sb_puts, _sb_getkey` 这样的带下划线符号，参数用 cc65 的 fastcall：最后一个参数在 A（低）与 X（高），其余在 C 栈上，被调用者弹出。
- 字符串指针传参：`lda #<msg / ldx #>msg / jsr _sb_puts`。
- 返回 DOS 用 `rts`。

## 最小程序

C：

```c
#include <sb2000.h>

int main(void)
{
    sb_puts("Hello, SB2000!");
    /* GB2312：你好，小霸王！ */
    sb_puts("\xC4\xE3\xBA\xC3\xA3\xAC\xD0\xA1\xB0\xD4\xCD\xF5\xA3\xA1");
    sb_getkey();   /* DOS 在程序返回后会清屏，不等待就看不到输出 */
    return 0;
}
```

中文使用 GB2312 编码，字符码不小于 `$A1` 的两个字节显示一个汉字；源文件里直接写中文字符不会得到 GB2312，要写成 `\x` 字节序列或先转码。

## 限制与没验证过的事

- `main` 返回值不是退出码，DOS 不读取。
- 运行需要用户自己提供 BIOS 文件；DOS 启动后要按两次回车跳过日期与时间提示，才能输入程序名。
- 英文输入法（序号 9）下按键不设结果标志，`sb_ime_key_wait` 会一直等；要用全拼等需要选字的输入法。外挂输入法模块与联想方式没有验证。
- 没验证过：屏幕绘图与精灵等直接操作 PPU 的程序；显示服务 `$3B-$61` 的参数只实测了 `$40` 子功能 0 的整屏填充和 `$3C` 的图块号，其余只读过代码；声音服务 `$65` 的音乐数据格式。涉及这些要先写小程序在模拟器里实测，不要把读过代码的推测当作结论。
