# SB2000 常用做法与易错点

在 SB2000 上实现具体功能时使用。下表的符号名（`SYS_FUNCTION`、`FN_INPUT` 等）是汇编用的 `sb2000.inc` 里的名字，C 里加 `SB_` 前缀；C 程序一般直接用运行库函数（用 `fcdev_api` 查），只有运行库没封装的服务才手写系统调用。表里的功能号写法：`$7B/$09` 表示功能号 `$7B`、子功能号 `$09`。

## 常用做法

| 要做的事 | 做法 |
| --- | --- |
| 调用系统服务 | 写 `SYS_FUNCTION`、`SYS_SUBFUNCTION`，`JSR SYSCALL`；A、X、Y、进位都不带回，结果只在内存变量里 |
| 显示文字 | C 用 `sb_puts`；汇编借用运行库：经功能 `FN_CALL_BANKED`（`SYS_GROUP=0`，入口写 `PROG_ENTRY_LO/HI`）调用 `LIB_PRINT_STRING`；字符串在程序里时 `LIB_GROUP` 写 `$80`，在 ERAM 里写 0；字符码不小于 `$A1` 按 GB2312 显示汉字；用 `LIB_NEWLINE` 换行（先把 `CURSOR_COL` 置 1） |
| 等待按键 | `sb_getkey`；系统调用是 `FN_INPUT` 的 `SUB_KEY_GET_WAIT`，结果在 `KEY_ASCII`、`KEY_SCAN` |
| 取命令行参数 | `CMD_TAIL`（`$6364`）：第 1 个字节是分隔空格，已转大写，以 0 结尾；`$6364` 为 0 表示没有参数 |
| 读整个文件 | 打开（`$7B/$09`，方式 0）→ 取大小（`$7C/$0D`）→ 按页分配（`$7E/$00`）→ 读入（`$7C/$0F`）→ 关闭（`$7B/$0A`）→ 释放（`$7E/$01`）→ 软驱停转（`$80/$07`） |
| 读文件的一段 | 打开后写 `FILE_OFFSET_0-2`、`FILE_SIZE_0-2`（长度）、`FILE_START_PAGE`，调用 `$7C/$05`；越界出错码 `$14` |
| 写文件 | 方式 1 打开（不存在则建立，已存在则覆盖）→ 写 `FILE_SIZE_0-2`、`FILE_START_PAGE` → `$7C/$10` → 关闭；关闭前目录项不会写回；空文件不能用 `$7C/$10` 写，打开后直接关闭 |
| 改文件的一段 | 方式 2 打开已有文件 → 写 `FILE_OFFSET_0-2`、`FILE_SIZE_0-2`、`FILE_START_PAGE` → `$7C/$06` → 关闭；文件大小不变，可跨扇区，不能扩大文件 |
| 访问读入的数据 | `FN_MAP_WINDOW`（`$29`）把页映射到窗口（`SYS_PAGE` 页号、`SYS_WINDOW` 窗口号），窗口 3 在 `$B000`；程序自己在窗口 0 里，不要映射窗口 0 |
| 处理出错 | 每次文件或页服务调用后读 `DOS_ERROR`（`$6300`），0 为成功；出错时按已做的步骤倒序清理（关闭文件、释放页、软驱停转） |
| 读手柄 | 先 `$12/$85` 打开 NMI 里的手柄读取，再 `$6A/$00` 初始化；`$6A/$01` 不等待取键码、`$6A/$02` 等到有键，键码在 `PAD_KEY`（A 为 `$0F`，右为 `$08`，无键 `$FF`），原始状态在 `PAD1_BITS`、`PAD2_BITS`（位 7 为 A，位 0 为右） |
| 读鼠标 | `$14` 复位并检查 `MOUSE_PRESENT`（`$0633`）非 0 → `$13/$81` 允许鼠标中断 → `$6C/$00` 设范围（`$0646-$0649`，`$0652` 不要是 1-4）→ `$6C/$04` 设初始坐标（`$0652`、`$0653`）→ 随时 `$6C/$02` 取坐标（`$0646`、`$0647`）；`$6C/$03` 取按键状态（`$0360-$0367`，按住为 1，点击事件读走即清） |
| 把 NES 游戏当程序运行 | 读入 `.nes`、复制启动桩到 ERAM、写 `$4301` 后跳转（参考示例 `play`） |
| 播放 WAV | 功能 `$65`、子功能 `$0C`（C 里是 `sb_sound_play_wav`）；只读过代码，没有实测，用前先在模拟器里验证 |

文件打开方式（`FILE_MODE`）：0 打开已有文件、1 创建或覆盖、2 打开已有文件并在关闭时写回目录项、3 删除、4 取目录项、5 创建目录项（只支持一级子目录）；不小于 6 时出错码 `$28`。

## 要避开的坑

- **程序返回后 DOS 会清屏。** 显示完先等按键再返回，否则看不到输出。
- **运行库例程拿不到寄存器参数。** 经功能 `$25` 调用时分发器用页组值覆盖了 A，所以 `LIB_PRINT_HEX` 这类要 A 传参的例程不能用；显示十六进制要自己转换。
- **`LIB_PRINT_STRING` 在光标当前列开始显示，且不移动光标。** 分两次显示同一行会互相覆盖；要整行显示就先拼好再一次显示，换行前把 `CURSOR_COL` 置 1。
- **服务的结果不要从进位标志取。** 读 `DOS_ERROR`（文件、页服务）或各服务规定的变量。
- **`FILE_SIZE_0-2`、`FILE_START_PAGE` 等单元会被后续调用改写。** 写文件时在 `$7C/$10` 之前才写这些单元；需要的值先存到程序自己的变量里。
- **页分配的 `ALLOC_COUNT`、`ALLOC_START` 要在释放前写回。** 它们也会被别的调用改写，自己保存起始页号与页数。
- **页数换算只适用于不大于 64K 的文件。** 文件大小的第 3 字节非 0 时按“内存不足”处理。
- **从键盘启动程序时，模拟器把回车键当成手柄的选择加开始键。** 读手柄的程序要先等几十帧再初始化（示例 `pad` 等 120 帧），否则一启动就读到这两个键。
- **鼠标中断要用 `$13/$81` 允许。** `$13` 的位是“屏蔽”位，`$13/$01` 是屏蔽，屏蔽时一直收不到鼠标数据。
- **手柄服务 `$6A` 要先用 `$12/$85` 打开。** 否则 NMI 里不读手柄，`$6A/$02` 会一直等下去。
- **不要直接 `JSR` 到别的页组的地址。** 跨页调用要经 `$25`、`$26`（C 用 `sb2000-system.h` 里的跨页函数）。
- **系统服务换页后，程序窗口里的参数块不可见。** 换入页组的服务（如 `$53` 直线步进用零页指针指向参数块）读到的是别的页；参数块要放在任何映射下都可见的 ERAM（`$7EE0` 起的 18 字节）。带“页组 + 窗口地址”的服务，页组取程序起始页即可读到程序窗口里的数据。
- **文件读写按块分。** `$7C/$05` 读按 `4096 − (偏移 & 511)` 为一块；`$7C/$06` 写不能扩大文件，超出大小出错码 `$14`；创建新文件并写入用整页写（`sb_file_write_all`）；`$7B/$01` 装入 FAT 缓存失败时 `DOS_ERROR` 仍为 0，要看 `DISK_STATUS`。
- **声音引擎在 NMI 里更新。** 起播后要等 1 到 2 帧才有寄存器影子；曲子放在程序窗口里起播后，引擎在 NMI 里读乱，曲子要放在 ROM 页或自己申请的扩展 RAM 页。
- **内联跳转表。** `JSR $EE76` 之后紧跟 2 字节地址表，A 为下标，直接跳到表项，不会回到 `JSR` 的下一条指令；汇编里不要按普通子程序理解它。
- **文件名与路径。** `PATH_BUFFER`（`$6543`）是以 0 结尾的 ASCII，可带 `A:` 与 `\`；DOS 文件名按 8.3，大写。

## 出错码（`DOS_ERROR`）

0 为成功。出错码的含义表在使用文档主题 `syscall`（`fcdev_docs`）的第 6 节（`$01` 到 `$2E`，中文与英文说明），符号名在 `sb2000.inc` 的出错码一节（C 里 `SB_ERR_*`）。`$2F` 起的字符串是 DOS 命令的提示文字，不是出错信息。常遇到的：`$02` 文件未找到、`$08` 无足够内存、`$14` 文件读写位置错误、`$28` 文件打开方式错误、`$2C` 磁盘空间不够。

## 没有示例的情况下怎么做

1. 先用 `fcdev_api` 查封装函数；有封装就用封装。
2. 没有封装：在 `api-reference.md` 的覆盖表里确认功能号，用 `sb_syscall` 加 `sb2000-symbols.h` 的常量调用。
3. 参数与结果变量、可靠程度按覆盖表与 `sb2000.inc` 的注释确认；标“代码阅读”或“待读”的只能当线索。
4. 写成小程序放进模拟器验证，验证前不在回答里写成结论；仓库示例 `syscall` 就是这种做法：由调试器把功能号与参数写进 ERAM `$7E00` 的请求块，程序代为调用并写回结果。
