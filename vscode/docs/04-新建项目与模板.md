# 新建项目与模板

命令“fcdev：新建项目”（与 Copilot 工具 `fcdev_new_project`）在空目录里生成开发结构与示例程序，之后用构建任务构建，见 [01-构建](01-构建.md)。模板随扩展发布，不从网络下载。

## 1. 命令与工具

命令的流程：

1. 选目标与语言：NES、SB2000（学习机）、SB97（小霸王 97）、裕兴（学习机）或步步高（学生电脑），C 或汇编（SB97、裕兴与步步高只有汇编）。
2. 选一个空目录作为项目目录；不存在的目录请先创建。
3. 生成项目后询问在当前窗口还是新窗口打开。

工具 `fcdev_new_project` 的参数是 `directory`（工作区里的目录，相对路径相对第一个工作区文件夹）、`target`（`nes`、`sb2000`、`sb97`、`yuxing` 或 `bbg`）、`language`（`c` 或 `asm`），调用前会弹出确认。

- 目标目录必须为空（允许已有 `.git`），否则报错，不覆盖已有文件。
- 没有该目标与语言的模板时报错，并列出可用的目标与语言。

## 2. 生成的项目

```text
<项目>/
  fcdev.json           { "target": "...", "name": "hello" }
  .gitignore           build/、compile_flags.txt、.vscode/c_cpp_properties.json
  README.md            该模板的使用说明，其中的 {{name}} 换成目录名
  src/hello.c          或 src/hello.s
  disk/README.TXT      只有带磁盘能力且镜像不建在系统盘上的目标（sb2000、sb97、yuxing）：构建磁盘镜像时放进镜像的使用说明，UTF-8 带 BOM、CRLF
  .vscode/tasks.json   构建任务（默认构建任务）、运行任务
```

- 程序名固定为 `hello`，同时是 `fcdev.json` 的 `name`，也是 DOS 里要输入的命令。
- `.gitignore` 在模板里叫 `gitignore`（不带点），生成项目时改名。
- `.vscode/c_cpp_properties.json` 与 `compile_flags.txt` 由扩展生成，含本机路径，所以被忽略。

## 3. 模板

七个模板（`rom` 目标没有模板，整机 ROM 工程的 `fcdev.json` 手写，见 [rom/01-开发指南](rom/01-开发指南.md)），放在扩展目录的 `templates/<目标>-<语言>/` 下，含 `template.json`（目标、语言、显示名）、`README.md`、`src`，`sb2000`、`sb97`、`yuxing` 的模板还有 `disk`；以 `_` 开头的目录（`_common`）放公共文件：

| 模板 | hello world |
| --- | --- |
| `nes-c` | 设置调色板，`nes_print` 在屏幕中间显示 `HELLO, NES!`，打开画面后死循环 |
| `nes-asm` | 同样的行为，汇编直接写 PPU 寄存器，`.include "fcnes.inc"`，导出 `_main` |
| `sb2000-c` | `sb_puts` 显示英文与中文（GB2312）各一行，`sb_getkey` 等键后返回 |
| `sb2000-asm` | 同样的行为，汇编调用 `_sb_puts`、`_sb_getkey`，导出 `_main` |
| `sb97-asm` | 直接写 PPU 显示两行英文并停住（SB97 的 DOS 程序不能返回 DOS），`.include "sb97.inc"`，导出 `_main`；SB97 没有 C 运行库，所以没有 C 模板 |
| `yuxing-asm` | 调用 ROM 的显示功能显示两行英文，`main` 返回后停住（裕兴的 DOS 程序不能返回 DOS），`.include "yuxing.inc"`，导出 `_main`；裕兴没有 C 运行库，所以没有 C 模板 |
| `bbg-asm` | 用 DOS 的显示字符功能显示两行英文，按任意键后返回 DOS，`.include "bbg.inc"`，导出 `_main`；步步高没有 C 运行库，所以没有 C 模板；没有 `disk` 目录（磁盘镜像建在用户指定的系统盘上，空间有限），`fcdev.json` 里运行时要加 `firmware` 与 `diskImage` |
