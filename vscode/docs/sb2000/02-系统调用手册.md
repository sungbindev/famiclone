# SB-DOS 系统调用手册

小霸王学生电脑的 SB-DOS（版本 2.00）程序接口：程序怎么放进内存、怎么调用系统服务、怎么读写文件、出错码是什么意思。内容来自对 BIOS 的代码阅读与模拟器实测；每一节标明可靠程度，没读完的地方写“待读”，不猜测。

可靠程度：**已确认**（代码阅读且实测过）、**代码阅读**（读过代码，没单独实测）、**待读**。

## 1. 程序文件与运行

| 项目 | 内容 | 可靠程度 |
| --- | --- | --- |
| 文件头 | 前 5 个字节是 `4C lo hi AA 55`：`JMP` 到程序入口，后面两个字节是魔数 `AA 55` | 已确认 |
| 装入位置 | DOS 把文件读入扩展 RAM（ERAM 页，页号不小于 `$80`），并映射到 `$8000` 起的窗口；程序文件的第 1 个字节位于 `$8000` | 已确认 |
| 入口 | 经系统调用 `$25`（页组 `$0642`）调用 `$0C/$0D` 里的地址，即文件头的 `JMP` | 已确认 |
| 退出 | 程序用 `RTS` 返回，DOS 恢复窗口、寄存器后回到命令行，并清屏重画提示符，所以输出要先停留再返回 | 已确认 |
| 命令行参数 | 程序名之后的部分转成大写、以 0 结尾放在 ERAM `$6364`（`CMD_TAIL`）起，第 1 个字节是分隔用的空格 | 已确认 |
| 大程序 | 程序大于 16K 时要自己换页：用系统调用 `$29` 映射别的页；FC Dev 的 `banks` 选项已封装，见 [开发指南](01-开发指南.md) 第 3.1 节 | 已确认 |

### 1.1 运行与装入的机制

- **装入位置**（已确认（ATTRIB 实测））：从 `$8000` 起装入扩展 RAM 窗口：实测 `ATTRIB.EXE` 运行时 `$4040-$4043` 为 `$80-$83`（扩展 RAM 前 4 页），`$8000` 起的内容与文件开头一致（其中偏移 5、6 的两个字节被 DOS 写成起始页号与页数，见 `$7F/$00`），大于 16K 的程序靠自己换页
- **调用与退出**（已确认（代码阅读与 ATTRIB 实测））：DOS 经 `JSR $FFF0`、功能 `$25`（内核 `$ED55`：`LDA $0642 / JSR $ED94 / JMP ($000C)`）把页号 `$0642` 起的 4 个连续页映射到 `$8000-$BFFF`，再跳到 `$000C/$000D` 里的地址（程序文件头的 `JMP`），程序以 `RTS` 退出，回到分发器 `$FDED`，`JMP $FEFC` 再用调用前保存在 `$0639-$063C` 的 4 个窗口页号重新映射 `$8000-$BFFF`，并从栈恢复 Y、X、P 后返回 DOS。所以程序退出就是普通的子程序返回，DOS 一直在 6576 模式下常驻；`ATTRIB.EXE` 在出错路径上把出错码写 `$6308` 后 `SEC / RTS`
- **从软盘装入的过程**（序列与读盘已确认）：在提示符输入 `attrib` 回车后（只含 `ATTRIB.EXE` 等文件的镜像实测）：软驱依次读 LBA 0-9（引导扇区与 FAT）、19（根目录）、33-41（`ATTRIB.EXE` 的 9 个数据扇区），读盘都由 `$862E` 的软驱例程完成；系统调用序列为 `$7B/$09`、`$80/$04`（读目录与 FAT），`$7C/$0D`、`$7E/$00`、`$7C/$0F`、`$80/$04`、`$7B/$0A`，再 `$80/$07`（软驱停转，每次文件操作之后都会调用，不读文件数据），同时用 `$29` 映射扩展 RAM 页 `$80`、`$81`，最后 `$29`（`$0641=$80`）、`$25`（`$0642=$80`，`$000C=$8000`）进入程序。各子功能的含义见 5 节各服务表

示例程序见 [开发指南](01-开发指南.md) 第 10 节。本手册里的变量、功能号、子功能号、出错码、运行库入口都有对应的符号名：汇编程序 `.include "sb2000.inc"`，C 程序用 `sb2000-symbols.h`（`SB_` 前缀），就能用名字代替数字。

## 2. 地址空间

6576 模式下（DOS 常驻在这个模式）：

| 地址 | 内容 |
| --- | --- |
| `$0000-$1FFF` | 内部 RAM：只有 2K，`$0800-$1FFF` 是 `$0000-$07FF` 的镜像（真机实测，模拟器已对齐，见 [硬件说明](03-硬件说明.md)）；零页 `$0000-$00FF` 供系统与程序共用，程序要避开 DOS 用到的单元 |
| `$2000-$3FFF` | 图形端口：寄存器 `$2000-$2008`（`$2008` 是 6576 的扩展控制寄存器）与调色板 `$2040-$207F`；芯片手册只定义这两段，`$2080` 以上有没有镜像没有实测 |
| `$4000-$4017` | 声音（4 通道 PSG：方波 2 路、三角波、噪声，寄存器 `$4000-$400F`、`$4015`；芯片手册没有定义 NES 的 DMC 通道寄存器 `$4010-$4013`）、精灵 DMA（`$4014`）、手柄（`$4016`、`$4017`） |
| `$4020-$4036` | 键盘（`$4020-$4022`，串行收发）、手柄与鼠标选择（`$4023`）、鼠标（`$4024`）、并口打印机（`$4025`）、扩展 I/O（`$4026`）、DAC（`$4027`）、初始设置（`$4031`）、中断（`$4032`、`$4033`）、定时器（`$4034-$4036`） |
| `$4040-$4047` | 8 个窗口的页选择：每个选一个 4K 页，对应 `$8000-$FFFF`；值小于 `$80` 是 BIOS ROM 页，不小于 `$80` 是扩展 RAM 页 |
| `$4048-$404F` | DMA（见 [硬件说明](03-硬件说明.md)） |
| `$4200-$4207` | 软驱控制器 |
| `$4300` | 显存 bank 选择（32K 一个 bank） |
| `$4400-$5FFF` | 不是 RAM：读出都是 `$68`，写不进去（真机实测，模拟器已对齐）；芯片手册里的 `$5000-$57FF` 2K 工作 RAM 在真机上没有，程序不能使用 |
| `$6000-$7FFF` | 8K 扩展 RAM（ERAM），任何窗口映射下都可见；`$6200-$65FF` 一带是 DOS 的状态变量 |
| `$8000-$BFFF` | 程序窗口：4 个 4K 窗口，由系统调用 `$29`、`$25` 映射 |
| `$C000-$FFFF` | 固定内核：ROM 第 4-7 页 |

汇编程序用 `sb2000.inc` 里的符号名，C 程序用 `sb2000-symbols.h`（`SB_` 前缀）。

## 3. 系统调用约定

```asm
        LDA #function
        STA SYS_FUNCTION        ; $063E，功能号
        LDA #sub
        STA SYS_SUBFUNCTION     ; $063F，子功能号（有子功能的服务才需要）
        ; 参数放在各服务规定的变量里
        JSR $FFF0               ; 系统调用入口
        ; 结果在各服务规定的变量里；文件、磁盘服务看 DOS_ERROR（$6300）
```

要点（已确认，来自分发器 `SYSCALL_DISPATCH` 与 `SYSCALL_RETURN` 的代码）：

- 入口 `$FFF0` 是 `JMP $FD8E`。分发器先把 P、A、X、Y 与 `$0639-$063C`（4 个窗口页号的影子）压栈，返回时全部恢复。
- **A、X、Y 与进位标志都不会带回调用者**：服务返回的值只能放在内存变量里，处理例程里的 `SEC`/`CLC` 在返回时会被恢复的 P 覆盖，所以必须读出错码，不能看进位。
- 每次调用开头把 `$0640`（`SYS_STATUS`）清 0；个别功能在子功能号超出范围时把它置为 `$FF`。
- 内联跳转表（已确认）：`JSR $EE76` 之后紧跟 2 字节地址表，A 为下标，直接跳到表项，不回到 JSR 的下一条指令；换页页组里也各有一份同样的例程
- 功能号规则：小于 `$10` 查 RAM 中 `$05FA` 起的表（每项 3 字节，运行时登记）；`$10-$3A`、`$65`、`$67-$6C`、`$6E-$75` 用 ROM 表 `$E082 + 2×(功能号−$10)`；`$3B-$64`、`$66`、`$6D`、`$76-$81` 按范围换入页组后进入页内入口；`$82` 以上直接返回。完整的功能号与封装情况见 [C 接口参考](../../targets/sb2000/api-reference.md)末尾的覆盖表。

## 4. 文件与目录服务

功能号 `$7B`、`$7C`、`$7D` 在页组 `$58`，子功能号写 `$063F`。例程名以 `FS_` 开头。

### 4.1 公共变量

| 变量 | 地址 | 含义 |
| --- | --- | --- |
| `DOS_ERROR` | `$6300` | 出错码，0 表示成功，见第 6 节；每次调用开头清 0 |
| `PATH_BUFFER` | `$6543` | 路径，以 0 结尾的 ASCII，可带 `A:` 与 `\` |
| `FILE_MODE` | `$6560` | 打开方式，0-5；不小于 6 时出错码 `$28` |
| `FILE_HANDLE_OFFSET` | `$6561` | 当前句柄在句柄表里的偏移，`$7B/$09` 成功后由系统写入，之后的 `$7C`、`$7B/$0A` 都用它 |
| `FILE_SIZE_0-2` | `$6568-$656A` | 文件大小，3 字节小端 |
| `FILE_START_PAGE` | `$656B` | 读写整个文件时的起始页号（扩展 RAM 页号） |
| `FILE_DATE_LO/HI` | `$656E/$656F` | 日期，FAT 格式：位 0-4 日，位 5-8 月，位 9-15 年（自 1980） |
| `FILE_TIME_LO/HI` | `$6570/$6571` | 时间，FAT 格式：位 0-4 秒的一半，位 5-10 分，位 11-15 时 |
| `FILE_ATTR` | `$6572` | 属性：位 0 只读，位 3 卷标，位 4 目录，位 5 存档（位 1、2 按 FAT 标准是隐藏、系统） |
| `DIR_NAME83` | `$651D` | 当前目录的 11 字节名称（8 字符加 3 字符扩展名，空格补齐，根目录首字节 `$5C`），由 `$7B/$0B` 设置，`$7D/$01` 整理名称时也读它；与 `$6528/$6529`（当前目录第一个扇区）一起决定相对路径在哪个目录里找，不要随便改写 |

### 4.2 打开方式（`FILE_MODE`）

| 方式 | 含义（来自 `FS_OPEN` 的代码） | 可靠程度 |
| --- | --- | --- |
| 0 | 打开已有文件；`$7C/$0F` 读整个文件要求这种方式 | 已确认 |
| 1 | 创建文件，已存在则覆盖；`$7C/$10` 写整个文件要求这种方式；打开时就分配 1 个簇，所以不写内容就关闭得到“大小 0 但占 1 个簇”的空文件；新文件属性 `$20`，日期时间取系统日期时间 | 已验证（`copy` 实机运行） |
| 2 | 打开已有文件；关闭时写回目录项；`$7C/$06` 按偏移写要用这种方式（或方式 1） | 已确认（`poke`） |
| 3 | 把已存在的文件的目录项首字节改成 `$E5`（标为已删除），关闭时同时把簇链在 FAT 里释放（实测：删除 HELLO.TXT 后簇 727 的 FAT 项为 0、空闲簇加 1）；只读文件（属性位 0）出错码 5，文件不变；目录项不存在时出错 | 已验证 |
| 4 | 取得目录项：只对根目录（路径 `\`、`A:\`、`.`）与已存在的子目录成功；对文件出错码 `$2D`，不存在出错码 2（`$7B/$0B`、`$7D/$03` 再把 2、`$2D` 改成 3）；已被占用的句柄出错码 `$2A` | 已验证 |
| 5 | 创建目录项（属性 `$10`）；目录已存在出错码 `$26`，已存在同名文件出错码 `$2D`；只支持一级子目录，在子目录里再建目录出错码 `$2A`（目录嵌套层数过多） | 已验证 |

关闭（`FS_CLOSE`）时，方式 1、2、5 的句柄先写回目录项，其余直接把句柄置为空闲。

### 4.3 句柄表

句柄表从 `FILE_HANDLES`（`$643B`）起共 4 项，每项 `$2C` 字节；`$FF` 表示空闲，打开后首字节是打开方式。第 0 项的字段（其他项的地址加 `$2C` 的倍数）：

| 地址 | 符号 | 含义 |
| --- | --- | --- |
| `$643B` | `FILE_HANDLES` | 打开方式，`$FF` 为空闲 |
| `$643C` | `FH_DRIVE` | 驱动器号：打开时存入当时的 `FS_DRIVE_LETTER`，读写时取回 |
| `$643D-$6447` | `FH_NAME` | 11 字节名称，首字节 `$E5` 表示已删除 |
| `$6448` | `FH_ATTR` | 属性 |
| `$6449-$644B` | `FH_SIZE_0-2` | 文件大小 |
| `$644C/$644D` | `FH_DATE_LO/HI` | 日期（FAT 格式） |
| `$644E/$644F` | `FH_TIME_LO/HI` | 时间（FAT 格式） |
| `$6450/$6451` | `FH_CLUSTER_LO/HI` | 起始簇号 |
| `$6452-$6454` | `FH_POS_0-2` | 文件位置，打开时清零 |
| `$6455` | `FH_FLAGS` | 标志 |
| `$6456/$6457` | `FH_DIR_LBA_LO/HI` | 目录项所在扇区 |
| `$6458` | `FH_DIR_ENTRY` | 目录项在扇区里的序号 |

### 4.4 功能 `$7B`（20 个子功能）

| 子功能 | 例程 | 作用 | 可靠程度 |
| --- | --- | --- | --- |
| `$09` | `FS_OPEN` | 按 `FILE_MODE` 打开 `PATH_BUFFER` 里的路径（相对路径在当前目录里找，见 `$7B/$0B`）；成功后句柄偏移在 `FILE_HANDLE_OFFSET`（依次 `$00`、`$2C`、`$58`、`$84`），`DOS_ERROR` 为 0；出错码：4 个句柄都在用 4，文件不存在 2，目录不存在（含把文件当目录）3，名称含非法字符 `$27`，打开方式不小于 6 时 `$28`；名称与卷标项同名（方式 0-3）出错码 5；方式 1、5 创建时根目录 224 项全部被占用（没有空位也没有已删除的位置）出错码 `$12`，有已删除的位置就占用它 | 已验证 |
| `$0A` | `FS_CLOSE` | 关闭 `FILE_HANDLE_OFFSET` 指定的句柄；关闭空闲句柄什么都不做、不出错 | 已验证 |
| `$0B` | `FS_FIND_ENTRY` | **设置当前目录**（DOS 的 CD 用）：以方式 4 打开路径，成功时 `DIR_NAME83`（`$651D`，11 字节）是该目录的名称（根目录首字节为 `$5C`），`$6528/$6529` 是它的第一个扇区（根目录 19），之后的相对路径都在这个目录里找；路径是文件、不存在或父目录不存在时出错码 3（当前目录不变），`..` 出错码 `$27`；**调用者不要随便改写 `DIR_NAME83` 与 `$6528/$6529`**，否则后面的相对路径打开会在“当前目录”里找不到文件（`$7D/$01` 也依赖 `DIR_NAME83`） | 已验证 |
| `$12` | `FS_OPEN_MODE3_CLOSE_NOFLUSH` | 以方式 3 打开再关闭（标为已删除、簇链释放），不停转软驱 | 已验证 |
| `$13` | `FS_RESET_HANDLES` | 把 4 个句柄全部置为空闲，每条命令开头都会调用 | 已确认 |
| `$01` | `FS_FAT_LOAD` | 取 `FS_LBA` 号扇区放到 ERAM `$6000` 起的 512 字节缓冲：FAT 缓存还没装入（`$6585` 位 7 为 0）时，先把引导扇区与 9 个 FAT 扇区共 10 个扇区整体装入缓存（ERAM 页 `$F5` 起，成功后 `$6585` 为 `$80`）；扇区号 0-9 再从缓存取出，缓存位置记在 `$6580`（扇区号）、`$6581/$6582`（页内地址，`$B000` 加余数乘 `$200`，低字节在前）、`$6583`（页号，`$F5` 加序号除以 8）；扇区号 10 起不经缓存，直接读盘；缓存里的修改在没有 `$7B/$07` 重置时一直保留 | 已验证（21 个扇区号，缓冲与镜像逐字节一致，装入后 10 个缓存扇区与镜像一致） |
| `$02` | `FS_FAT_STORE` | 把 ERAM `$6000` 起的扇区缓冲（512 字节）写到磁盘的 `FS_LBA` 号扇区；扇区号为 0-9 时同时更新 FAT 缓存里对应的扇区，10 起（含第二份 FAT）和其他扇区只写磁盘 | 已验证（扇区 0、1、5、9、10、15、19、2000、2879，磁盘上只有该扇区被改写，缓存同步更新或不变） |
| `$07` | `FS_FAT_CACHE_RESET` | 把 `$6584`、`$6585` 清 0，`$657E`、`$657F` 置 `$0A`，只是把缓存标为“未装入”，缓存内容不动；下一次 `$7B/$01` 才会从磁盘重新装入整个缓存（修改过但没写回的缓存内容随之丢弃）；`$7B/$05`、`$7B/$0F` 自己不检查缓存是否已装入，使用前要先调用一次 `$7B/$01`（代码阅读） | 已验证（状态单元、重置后重新装入） |
| `$00` | `FS_NEXT_SECTOR` | 前进到下一扇区，结果在 ERAM `$65A9/$65AA`（调用开头先置为 `FS_LBA`），`$65C5` 开头清 0。按 `FS_LBA` 所在区域：扇区 0 与 10-18（第二份 FAT）出错码 `$1F`；1-9（第一份 FAT）与 19-32（根目录）加 1，加 1 后越出区域（到 10 或 33）不算出错，`$65C5` 置 1 表示区域结束；数据区（33 起）里，同一簇还有下一个扇区就加 1（16 位回绕，扇区 65535 加 1 得 0），否则按簇链取下一簇再换算扇区；簇链到链尾（`$FF8` 以上）时 `$65C5` 置 1、`$65A9/$65AA` 保持原扇区号、出错码为 0；下一簇是空闲簇、坏簇（`$FF0-$FF7`、超过簇号上限的值）、扇区在数据区之前或簇号超出 FAT 范围（簇号不小于 3072）时出错码 `$1F`；等于簇号上限或为 1 的链项被当作有效的下一簇（C=1、A=`$FF` 等返回标志调用者看不到，只能看 `$65C5` 与出错码） | 已验证（每簇 1、2、4、8 扇区，原样镜像与特制 FAT 共 8 组，约 70 个扇区号各自与按汇编转录的模型一致） |

**软驱出错时文件服务的行为**（已验证，用模拟器的 `fdc` 命令注入故障；状态码与 `DISK_STATUS` 的对应见 5.2 节）：`$7B/$01` 读扇区（不经 FAT 缓存时）、`$7B/$02` 写扇区、`$7B/$10` 写回 FAT、`$7C/$0E` 读引导扇区、`$7C/$0F` 读整个文件、`$7C/$10` 写整个文件，磁盘读写失败时 `DOS_ERROR` 就是 `DISK_STATUS`（`$1A`、`$18`、`$15`、`$17`、写保护时 `$13`）。**例外**：`$7B/$01` 在 FAT 缓存还没装入时要先整体装入 10 个扇区，这一步失败时 `DOS_ERROR` 仍为 0（出错码没有传出来，只有 `DISK_STATUS` 里是状态码），而且缓存有效标志（`$6585`）已先置成 `$80`，缓存里是没读到的旧内容，之后的调用把它当有效缓存用。`$7C/$0F` 读整个文件时磁盘服务按方式 `$80` 工作，文件里排在出错扇区前面的扇区已读入目的页，出错扇区及之后的保持原样；簇链里的下一簇是坏簇 `$FF7` 时同样，链里已有的簇读入，之后保持原样。

**FAT 项读写的边界输入**（已验证，按汇编逻辑转录）：FAT 缓存只有 9 个 FAT 扇区，簇号不小于 3072（FAT 项偏移 = 簇号 × 1.5 取整，所在扇区序号不小于 9）时，`$7B/$05` 读不到项，`DOS_ERROR` 为 0，`$6532/$6533` 里留的是这个偏移本身；`$7B/$0F` 写不进缓存，什么也不改，`DOS_ERROR` 为 0；偏移按 16 位算，进位丢弃（簇 43691 起会折回缓存范围，没有专门验证）。`$7B/$0F` 的新值超过 12 位时：偶数簇把新值的高字节整个或进相邻字节（污染相邻簇的低半字节），奇数簇的新值左移 4 位，最高半字节被丢弃。

**目录写满时创建文件**（已验证）：子目录的目录簇写满 16 项时，创建文件先给目录再分配一个簇（新簇清 0 并写盘），再给文件分配簇；后一步因空闲簇用完失败（出错码 `$2C`）时，目录扩展不回滚：磁盘上目录多了一个空簇，文件没有创建，FAT 两份一致。只读目录（属性 `$11`）用 `$7D/$03` 删除出错码 5，磁盘不变。

磁盘按 FAT12 格式管理：簇号 ×1.5 得到 FAT 里的字节偏移，奇数簇取高 12 位。每个盘的参数块（每簇扇区数、FAT 扇区数、数据区起始扇区、簇总数等）在 ERAM `$64FB` 起，A 盘偏移 0，其他盘偏移 `$19`：`+0` 每簇扇区数，`+1` 它的移位数，`+2` 根目录项数（低字节），`+3` 每个 FAT 的扇区数，`+4` 数据区起始扇区，`+5` FAT 部分扇区数（含引导扇区，即 2 × 每个 FAT 的扇区数 + 1），`+6` 根目录扇区数，`+7/+8` 簇号上限（簇总数 + 2）；卷序列号在 `$64EC` 起 4 字节、卷标在 `$64F0` 起 11 字节（由 `$7C/$0E` 填写）；FAT 缓存里的第 0-9 个扇区是引导扇区与 9 个 FAT 扇区。内部还有分配簇链、找空闲簇、扇区号换算簇号等例程（`FS_ALLOC_CHAIN`、`FS_FIND_FREE_CLUSTER`、`FS_LBA_TO_CLUSTER`），程序用 4.5 节的高层服务就够了。

### 4.7 读文件的标准顺序（已确认，`play`、`show` 实机运行）

完整示例见示例程序 `show`（DOS 下输入 `show 文件名`，显示文件开头 90 个字节；含参数读取、出错时先释放再关闭、显示出错码）。

```asm
        ; 1. 路径写入 PATH_BUFFER（$6543），以 0 结尾
        LDA #0
        STA FILE_MODE              ; 方式 0
        LDA #$7B
        STA SYS_FUNCTION
        LDA #$09
        STA SYS_SUBFUNCTION
        JSR $FFF0                  ; 打开；之后检查 DOS_ERROR
        ; 2. 取文件大小
        LDA #$7C
        STA SYS_FUNCTION
        LDA #$0D
        STA SYS_SUBFUNCTION
        JSR $FFF0                  ; 大小在 FILE_SIZE_0-2
        ; 3. 按 ceil(大小 / 4096) 分配页
        ;    页数写 ALLOC_COUNT（$65A6），调用 $7E/$00，起始页号在 ALLOC_START（$65A7）
        ; 4. 起始页号写 FILE_START_PAGE（$656B），调用 $7C/$0F 读入整个文件
        ; 5. 关闭：$7B/$0A；释放页：$7E/$01
```

每一步之后都要读 `DOS_ERROR`，0 为成功。

只需要文件中的一段时，把第 4 步换成“写 `FILE_OFFSET_0-2`、`FILE_SIZE_0-2`（长度）、`FILE_START_PAGE`，调用 `$7C/$05`”，页只需要分配能放下这段数据的个数（见 `peek`，分配 1 页读 30 个字节）。

### 4.8 写文件的标准顺序（已确认，`copy` 实机运行）

1. 路径写入 `PATH_BUFFER`，`FILE_MODE` 写 1，调用 `$7B/$09` 创建文件（已存在则覆盖），检查 `DOS_ERROR`。
2. 要写的内容放在已分配的扩展 RAM 页里（页的分配与读入见 4.7）；把长度写入 `FILE_SIZE_0-2`、起始页号写入 `FILE_START_PAGE`，调用 `$7C/$10`。`$7B/$09` 与读文件的调用会用到这几个单元（读文件会把大小写入 `FILE_SIZE_0-2`），所以要在调用 `$7C/$10` 之前才写。
3. 调用 `$7B/$0A` 关闭：方式 1 的句柄关闭时才把目录项（大小、起始簇）写回磁盘（代码阅读），程序里不要省略。
4. 调用 `$80/$07` 让软驱停转。

不能写长度为 0 的内容（出错码 `$25`）；复制空文件时只做第 1、3 步，得到一个空文件（已实测）。新建文件的日期时间取 DOS 当前日期时间；覆盖已存在的文件时也会更新目录项的日期。

只改已有文件的一段时，把第 1 步的 `FILE_MODE` 改成 2，把第 2 步换成“写 `FILE_OFFSET_0-2`、`FILE_SIZE_0-2`（长度）、`FILE_START_PAGE`，调用 `$7C/$06`”，再关闭；文件大小不变（见 `poke`，跨扇区写入已实测）。

## 5. 内存页服务（功能 `$7E`，页组 `$5C`）

扩展 RAM 页由 ERAM `$6586` 起 32 字节的位图管理（位为 1 表示空闲）：

| 子功能 | 作用 | 可靠程度 |
| --- | --- | --- |
| `$7E/$00` | 按 `ALLOC_COUNT`（`$65A6`）个页数找连续空闲页（位图从页 0 找起，位 7 是最小页号），占用它们，起始页号放 `ALLOC_START`（`$65A7`），`ALLOC_COUNT` 保持原值；没有则出错码 8、起始页号清 0；`ALLOC_COUNT` 为 0 时只返回第一个空闲页号，不占用（没有空闲页同样出错码 8） | 已验证（位图、临时单元逐字节与模型一致） |

## 5.3 键盘输入服务（功能 `$6B`，内核）

键盘经 `$4020-$4022` 串行收发，扫描码按 IBM 扫描码集 1 的按下码处理（`$E0`、`$E1` 前缀的扩展键也认）。`KBD_HANDLER` 读到扫描码后，按修饰键状态查映射表，把一个按键转成 2 个字节（ASCII，扫描码）放入按键队列。

| 变量 | 地址 | 含义 |
| --- | --- | --- |
| `KEY_QUEUE` | `$0336` | 按键队列，12 字节的环形队列，每个按键 2 字节（ASCII 在前、扫描码在后），实际只能存 5 个按键（留一个空位区分满与空，第 6 个起被丢弃，已实测） |
| `KEY_READ_INDEX` / `KEY_WRITE_INDEX` | `$0342` / `$0343` | 读、写指针（字节偏移，到 12 回绕）；队列满时新按键被丢弃 |
| `KEY_ASCII` | `$034B` | 取到的按键的 ASCII 码，没有字符的键（功能键、方向键等）为 0 |
| `KEY_SCAN` | `$034C` | 取到的按键的扫描码；功能键与 Ctrl、Alt 组合使用 IBM 扩展码（如 F1 是 `$3B`，Ctrl+F1 是 `$5E`，Alt+F1 是 `$68`） |
| `KBD_FLAGS` | `$0344` | 修饰键状态：位 0 右 Shift，位 1 左 Shift，位 2 Ctrl，位 3 Alt，位 4 ScrollLock，位 5 NumLock，位 6 CapsLock，位 7 Insert |
| `KBD_LEDS` | `$0348` | 指示灯状态：位 0 ScrollLock，位 1 NumLock，位 2 CapsLock |
| `ESC_BREAK` | `$063D` | 按 ESC 中断开关，见下 |

| 子功能 | 例程 | 作用 | 可靠程度 |
| --- | --- | --- | --- |

| `$6B/$01` | — | `ESC_BREAK` 置 `$FF`：之后按 ESC 会调用功能 `$1D`，恢复功能 `$1C` 保存的上下文（类似 `longjmp`，不返回） | 代码阅读 |

映射表（BIOS 内核里，每个扫描码 2 字节：ASCII、扫描码）：`KEYMAP_NORMAL`（普通）、`KEYMAP_CAPS`（CapsLock 开）、`KEYMAP_SHIFT`（Shift）、`KEYMAP_CTRL`（Ctrl，如 Ctrl+A 为 `$01`）、`KEYMAP_ALT`（Alt）、`KEYMAP_NUMLOCK`（NumLock 开时的小键盘）。表项里 ASCII 为 `$FE` 表示按小键盘规则处理，`$FD`、`$FF` 表示不产生按键。修改键盘布局就是改这几张表。

实测（用模拟器注入按键、读 ERAM 队列）：普通、Shift、右 Shift、CapsLock、Shift+CapsLock、Ctrl、Alt、NumLock 关这 8 种状态下，字母、数字行、标点、F1-F10、小键盘、方向等扩展键的翻译与标准 IBM 美式键盘一致（开机后 NumLock 是开的），只有下面几个组合与 IBM 不同：① Ctrl 加上、下、Insert、Delete 与 NumLock 关时的小键盘中间键，队列里会出现 `($FD, 0)`（表里的“不产生按键”标记被当成了按键）；② Alt 加小键盘（NumLock 开）给出数字本身的 ASCII 与扫描码，IBM 是不产生按键。修饰键标志 `$0344`、指示灯 `$0348` 随按键变化。`$6B/$00` 清空队列并重新初始化键盘（约 42 帧返回）；单独调 `$17`（键盘复位与识别）也能返回，但之后键盘不再上报按键，要再调 `$6B/$00` 才恢复。

曲子数据与引擎（已验证：实机逐帧与按代码写的模型比对 `$0393-$04A3` 的全部字节、`SOUND_TEMP0-03`，以及写向 APU 寄存器的序列（验证时记录 `$4000-$4013`、`$4015` 的写入；芯片手册只定义 `$4000-$400F` 与 `$4015`））：

- 曲子有两种头。**音乐格式**：首字节不小于 `$80`，后面是声道项 `[声道号, 音轨偏移低, 偏移高]`（声道号小于 `$80`），以不小于 `$80` 的字节结束；首字节后紧跟一个不小于 `$80` 的字节时，声道项从第 4 字节起。**音效格式**：首字节小于 `$80`，是优先级，后面同样是声道项；第 2 字节不小于 `$80` 时还有 3 字节头（第 3 字节放 `$03BD`，曲号放 `$03BE`，`$0499` 置位 5，用于播完自动接下一首）。声道项里声道号不小于 4 的，优先级写进 `$03BB+声道号`，优先级小于当前 `$03BB+声道号` 时整首不起播；音乐格式的曲子曲号与 `$03BB` 相同时也不起播（`$65/$0A`、`$0B` 的曲号恒为 0，所以音乐格式的曲子用它们起不了播，要用 `$00`、`$01`、`$09`）。
- 音轨偏移相对曲首（`$039B/$039C`，音效格式是 `$039D/$039E`）；声道 0-3 是音乐声道，4-7 是音效声道，音效声道与同号后四位的音乐声道共用一个硬件声道，音效声道播放时（`$03CF+声道号` 非 0）音乐声道不写 APU。音乐声道读曲子的页放 `$04A1`（`$00`、`$01`、`$09` 设置），音效声道的页放 `$04A3`（`$0A`、`$0B` 设置）。
- 每帧更新（NMI，要求 `$0630` 位 6 与 `$0499` 位 7 为 1）：先处理音效声道 7 到 4（时长减 1，减到 0 读音轨，刷新寄存器），再（`$0499` 位 6 为 0 时）处理音乐声道 3 到 0 的颤音、寄存器刷新与包络，然后 `$03D6` 加 `$03D4`，有进位的这一帧音乐声道的时长才减 1。声道 0 的状态位 `$03C3`：位 7 静音、位 6 写寄存器 0-1、位 5 写音高、位 3 写音量、位 2 写寄存器 1、位 4 发声、位 1 音效声道写寄存器 2-3 与 0、位 0 滑音（颤音用）。
- 音轨字节：`$00-$3F` 时长（音乐声道乘 `$043F` 的高字节得释放计数；音效声道直接作倒计时），`$40-$BF` 音符（音乐声道加 `$0447` 与全局移调 `$0393`，音符不小于 `$80` 时后跟 1 个扩展字节：位 6 把释放计数限到 `$043B`，位 7 持续发声，位 5 置 `$03CB` 位 2），`$C0-$E4` 命令：

## 5.6 窗口与跨页服务（内核）

`$8000-$BFFF` 是 4 个 4K 窗口，窗口 0-3 的页号寄存器是 `WIN_PAGE_0-3`（`$4040-$4043`），系统在 `WINDOW_SAVE_0-3`（`$0639-$063C`）里保存影子，每次系统调用返回时把影子写回寄存器（所以服务里对窗口的改动只在影子里记下，返回后才生效）。页组指连续的 4 页：首页号写 `SYS_GROUP`（`$0642`），其余三页依次加 1。

| 服务 | 入口 | 参数与作用 | 可靠程度 |
| --- | --- | --- | --- |
| `$25` | `API_25_CALL_BANKED` | 把页组 `$0642` 映射到 `$8000-$BFFF`，再调用 `PROG_ENTRY`（`$0C/$0D`）里的地址；入口返回后窗口恢复成调用前的样子 | 已确认 |

## 5.7 画面与中断控制（内核，部分）

下面只写读过代码、确认过的用法，其余子功能见 [C 接口参考](../../targets/sb2000/api-reference.md)：

- `$12`（`API_12_PPU_CONTROL`）：`$12/$00` 把 PPU 控制寄存器影子（`$062A`）的位 7 清零，即关闭 NMI；`$12/$80` 把位 7 置位，重新打开 NMI。磁盘读写前后就是成对使用（已确认）。子功能低 4 位不大于 6 时还能打开、关闭 NMI 中断里的各项服务（`$0630` 的开关）：`$12/$81-$86` 依次置位 `$0630` 的位 7、6、5、4、3、1，`$12/$01-$06` 清这些位（代码阅读）。其中位 3 管 NMI 里读手柄，要用 `$6A` 必须先调用 `$12/$85`（已确认，`pad`）；`$12/$85` 还把 `$0634` 置 `$FF`。`NMI_FLAGS` 各位：位 7 条带动画、位 6 声音更新（`NMI_SOUND_UPDATE`）、位 5 与位 4 调用登记的钩子、位 3 读手柄、位 2 精灵 DMA、位 1 把缓冲区内容复制到 `$2040` 起的调色板区域（代码阅读 `interrupt-handlers.asm`）。
- `$13`（`API_13_IRQ_MASK`）：中断屏蔽影子 `$062F`，写入 `$4032`，位为 1 表示屏蔽（禁止）该中断源，写 1 时硬件还会同时清除 `$4033` 里该源的待处理标志（模拟器源码确认，见[硬件说明](03-硬件说明.md)）。子功能 0-6 把位 7 到位 1（依次为 `$80、$40、$20、$10、$08、$04、$02`）置 1，即屏蔽；`$80+n` 把对应位清 0，即允许。已确认（`mouse`）：鼠标中断是位 6，`$13/$81` 允许鼠标中断，`$13/$01` 屏蔽；屏蔽着鼠标中断时收不到鼠标数据。`$13/$81` 执行后，如果鼠标已接入（`$0633` 非 0）就把 `$0634` 清 0，否则置 `$FF`。另外 `$13/$80` 还设置定时器 `$4034/$4035`，`$13/$02`、`$13/$82` 向 `$4022` 写 `$40`、`$80`；`$13/$88` 登记各中断源的处理例程。
- `$1B`（`API_1B_WAIT_FRAMES`）：等待 X 个完整的垂直消隐周期（帧）（已确认，最常用的延时）。
- `$1C`、`$1D`：保存、恢复上下文，类似 `setjmp`/`longjmp`：`$1C` 把页组 `$0642`、地址 `$0C/$0D`、子功能 `$063F` 压入 `$0656` 起的上下文栈（最多 10 项，个数在 `$0655`）；`$1D` 弹出并换页跳转，不返回；输入服务的 ESC 中断（`$6B/$01`）也经 `$1D` 实现。
- `$1E`（`API_1E_QUERY_STATE`）：按子功能 `$063F`（0-`$0C`）查询显示与系统状态，结果放 `$0652`（`$1E/$07`：位 0 表示 NMI 是否开着，即 `$062A` 的位 7，其余位取自 `$0630`；磁盘服务用它记住显示开关，读写完再恢复）。

### 5.7.2 DMA 与显存服务 `$30-$34`（已验证）

DMA 寄存器：`$4048` 控制、`$4049` 源 bank、`$404A` 源低、`$404B` 源高（位 7 是 A15，要求为 1，为 0 时 DMA 失败）、`$404C` 目的低、`$404D` 目的高、`$404E` 长度低、`$404F` 长度高（各位的含义见 [硬件说明](03-硬件说明.md)；BIOS 源码里的符号 `DMA_SRC_BANK`、`DMA_SRC_LOW`、`DMA_SRC_HIGH` 依次对应 `$4049`、`$404A`、`$404B`）；长度寄存器写“长度 − 1”。屏幕缓冲在扩展 RAM 页 `$FA`（名称表 4、5，偏移 `$000`、`$800`）与页 `$FB`（名称表 6、7），每张 2KB、每个单元 2 字节；区域填充的中转缓冲在页 `$F8` 起。

| 功能 | 作用 |
| --- | --- |
| `$30/$00-$03` | 名称表 DMA：把页 `$1F` 里的一张名称表经 DMA 写到显存（源中位 `$A0、$A8、$B0、$B8`，目的高位 = 子功能 × 8，`$062E` 位 0 为 1 时再加 `$20`，长度 `$07FF`，控制 `$C0`），等 1 帧 |
| `$30/$04-$07` | 求屏幕缓冲里单元的远地址：`$0648` 列、`$0649` 行，偏移 = 行 × 64 + 列 × 2 + 名称表基址（`$A0、$A8、$B0、$B8` 对应子功能 4-7）× 256，结果在 `SYS_PAGE`（`$0641`，高 4 位 + `$F0`）与 `FAR_OFFSET`（低 12 位） |
| `$30/$08` | 写单元：把页组 `$0642` 窗口地址 `PROG_ENTRY`（`$0C/$0D`，只取低 12 位）起的单元（每个 2 字节）写到远地址（`SYS_PAGE`、`FAR_OFFSET`），个数在 `$064F/$0650`，每写一个目的偏移加 `$0652` |
| `$30/$09` | 读单元：从远地址读 `$064F/$0650` 个单元到页组 `$0643`、`DST_ADDR_LO/DST_ADDR_HI` 指向的内存，每读一个源偏移加 `$0652` |
| `$30/$0A` | 清屏：`$0652` 的位 0-3 分别决定是否把屏幕缓冲里名称表 4-7 的全部单元填成 `$064C/$064D` |
| `$31` | 位掩码选区域，用 `$064C` 填满显存：位 0-4 依次是显存 `$0000、$0800、$1000、$1800、$2000` 起各 `$0800` 字节，位 5 是 `$2800` 起 `$5800` 字节，位 6 是 `$8000` 起 `$8000` 字节，位 7 把 `$2040` 起 64 字节调色板缓冲填成 `$064C`（显示关闭或 NMI 关闭时直接写，NMI 与显示都开时放进 `$0700` 缓冲，经 `$0630` 位 1 交给 NMI 上传）。长度不小于 `$1C00` 的区域分段 DMA（每段 `$1C00` 字节），最后一段不足 `$1C00` 时目的地址与上一段相同，可能是原程序的疏漏 |
| `$32` | 单段填充：显存 `$0646/$0647`（高、低）起，长度 `$0650/$064F`，用 `$064C` 填，长度为 0 时什么都不做 |
| `$33` | 扩展 RAM 到显存的 DMA：源 `SYS_PAGE`、`FAR_OFFSET`（经 `$28` 换算成 DMA 源地址），目的 `$0646/$0647`，长度 `$0650/$064F`，控制 `$C0`；长度为 0 时什么都不做 |
| `$34` | 同 `$33`，控制 `$A0`，目的取 `DST_ADDR_HI/DST_ADDR_LO` |

## 5.8 手柄与鼠标（功能 `$6A`、`$6C`，内核）

下面是读代码得到的结论，手柄、鼠标部分都已用模拟器的注入命令实测（`pad`、`mouse`）。手柄驱动在 NMI 中断里（`$0630` 位 3 置位时，用 `$12/$85` 打开）读 2 个手柄（`READ_PADS`），鼠标数据包由内核里的中断代码解析，程序并不直接读硬件。

**手柄（`$6A`）**

| 子功能 | 作用 |
| --- | --- |
| `$6A/$00` | 初始化：`PAD_KEY`、`PAD1_BITS`、`PAD2_BITS` 置 `$80`，`PAD1_RAW`、`PAD2_RAW` 清 0 |
| `$6A/$01` | 取按键码（不等待）：从位 7 向下找 `PAD1_RAW` 里第一个按下的键，没有就找 `PAD2_RAW`（鼠标接入时不找），键码放 `PAD_KEY`（`$034D`）；两个手柄的原始状态放 `PAD1_BITS`（`$034E`）、`PAD2_BITS`（`$034F`） |
| `$6A/$02` | 等到有按键再返回，结果同 `$6A/$01` |

键码（已确认：按 A、右、上、B 分别得到 `$0F`、`$08`、`$0B`、`$0E`，原始状态 `$80`、`$01`、`$08`、`$40`）：`$FF` 表示没有键；1 号手柄 `$0F`（A）、`$0E`（B）、`$0D`（选择）、`$0C`（开始）、`$0B`（上）、`$0A`（下）、`$09`（左）、`$08`（右）；2 号手柄同序，`$07-$00`。同时按下多个键时取最高位的。手柄原始状态的位顺序：位 7 为 A，位 0 为右（标准 FC 手柄的读取顺序）。

**鼠标（`$6C`）**

| 子功能 | 作用 |
| --- | --- |
| `$6C/$00` | 设置坐标范围：X 下限 `$0646`、Y 下限 `$0647`、X 上限 `$0648`、Y 上限 `$0649`，并保存 `$0652` 到 `MOUSE_PARAM`；原始 BIOS 里这一项执行完后会拿寄存器 A（`$0652` 的值）继续当子功能号比较，程序应让 `$0652` 不等于 1–4 |
| `$6C/$01` | 保存 `$0652` 到 `MOUSE_PARAM`（`$035E`） |
| `$6C/$02` | 取坐标：X 放 `$0646`、Y 放 `$0647` |
| `$6C/$03` | 整理按键状态到 `$0360-$0367`（按键 1：`MOUSE_BTN1_STATE`、`_RELEASE`、`_CLICK`、`_DOWN`；按键 2 同理） |
| `$6C/$04` | 设置坐标：X 取自 `$0652`、Y 取自 `$0653` |

光标坐标 `MOUSE_X`（`$0354`）、`MOUSE_Y`（`$0355`）每收到一个数据包就加上有符号位移，并限制在上下限之间；最后一个数据包的位移留在 `MOUSE_DX`（`$0352`）、`MOUSE_DY`（`$0353`）。`$14`（鼠标复位）得到的鼠标存在标志放 `$0633`。

**使用鼠标的顺序（已确认，`mouse`）**：`$14` 复位，检查 `$0633` 非 0（没有鼠标则为 0）；`$13/$81` 允许鼠标中断；`$6C/$00` 设置范围（`$0652` 不要是 1-4）；`$6C/$04` 设置初始坐标；之后随时用 `$6C/$02` 取坐标。实测坐标初值 `$80`、`$64`，依次移动 (10,5)、(10,5)、(-4,-3) 后得到 `$90`、`$6B`，即位移按 1:1 累加；范围上下限实测按 X 下限 `$0646`、Y 下限 `$0647`、X 上限 `$0648`、Y 上限 `$0649` 存入 `$035A-$035D`。模拟器把鼠标当成 1200bps 的微软串口鼠标（3 字节数据包，首字节位 6 为同步位）。

按键状态（`$6C/$03`，已确认，`mouse`）：`$6C/$03` 把驱动里的按键标志整理到 `$0360-$0367`。按键 1（数据包位 5）用 `$0360`、`$0362`、`$0364`、`$0366`，按键 2（数据包位 4）用 `$0361`、`$0363`、`$0365`、`$0367`。实测（模拟器里 `mouse btn 4` 对应按键 1、`mouse btn 1` 对应按键 2、`mouse btn 2` 没有反应）：

| 操作 | 状态字节（`$0360`/`$0361`） | 点击字节（`$0364`/`$0365`） | 松开、拖动字节 |
| --- | --- | --- | --- |
| 按住不放 | 1 | 0 | 0 |
| 按下并松开（查询时已松开） | 2（按键 2 实测） | 1（按键 2 实测） | 0 |
| 按下并松开，再按下（双击的第二次按下） | 1 | 0 | 双击字节（`$0362`/`$0363`）为 1，读走即清 |
| 双击的第二次松开 | 2 | 0（不再产生点击） | 0 |
| 按住并移动 | 1 | 0 | 拖动字节（`$0366`/`$0367`）为 1 |
| 拖动后松开 | 2 | 0（拖动不产生点击） | 0 |

“点击”字节读走一次就被清除。以上都在模拟器里用实验程序调用 `$6C/$03` 实测（`mouse btn 4`、`mouse move`），按键 1。驱动里的状态机（代码阅读，内部标志 `$0369`、`$036A`、`$036D`）：按下后若没移动，记下“可能双击”并让计时器 `$035F`（按键 2 是 `$0368`）清 0；松开时产生点击；在计时器小于 `MOUSE_PARAM`（`$6C/$01` 设置，取自 `$0652`）时又按下且没移动，才算双击；计时器由 IRQ 里 `$4033` 位 7 的定时器中断递增（`TIMER_IRQ_HANDLER`），实测在只允许了鼠标中断的程序里计时器不走（`$035F` 一直是 0），第二次按下不管间隔多久都被当作双击，要靠计时淘汰就得打开定时器中断（打开方法没有核实）。在 DOS 环境里（定时器中断已开）再测：双击间隔参数（`$6C/$00`、`$6C/$01` 的 `$0652`）为 `$FF` 时，按键 1 按下、松开、查询一次点击、再按下，第二次按下的双击字节为 1；参数为 0 时不产生双击（计时器不可能小于 0），第二次松开又产生一次点击；按键 2 的双击字节没有观察到产生。读走一次点击后，“松开”状态字节也会被清为 0。

## 5.10 中文输入法（功能 `$6D`，页组 `$0C`）

功能 `$6D` 换入页组 `$0C` 后按子功能号查 `IME_SUB_TABLE`（`$8012`，37 项，子功能 `$00-$24`）跳转；状态变量在 ERAM `$6900` 起，参数在 `$0652`、`$0653`、`$069A` 起。子功能 `$00-$0B`、`$0D`、`$0E`、`$13-$24` 已用模拟器实测：状态类子功能（`$00-$09`、`$13-$24`）、按键处理（`$0A`、`$0B`）与 `$0D`、`$0E` 都按字节级模型逐字节核对 ERAM `$6900-$69FF` 与相关 RAM。状态行显示（`IME_DRAW_STATUS_LINE`）是调用功能 `$45` 画到屏幕，只核对它清 ERAM `$6951` 的副作用，不核对屏幕内容。拼音类输入法（序号 1、2）的按键处理与词库子功能 `$0C`、`$0F-$12` 也已实测；外挂输入法（序号 3-6）、联想方式下的按键处理依赖外挂模块或联想词库，没有验证。

输入法序号（`$0652` 低 4 位，状态行文字取自 ROM `$9CF9`，每项 4 个 GB2312 字符）：0 区位、1 全拼、2 双拼、3 五笔、4 表形、5 认知、6 自定义（页组在 ERAM `$697C`，名称取自 ERAM `$697D`，由 `$09` 登记）、7 扩充、8 图形、9 英文；按键处理里临时用到的 10 国标（十六进制内码输入）、11 联想只在显示状态行文字时出现，不能选择。序号 7、9 不处理按键，原样传回；序号 0 是区位码与十六进制内码输入；序号 8 按输入长度 1-9（区号 `$A1-$A9`，低字节从 `$A1` 起）翻页浏览 GB2312 图形符号。

序号 1、2（全拼、双拼）的按键处理：小写字母追加到输入串（ERAM `$6905` 起），在音节表里查（全拼 408 项、每项 6 字节，输入串最长 6 个字符；双拼 465 项、每项 2 个字符，键位里含 `;`）。没有音节以输入串开头时：输入的是小写字母且已有候选字，先把第 1 个候选字作为输出（`$6922` 为 2），清空输入后以这个字母重新开始；输入的是小写字母但没有候选字，只丢掉这个字母；输入的不是小写字母（大写字母、数字、符号等），原样传回并丢掉这个键。输入串只是某个音节的前缀时只显示输入串；与某个音节完全相同时从词库取候选字（每页 5 个，页序号 ERAM `$690B` 清 0，后面还有候选字时 ERAM `$6903` 位 7、6 置位，没有候选字时显示提示）。没有输入时第一个键不是小写字母，原样传回。已有候选字时 `=`、`.` 翻到下一页（要 `$6903` 位 7 置位），`-`、`,` 翻到上一页；数字键 1-5、空格、Alt+1-5 的选字由通用处理完成（见 `$0B`），空格不会走到输入法自己的处理；退格删一个字符并重新查表。已验证（408 个全拼音节与 465 个双拼键位逐个输入并选字，另有翻页、自动输出候选字、非字母键、退格等输入）。

## 5.11 打印机服务（功能 `$76-$7A`，页组 `$0E`）

功能 `$76-$7A` 是同一个入口：分发器对这五个功能号做完全相同的事，只看子功能号（`SYS_SUBFUNCTION`，0-15），功能号之间没有区别。`$0391` 为 0 时换入页组 `$0E`（ROM 第 0E 页映射到 `$8000`）并从 `$8300` 进入（`PRN_ENTRY`）；`$0391` 不为 0 时改换入页组 `$0390` 并从 `$8000` 进入，这是留给外挂打印驱动的位置（实测把 `$0390` 设成输入法的页组 `$0C`，进入的就是输入法的子功能，证实了这条路径）。页组 `$0E` 里的代码是 24 针点阵打印机的驱动：发送字节经并口数据寄存器 `$4025`，握手用 `$4026`、`$4017`（位定义见[硬件说明](03-硬件说明.md)），发送的命令是 Epson ESC/P：`ESC @`（复位）、`ESC <`（打印头回左端）、`ESC J n`（进纸 n/216 英寸）、`ESC $`、`ESC \`（横向定位）、`ESC * 39 nL nH`（24 针三倍密度位图，`nL nH` = `$0478` = 1144 列）。模拟器实现了 ESC/P 虚拟打印机，输出到系统打印机或 PDF、PNG 文件。入口先调用 `PRN_SUB_14`（`$038F` 为 0 时初始化并口，之后置 1），再把 `$064E` 存入 `$0544`（发送变换模式）、`$0648` 存入 `$0546`（每个字符后附加的空白列数）、`$0649` 存入 `$0547`（换行后的进纸量），`$0640` 清 0，然后按子功能号跳转。

## 5.13 语音端口服务（功能 `$74`、`$75`，内核）

语音端口 `$4302` 的读写规则与 `$4026` 位 6 见[硬件说明](03-硬件说明.md)。语音数据是 LPC 码流：第 1 个字节 `$0A` 是开头标志，之后每帧先读 4 位能量（`0` 是静音帧，`15` 是结束帧），字节按位反序使用。`$032B` 是语音控制标志（位 0 为 0 同步发送，为 1 交给 NMI 逐字节发送；位 1 为 1 时已有传输就不等待；位 2 为 1 时发送后等传输结束；位 3 选命令字节 `$0A` 或 `$0B`；位 6 为 1 表示语音芯片已使用，调用时要先复位），`$0328` 是待发的命令字节，`$0329` 非 0 表示 NMI 正在发送（`$FF` 为请求发送，发出命令字节后放命令字节本身）。

## 9. 程序运行环境验证（V01～V10）

实施时对程序运行环境做过验证（2026-11-10，模拟器实测，固件为 `SB2K_BIOS.NES`），结论已写入 `link.cfg` 与 `crt0.s`：

| 编号 | 问题 | 结果 |
| --- | --- | --- |
| V01 | 程序运行时哪些零页单元空闲 | BIOS 符号表里的零页符号只到 `$50`；开机后 1800 帧内对 `$51` 到 `$FF` 设写断点，命中 0 次；C 运行库的零页定在 `$0060` 到 `$007F` |
| V02 | 返回 DOS 前需要恢复哪些被改写的零页单元 | 不需要；C 与汇编的 hello 各连续返回 DOS 两次都正常，DOS 清屏并重画提示符 |
| V03 | 窗口内数据、BSS 与软件栈的位置，硬件栈深度 | `main` 入口时 `S=$EA`，硬件栈约 235 字节；8000 字节的 `BSS`（超出文件）与 60 层递归通过 |
| V04 | 超出 16K 的程序是否需要换页 | 可行（2026-11-11 实验）：DOS 按文件大小一次装入整个文件（实测 12、64、116 页都能装入运行，160 页因内存不足不能启动），文件偏移 6 的页数字节是 12 等真实页数；程序自己用功能 `$29`（`sb_window_map`）把后面的页换进窗口 2 即可。实验程序：窗口 0、1 常驻代码与数据（链接配置里 `MAIN` 8K），文件第 2 页是窗口 2 的初始页，第 3 页是窗口 3（C 栈所在，必须留一个空页），第 4 页起是库页，每页 `$A000` 起 4K，C 里用 `#pragma code-name` 与 `rodata-name` 放进库页；常驻的 `bank_call` 先换页再调用、返回后换回，嵌套换页靠它保存当前页。`fcdev` 已按这个方案实现，见 [开发指南](01-开发指南.md) 第 3.1 节。9 个库页各取 3500 字节数据校验和、库页里调用常驻的运行库函数、库页间嵌套调用、系统调用（等帧、写文件）与 30 帧 NMI 等待之后，窗口 2 仍是换入的页，全部正确。DOS 运行时最大连续空闲页约 117 页（12 页程序运行时是 105 页），所以程序最大约 468K |
| V05 | 文件头 3 个自由字节的含义 | 偏移 5、6 由 DOS 改写；文件头用 `00 00 00` 可正常运行 |
| V06 | 程序窗口里文件之外的页归谁 | 无人占用：DOS 只按文件大小分页，页分配服务会把它们分给别人（程序的 `BSS` 与栈被占）。`crt0.s` 启动时紧接着程序页申请下来，返回前释放（2026-11-11，2 页与 4 页的程序都通过） |
| V07 | `sb_exec`（`$7F/$00`）运行子程序后调用者的状态 | 子程序的启动代码重设软件栈指针、改写零页 `$60` 到 `$7F`，返回后调用者的栈乱了；`sbi_exec_run` 在运行前后保存、恢复这 32 字节（只用绝对地址，不依赖软件栈）。子程序用新分配的页，调用者的页不受影响 |
| V08 | 系统服务换页后，程序窗口里的参数块是否可见 | 不可见：换入页组的服务（如 `$53` 直线步进用零页指针指向参数块）读到的是别的页。参数块要放在任何映射下都可见的 ERAM（`$7EE0` 起的 18 字节）。带“页组 + 窗口地址”的服务，页组取程序起始页（程序窗口占 4 页连续）即可读到程序窗口里的数据 |
| V09 | 文件读写的分块规则 | `$7C/$05` 读按 `4096 − (偏移 & 511)` 为一块；`$7C/$06` 写不能扩大文件，超出大小出错码 `$14`；创建新文件并写入用整页写（`sb_file_write_all`）；`$7B/$01` 装入 FAT 缓存失败时 `DOS_ERROR` 仍为 0，要看 `DISK_STATUS` |
| V10 | 声音引擎 | 在 NMI 里更新，起播后要等 1 到 2 帧才有寄存器影子；曲子放在程序窗口里起播后，引擎在 NMI 里读乱，曲子要放在 ROM 页或自己申请的扩展 RAM 页（BIOS 页 `$78` 的 `$8445` 提示音可作测试曲） |

## 10. 附录：卡拉 OK 歌词文字流格式（功能 `$66`）

功能 `$66` 读的歌词文字流，由调用者准备（各盘 `WIN98` 目录的 `KARAOK.EXE` 是例子）：

- ASCII 字符：`[字符, 时长]`；汉字：`[GB2312 高字节, 低字节, 时长]`；时长后可跟若干 `[$80, 附加时长]`，时长相加，可超过 255。
- `$00` 空白：`[$00, 时长]`。
- `$20` 空格：`[$20, 时长]`；时长为 0 的空格只把位置推进 2。
- `$5E`（`^`）：在子段外显示成 `$A1F1` 并按汉字算，在子段里按空白算。
- `$9D` 换行：一行最多 28 个字节，不足补空格。
- `$8E` 调用子段：`[$8E, 起点偏移 2 字节, 终点偏移 2 字节]`，偏移相对歌词数据起点，读到终点后回到调用之后继续，最多两层。
- `$FF` 结束。

注意（实机核对）：一行超过 28 个字节时，补空格的循环越界，把后面的内存（含位置栈和窗口保存单元）全写成 `$20`，随后的显示调用的页组变成 `$20`，不会再回到歌词例程；`$81-$9C` 里不认识的控制码在逐行解析里当 1 字节字符、往前解析里只跳过 1 字节，两个解析会不同步。所以歌词文字流里不要出现超长行和这些控制码。
